# ADR-009：账户身份与持仓录入来源分离

## 背景

现有 `Account.source` 同时承载“手动”“支付宝”“同花顺”“券商”，把账户身份、外部机构和本次持仓录入方式混为一个字段，并参与账户唯一键。这会让创建账户看起来像每次录入持仓的必经步骤，也无法准确表达同一账户可以通过不同方式更新持仓。

## 决策

投资账户只描述名称、可选机构、账户类型和币种，不再保存录入来源。手动或截图等录入方式保留在持仓变化、Ledger 和导入草稿的来源信息中；截图所属平台保留为导入草稿的截图来源。账户使用稳定 ID 标识并允许同名，界面通过机构、类型和币种帮助用户区分。

## 后果

数据库和共享类型移除 `Account.source`，将现有 `broker` 统一为可选 `institution`，并迁移可识别的历史机构信息。账户创建、持仓录入和截图审核成为相互独立但通过账户 ID 关联的能力；修改账户机构不会改变既有录入来源或审计记录。

## 替代方案

仅在界面隐藏 `source` 会保留错误的数据边界；把字段改名为账户平台仍无法容纳“手动”且会继续混淆机构与录入方式，因此不采用。
