# ADR-010：账户类型与账户模式分离

## 背景

现有 `AccountType` 把 `securities`、`fund`、`cash` 和 `shadow` 放在同一枚举中。前三项描述账户的业务容器类别，`shadow` 描述账户用于真实资产还是模拟研究，因此无法表达影子证券账户、影子基金账户或影子现金账户。

## 决策

账户分类拆为两个正交属性：`type` 取证券、基金或现金，`mode` 取真实或影子。账户类型表示业务容器并决定允许录入的资产与余额规则，账户模式决定数据是否代表真实资产，两者不得互相替代。第一版影子账户是拥有独立 Ledger、持仓、估值和风险数据的模拟账户，不自动镜像真实账户或接收策略自动写入，并默认排除在真实资产总额之外。

## 后果

数据库、共享类型、账户 API 和账户管理界面新增 `mode`。历史 `type=shadow` 账户迁移为影子证券账户，其他历史账户迁移为 `mode=actual`。Portfolio、Risk、Performance 和 AI 的跨账户查询默认只包含真实账户；只有显式选择影子模式或具体影子账户时才读取模拟数据，结果必须标注“模拟”。

## 替代方案

继续使用四选一枚举改动较小，但会永久丢失影子账户的资产类别，无法建立可靠的录入和估值约束，因此不采用。
