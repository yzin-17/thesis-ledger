## 口径与结论

按 [a-stock-data 固定提交](https://github.com/simonlin1212/a-stock-data/tree/bf447c1d05fa75eac907426601d602125c81a0cd) README 的 34 来源清单逐项核对。项目已交付的 63 类是资料类型数，不能当成来源数或全部端点覆盖。现有证据中，27 个来源至少有一项本轮或历史真实成功记录，1 个来源只有本次核对范围内的指定路径失败记录，6 个来源的相关路径未被本轮所核证据覆盖；这不是今日实时可用率。

“部分已验”只证明表中具体能力。不同 SDK、Provider 承载、同一网站的多个接口不自动成为独立上游；东财各域名也不据此计为互不相关的备份。参考库的可用性及风控描述属于其历史声明，本项目只按实际证据记账，不自动执行其重试、安装或关闭 TLS 的代码。

## 当前使用状态与边界

本轮完成的是来源覆盖核对及四组实源资格判定。纯解析、来源回执及39条条目Schema映射有独立证据；现有63类查询、精确路由、Provider／准入与业务保持当前状态。没有把采证成功写成正常产品备用绑定、前端可选来源或自动故障切换已经通过，也没有部署或设备更新。

配置只读快照期间另有并发工作把策略183／83条路由追加为184／85条：原83条全部保持，Provider／准入摘要相同，新增的两条基金净值路由不计入本轮写入或验收，也未回滚。工作区组合／估值／标的名称等并发源码修改同样单列保留，不计本轮代码验证结果；本轮主仓只改文档，DSA只新增资格纯解析／入口和测试登记，infra只扩固定采证入口。

读取不到的指定路径不代表整项功能无解；暂未核对的候选保留为未测，不伪造可用或不可用。后续产品接入必须先确定各源的请求范围及兼容字段，再维护来源修订和配置入口。当前四组首批资格任务没有代持这些未立项产品行为。
