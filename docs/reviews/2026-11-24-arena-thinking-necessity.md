# 重复思考方案的必要性审查

关联：[活动任务](../tasks/2026-11-12-arena-replay-live.md)、[已保存请求与回执](../evidence/2026-11-24-arena-finalization.md#本次截断的离线排查)。用户本轮要求先审查问题是否确需解决，再复用 `zshrc` 的现有 OpenAI 密钥新增提供方，用新模型对照已保存失败输入；不恢复或重试比赛。

## 审查结论

| 前述建议 | 现有证据 | 必要性判断 |
| --- | --- | --- |
| 压缩提示词与 Schema | 同一系统提示和 Schema 的前 6 次请求成功，失败输入比部分成功输入更短 | 可作为效率优化，尚不能认定为必须先修复的故障根因；本轮不改，以免干扰对照 |
| 改写 RSI 空值及资料缺口表达 | 早期样本确实不足；缺少执行资格时已有成功观望决策，现行合同允许合法结束 | 事实不完整不用于交易；表达优化尚无触发循环的因果证据，不补资料或扩大数据门禁 |
| 关闭或限制思考 | 本次思考重复、最终正文为空且长度终止有直接证据；具体语义触发原因未保存 | 是可能的缓解手段，尚未证明必要；先换模型检验，当前不改原模型推理设置 |
| 新增输出／周期保护 | 协议已有可选单次输出上限、周期时限及运行预算，失败后已有停止行为 | 保护可以复用，不新增强制预算或另一套终止协议；有限付费对照使用明确上限 |
| 先检验模型是否能完成相同任务 | 原失败输入、工具结果和合同已冻结，可独立生成且不落单 | 本轮优先做的最小对照，成功也不认证完整历史／实时业务 |

因此本轮不实施提示词、工具结果、业务校验、原模型参数或来源整改。新增提供方及单次对照的实际结果由独立证据记录；不能先把候选改进列成运行前提。

## 新提供方的接口适配边界

新模型选择官方模型目录可见的 `gpt-6.2-astra`。本次保存的原生请求 Schema 根节点为 `oneOf`，没有根 object；OpenAI 原生结构化输出要求根节点为 object，不能直接复用这一原生格式。[官方结构化输出说明](https://developers.openai.com/api/docs/guides/structured-outputs)。因此新提供方显式选择现有 `json_mode`，继续使用同一完整 Schema 文本和严格本地 Zod 校验；不为对照修改领域合同，也不通过格式失败推断模型能力。

请求内容、原时点、账户和工具结果保持；差异包括提供方、模型、相应 SDK 适配器／输出格式、模型自身默认推理行为，以及付费对照的有限输出／时间保护。它验证新组合能否完成同一业务任务，不能单凭一次结果区分基础模型能力、量化、模板、grammar 引擎及推理设置各自的影响。

## 有限执行与验收

新增 `openai-arena`，仅启用自主竞技场 v6 用途，不修改既有提供方或研究默认模型。正式验证计划限单用途、手动 JSON 模式，最多一次准入请求；通过后一次保存失败输入的独立生成。对照最多 16,384 输出 tokens、600 秒；失败／截断／未知即停，SDK 重试为零，不运行新工具、不写比赛及账户。

价格按 OpenAI 当前标准短上下文价登记：每百万输入 8 USD、输出 40 USD，即每千输入 0.008 USD、输出 0.04 USD。[官方模型及价格](https://developers.openai.com/api/docs/models/gpt-6.2-astra)。先固定正式计划和估算，再执行；旧 200 次预算不转用。密钥从用户指定的文件读取，仅交正式配置接口并由应用加密持久化，不回显或写入证据文件。

审查通过的执行范围为新提供方配置及独立样本对照；本轮不部署、提交或推送，不新增重启，不恢复共享队列或重试任何比赛。完整历史／实时的未通过状态继续由原活动任务持有。
