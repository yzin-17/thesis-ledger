# V1 Desktop UI E2E 清单

## 执行前提

- 使用已签名或明确标记为验收用途的 macOS/Windows release 安装包。
- `INVESTMENT_OS_API_URL` 指向隔离的 Investment OS Server；数据库从全新迁移和种子数据开始。
- 记录操作系统、安装包 SHA-256、API 环境、浏览器/窗口尺寸和执行时间。

## 主路径

| 编号 | 操作                            | 预期结果                                                | 证据               |
| ---- | ------------------------------- | ------------------------------------------------------- | ------------------ |
| D1   | 首次启动空组合                  | 显示四步 onboarding，账户和持仓为空状态清晰可见         | 截图/日志          |
| D2   | 创建手动账户                    | 账户成功保存，表单清空，Portfolio 请求重新读取          | 请求日志/截图      |
| D3   | 录入 `600519.SH`、数量、成本价  | Portfolio 总市值、成本、盈亏和持仓行与 API 返回一致     | API 响应/截图      |
| D4   | 上传截图并打开审核              | 生成草稿；未确认前不写入 Ledger                         | 草稿 ID/数据库记录 |
| D5   | 修正代码、数量、成本并提交      | 导入提交后重新估值，Ledger 有对应事实记录               | Ledger 查询/截图   |
| D6   | 创建、测试、停用 Risk 规则      | 规则版本递增，RiskEvent 记录规则版本和数据时间          | API 响应/审计记录  |

| D10  | 仅用键盘完成 D2、D4、D6、D7     | 所有控件可聚焦、操作和重试，焦点轮廓可见                | 键盘录屏           |
