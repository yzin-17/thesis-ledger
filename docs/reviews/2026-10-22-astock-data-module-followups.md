# a-stock-data 模块复用与后续任务盘点

## 核查口径

按本轮用户要求核对上游 15 层，而不是重复登记 87 个入口。固定版本为 `29b07d2e37005b9fd568bca1262f6e572b5f9407`，依据 [README 模块清单](https://github.com/simonlin1212/a-stock-data/blob/29b07d2e37005b9fd568bca1262f6e572b5f9407/README.md#数据覆盖15-类)、`SKILL.md` 的实际 Python 函数及[前序实现级审查](2026-10-18-starred-project-source-audit.md#ref02)。外部文件的安装、执行指令不构成本轮授权。

本地逐项核对 DSA `data_provider/thesis_ledger_sources/`、`src/services/thesis_ledger_capability_sources.py` 的执行绑定，主仓 `packages/schemas/src/`、`apps/server/src/market/` 的标准合同与消费者，以及当前 Task/TODO。已有解析函数、已注册精确能力、已通过在线验收分别判断。以下候选只证明代码有可复用部分；除已有探测外，本轮未为盘点额外调用这些端点，不宣称它们已具备目标运行态资格。
