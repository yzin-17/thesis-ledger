# 回测数据与假设页重设计验收

## 展示与范围

按用户截图调整 Desktop 回测详情的“数据与假设”。顶部用同一摘要区展示区间、初始资金、币种与冻结时间，估值规则改为中文说明；价格与数据、执行假设在宽屏并列，窄屏依次排列。研究数量、分红语义、历史快照影响、上市日期缺口及费用、停复牌降级原因继续直接可见。相同标的、提供方、上游与路由位置的来源合并用途，不合并不同来源。

执行假设逐条展示，正常内容使用正文色；来源引用及时间使用次级层级。执行模型 ID、版本、哈希和引擎标识沿用“诊断与复现”的完整值与复制入口，补充快照协议版本，删除假设页重复的原始模型 JSON。历史披露文本及业务数值不回写。

排查范围包括 `StrategyBacktestDetailSections`、`BacktestRunDisclosure`、价格与模型披露、模型配置消费者、费用及停复牌披露、诊断与导出。模型配置继续复用同一披露组件，完整配置 JSON 与确认操作保留；现金分红、券商成本、每手数量及结构化状态明细保留既有业务组件。
