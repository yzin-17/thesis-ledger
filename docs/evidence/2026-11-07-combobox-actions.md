# 下拉输入尾部图标统一证据

## 修复

用户截图中的清空图标位于下拉箭头之后。共享 `ComboboxInput` 先输出箭头容器，`InstrumentSearchCombobox` 再追加另一个尾部容器，导致顺序相反且间距分属两层。

共享输入增加 `endActions`，业务清空按钮进入同一个尾部操作区；内置 `showClear` 也采用“清空 → 下拉箭头”，不再因为有清空按钮就隐藏展开入口。两个按钮复用 `InputGroupButton` 的 24px 尺寸和同一层 8px 间距，默认可访问名称为中文。现有输入、清空、禁用、目录范围与选择回调保持。

## 排查范围

- Desktop 仅有一处 `ComboboxInput` 业务组合，位于 `InstrumentSearchCombobox`；其四个直接消费者为目录字段 `InstrumentSymbolField`、选项字段 `InstrumentOptionField`、持仓目录 `InstrumentCombobox` 和来源合同字段 `MarketReferenceContractField`，全部继承修复。
- 继续核对 Desktop 的 17 处目录字段、4 处业务选项字段、2 处持仓目录字段及来源合同的直接组合，覆盖策略执行标的、自然语言确认、研究、竞赛、自选、复盘、风险、定投、导入、持仓和成交编辑/筛选等派生入口。范围由实际 JSX 消费关系确认，没有逐页复制修复。
- 全仓核对下拉箭头、组合输入、清空图标和尾部 Addon。普通 `Select` 没有同框清空按钮；日期输入只有日历触发器；模型默认值、持仓与交易的独立清除动作不属于同框双图标；排序、任务取消、分组展开和对话框关闭保持各自语义。
- Mobile 使用输入加独立搜索/选择操作，没有这组输入尾部双图标，本轮不改变其交互。
