# 路由选项按当前能力过滤验收

状态：通过。规格见 [细分路由直接编辑](../specs/2026-11-09-market-routing-inline-editor.md) AC7，任务见 [实施清单](../archive/tasks/2026-11-10-routing-capability-options.md)。

## 当前行为与边界

主备新选项只来自当前范围的实际能力目录，不从提供方总表补入没有对应能力的来源。匹配市场、标的类型、用途、周期及复权全部已指定维度；具体来源本身也必须匹配，不能借用同一家提供方其他接口或周期的能力。大类、市场等聚合范围按至少一项实际支持入选，保留主备互补覆盖，覆盖不足仍由诊断表达。

未适配、复权或价格口径不兼容的来源排除。账户访问判断复用原 `accountAccessSelectable` 和原因映射，权限未确认、当前等级未包含、报告过期或配置修订不符时不作为新选项；缺少凭据的已适配来源沿用原禁选及说明。来源尚未准入等其他就绪状态仍显示原业务原因，能力支持与运行就绪分开判断。

已有不适用选择保持回显并附原因，选项禁选且领域更新拒绝写入；仍可清空或选择合格来源。初始读取不自动清空、换源或修改精确绑定。主备共享选择器、大类与细分行、统一草稿和预览保存保持。

仅修改 Desktop 投影、共享选择器的禁用表达、对应测试及浏览器脚本，没有 Server、DSA、接口、依赖、数据库或 Docker 改动。实际页面由宿主机 Vite 提供当前源码。
