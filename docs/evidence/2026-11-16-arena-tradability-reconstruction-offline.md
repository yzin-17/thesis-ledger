# 历史可交易性重建的离线修正与验证

## 范围与口径

承接[主任务](../tasks/2026-11-12-arena-replay-live.md) R1N1～R1N3 和 [DSA 任务](../../../daily-stock-analysis/docs/tasks/2026-11-12-arena-history.md) H5。按用户确认的口径：证券处于上市存续期、目标时点属于交易会话，官方停复牌查询成功且证券／日期筛选正确、分页完整，没有有效停牌事件，即可重建为正常交易。不再额外要求一份“未停牌证明”、原生逐分钟状态快照或官方全历史保留承诺。

本批次复用已保存的官方响应，未发送来源或模型请求，未部署、启动或重试比赛，未写生产归档、准入记录或真实业务数据库。历史失败、原始查询和原比赛保持原值。测试所用上市信息、交易会话、价格、收费和结算制度均明确为受控输入；本报告验证状态口径与接入链，不认证两证券完整真实执行资料已准入。

## 实现结果

- Python 与 TypeScript 合同增加 `reconstruction` 状态证据和 `trading.basis`，保存真实采集时刻、HTTP 成功状态、查询代码／日期／完整分页及上市、会话依据，不伪造历史 `availableAt`。原有快照／规则证据仍按历史可见时间核验，旧版合同往返保持兼容。
- DSA 新增纯离线的上交所基金历史查询原文解析与状态重建；校验官方端点、参数、代码／日期、错误结构、分页元数据、实取条数、重复记录及原文摘要。申赎暂停与二级交易停牌分开；固定且明确的交易停牌区间可以重建，相关粗时段或人工记录仍拒绝。不会把尚未发生的复牌时刻交给决策。
- 既有 `historical-execution-archive` 支持第二版索引的 `dailyContexts`，每次按 `asOf` 求状态；精确快照优先，旧版索引可继续读取。适配器和来源修订升为 v2，新旧准入隔离。来源仍默认关闭，逐证券／日期范围、政策与修订检查保留。
- 生产 Market 读取器通过既有 DSA 客户端消费重建结果，无需修改执行规则、价格限制、收费或结算的验收门槛。
