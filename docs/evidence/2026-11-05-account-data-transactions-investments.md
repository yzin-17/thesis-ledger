## 实现边界

- `AccountDataPage`、`useAccountDataNavigation` 和页签类型拥有页面组合与地址语义。
- `account-data.fund-investment.display` 拥有定投入口条件和稳定来源标识投影；页面、导航与定投查询复用相同条件。
- `AccountDataSections` 和 `AccountDataEventActions` 拥有成交工具栏、行与行内菜单；既有审计、成交修正、快照移除和划转回调保持。
- `AccountDataRecurringFundInvestments` 保留既有表单与 mutations；`FundInvestmentPlanList` 拥有当前/已结束计划的展示、展开及对应计划定位。
- 展示金额保留既有 BigInt 十进制乘法，不将数量与价格转换成浮点后相乘。回归样本 `9007199254740993 × 0.00000001` 显示为 `¥90071992.54740993`，非法金额显示暂不可用。
- 按 recommend skill 核对已安装 `es-toolkit@1.51.0` 的运行时导出、`partition.d.ts`、实现和官方文档后，使用 `import { partition } from 'es-toolkit'` 一次分组当前/已结束计划；该函数返回两个新数组，不修改原计划集合。未新增依赖或安装组件。金额展示是领域投影，继续使用现有精确运算。
- 定投历史使用仓库已有的原生 details/summary 模式；未新增 CSS 或全局覆盖，未修改服务端、数据库、原生工程或业务写入协议。

原定投业务规格仅同步页面位置并链接当前界面规格，计划生成、确认前不改变持仓现金和账本版本约束继续有效。
