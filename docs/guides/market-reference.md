# 市场资料查询

桌面从“市场数据 → 市场资料”进入；手机从“市场 → 市场资料查询”进入。选择类型，填写所需代码／日期，再点“查询资料”。每页五条，翻页沿用当前条件；修改条件后重新查询。页面展示来源、抓取时间、字段单位和覆盖说明，缺失显示为 `—`，零仍显示为零。

## 当前范围

| 分组 | 可查询资料 |
| --- | --- |
| 财务与估值 | 资产负债表、利润表、现金流量表、估值历史、同花顺来源 EPS 汇总及机构 EPS 预测 |
| 宏观与利率 | GDP、PMI、LPR、中美国债收益率转引、宏观日历、官方 FR／FDR、人民银行社融增量、统计局最新 PMI、中债三类曲线 |
| 基金份额与公司事实 | 沪深 ETF 份额、融资融券、最新股东户数、大宗交易、营业收入／归母净利润预告、业绩快报、股东增减持、回购方案与进度、机构调研 |
| 市场事实 | 来源板块归属、个股资金流估算、龙虎榜、重点监控名单、涨停池、炸板池、跌停池、昨日涨停当日表现、同花顺编辑题材标签 |
| 指数参考 | 新浪沪深 300 参考、中证沪深 300 官方成分／权重、国证深证成指官方成分／权重 |
| 新闻与问答 | 东方财富全球快讯、央视新闻联播元数据、沪市全市场近期问答、深市指定公司近期问答 |
| 成交与盘后包 | 最近来源交易日的股票／ETF 分笔、指定交易日通达信 HTTP 盘后股票／ETF 快照 |
| 期货与大宗 | 五所官方期货日行情、四所会员排名、新浪国内期货报价及日线、A50 来源连续报价 |
| ETF 期权 | 四个沪市 ETF 标的的近月认购／认沽合约清单、独立合约报价、来源 Greeks／IV |
| 可转债 | 债券／正股身份、条款、上市／摘牌状态与来源最新转股数据 |

合计 63 类。既有 AKShare、HiThink、pytdx、BaoStock、腾讯和华尔街见闻 Provider 承载读取，真实发布机构和协议分别标识。原 47 类证据继续复用，本次新增期货、ETF 期权及可转债 16 类，见[当前来源复核](../archive/reviews/2026-11-04-astock-derivative-reference.md)及[前轮公开实现复用](../archive/reviews/2026-11-04-astock-public-source-reuse.md)。查询只读取资料，不触发研究生成、交易、记账或自动扫描。

## 查询条件和含义

- 股票代码使用 `600519.SH`、`300750.SZ` 等规范沪深 A 股代码。ETF 资料使用 `510300.SH`、`159915.SZ` 等当前规范范围的代码，沪深份额按交易所分开；深市公司问答只接受深市股票。新浪／中证指数切片固定为 `000300`，国证切片固定为 `399001`，表单自动显示相应指数。
- 估值历史必须指定日期窗口；宏观日历含首尾最多七天，中债曲线最多 360 天；涨跌停池、沪市 ETF 份额、央视元数据、编辑题材及盘后包的起止日期须为同一天。FR／FDR 可以不填日期读取最近记录。三表按原报表分页；深市 ETF、股东户数及最新官方宏观不接受任意历史筛选。
- 快讯使用来源游标翻页。其他资料按各来源的当前页或已明确窗口分页，均不承诺完整历史。日期不匹配、字段异常、连接失败与真正无记录分别处理。
- 财报按来源人民币原表展示，金额和每股值分列；历史报表可能已被修订。来源披露日不等于已建立严格历史可见性。GDP／PMI 等统计期单独展示，来源记录日不替代官方发布时间。
- 宏观、LPR 与国债收益率是来源转引记录；各期限缺值保留为空，不补成完整曲线。日历的计划公布时间、预期、前值和修正值保留原有含义与单位。
- 资金流为来源按订单大小估算的口径。板块归属包含来源自己的分类，不替代申万历史分类。回购保留来源进度代码，未知代码不推断成已完成；这些资料不转换为策略信号。
- 腾讯分笔为约三秒聚合记录，量以“手”展示；交易日由前后两次同一证券的来源行情时间确认。不提供交易所 Level 2 或整日完整性保证。
- 沪市份额接口一次返回该日整份快照，再选取证券；深市份额使用接口单标过滤，避免扫描全部分页。单位为万份，不等于净申赎金额；深市 T 日晚间值可能为预估，以 T+1 早间确认值为准，接口未逐条给确认标志。
- 中证成分与权重可能不是同一天，国证文件是当前发布快照；分别显示文件日期，不按行号混合或回填历史调样。FR 与 FDR 的样本范围不同；中短期票据曲线没有三十年期限，不补零。
- EPS 按同花顺表头的明确年度和“来源元／股”展示。来源没有另给 ISO 币种代码或完整统计窗／机构去重方法，不编造 CNY，不重算独立一致预期或自动进入估值。机构表是页面当前可见报告，不等于全部统计样本。
- 公司问答分开显示投资者提问与公司回复，未回复保留空值。沪市为近期全市场列表，来源相对时间按原样保留并配抓取时间；深市按指定证券查询，时间戳转北京时间。央视只读节目标题、日期和链接，整期节目与单篇条目分开。
- 编辑题材是来源编辑标签，不是本系统验证后的涨跌原因或生命周期。盘后包一次下载并核对各市场文件，表格投影当前支持代码范围的股票／ETF，数量分别为股／份；其他原包资产不作为新增功能。页面有分页边界，完整原包可从来源链接下载；不自动导入本地历史库。
- 期货日行情与会员排名须填写同一个交易日。日行情支持上期所、上期能源、郑商所、中金所及广期所，会员排名支持前四所；上期与能源分别显示。会员成交、持买、持卖为三套名单，郑商所的品种／合约层级分开，不按行号拼成同一会员的头寸。
- 新浪期货查询填写 `RB0`、`M0`、`IF0` 等来源连续代码，或 `RB2612` 等具体合约代码，不填写 `nf_` 前缀。日线可选日期；连续线保留换月跳空且不复权，来源缺结算时显示为空。价格保留来源报价单位，成交／持仓为手，官方日行情成交额为万元；不据此换算保证金或合约金额。大商所品种通过新浪读取，不称为大商所官方快照。
- A50 保留来源 `CHA50CFD` 连续报价身份，不对应本系统可交易的某个 SGX 到期合约。
- 期权合约清单支持 `510050.SH`、`510300.SH`、`588000.SH`、`510500.SH`，返回来源当前可用近月的认购／认沽；独立报价和 Greeks 填写清单中的八位合约代码。数量为张，价格为每份 ETF 权利金；调整合约的份数不假定固定一万。IV 按小数展示，例如 `0.1317` 为 `13.17%`；来源未披露完整 Greek 模型／时间缩放假设，不自行重算账户风险。
- 可转债按来源页读取，条款日期与来源最新债价／股价／转股价分列，规模为亿元、溢价率为百分比。未来摘牌日不提前判为摘牌，未来上市与未知状态分别保留；条款和报价不自动证明当前可交易性，也不回填历史时点。

## 收费资料版本

在“规则监测”的检查结果中打开“查看版本”，选择正文版本和比较基准，可切换“版本差异”与“正文快照”。差异以基准为起点，标记所选版本新增与删除的文字；观察时间只表示何时读到该内容，不表示正式发布时间或规则生效日期。

新采集支持网页主体及引用、DOCX 段落、可提取文字的 PDF 和资料包 JSON。快照在监测采集时保存，查看和切换版本不重新抓取来源。旧记录若没有保存正文，会明确提示；以后再次观察到相同指纹时可以保存当次快照，其采集时间不会回填成历史时间。扫描 PDF、加密文件、解析失败或超限均保留具体原因。来源网页入口展示当前网页，不能代替历史快照。

具体合同与验收边界见[资料正文快照与版本差异](../specs/2026-11-10-rule-monitor-snapshots.md)。

## 来源不可读时

页面保留明确错误，用户可稍后重新读取。资料查询遵循已保存的来源启停与精确路由，不自动启用、续期或切换来源。保存了当前适配不支持的自定义传输设置时，会在出站前拒绝，不忽略设置。

此前仅因未接入而取消的公开读取范围已经重新核对，新增功能见上表。申万分类变更在本机及目标 DSA 均遇到证书链校验失败，本轮保留取消结论；行业排名复用相同协议的既有失败证据。严格历史可见性、跨源统一预测币种、独立样本重算及完整题材生命周期不由这些来源事实自动提供，见[前轮来源复核](../archive/reviews/2026-11-04-astock-public-source-reuse.md)。取消范围不重新挂回 TODO。

## 接口与维护

各主要来源的实际已验能力、未测范围及首批备用路径差异见[来源覆盖与备用源核对](../reviews/2026-11-04-astock-source-coverage.md)。采证通过本身不改变来源选择；是否已用于产品读取，以当前配置、精确路由及对应产品验收为准。

产品入口为 `POST /api/market-data/reference`；DSA 使用独立的 `dsa-data-v1` 市场资料入口。资料类型、列、单位及作用域由[当前规格](../specs/2026-11-03-market-reference-data.md)与共享合同维护，不接受任意 URL 或字段。

目标仅做代码更新时使用 infra 的 `scripts/sync-code.sh`，保留其兼容性预检。新资料路由由 infra 的 `scripts/market-reference-routes.mjs` 先生成只读计划，再通过前端同一 Server 策略 API 按期望修订应用；撤销本轮取消项须额外提供首次创建计划，不能删除原有路由。代码快更位于容器可写层，镜像重建后需要重新更新。

来源解析与执行由 [DSA 资料规格](../../../daily-stock-analysis/docs/specs/2026-11-03-market-reference-data.md)、[公开协议规格](../../../daily-stock-analysis/docs/specs/2026-11-04-public-reference-data.md)及[衍生品适配规格](../../../daily-stock-analysis/docs/specs/2026-11-04-derivative-reference-data.md)维护；采证由 [infra 公开来源契约](../../../daily-stock-analysis/docs/specs/2026-11-04-public-reference-source-check.md)与[衍生品采证契约](../../../daily-stock-analysis/docs/specs/2026-11-04-derivative-source-check.md)维护，路由计划和保护边界继续使用[精确路由契约](../../../daily-stock-analysis/docs/specs/2026-11-03-astock-existing-source-check.md)。
