# Android 与 iOS 手机端使用说明

手机端使用“组合、账户、市场、研究、更多”五个入口。本文说明已实现的页面与操作方式；双端原生编译、模拟器运行、当前源码 CI、真实来源、模型和 OAuth 的验收状态以[手机迁移任务](../tasks/2026-10-22-web-mobile-feature-parity.md)为准。

## 连接服务与范围

在“更多”的服务连接区域填写 API 地址，验证后确认切换。Android 模拟器默认使用 `http://10.0.2.2:3000/api/v1`，iOS Simulator 默认使用 `http://127.0.0.1:3000/api/v1`；访问其他部署时使用可达的可信服务地址，可通过 `EXPO_PUBLIC_API_BASE_URL` 配置默认值。

页面顶部切换“实际 / 模拟”。需要账户范围的页面另有账户选择；全局来源、模型和自动化配置不会因切换账户而变成某个账户独占。切换服务、范围或账户时，未提交输入与进行中的命令按页面提示处理。确认写入前应重新读取相关对象，读取失败或修订冲突时保留输入并显示原因。

## 组合与账户

“组合”展示服务端估值、现金、持仓与数据时点，可按账户查看交易、收益、风险事件和标的行情。没有证券持仓时仍可能有现金资产；陈旧、部分不可用与读取失败分别显示。

“账户”支持新建、编辑、停用和重新启用。进入“查看账户数据”后，可管理持仓/现金基线、成交、草稿与对账候选，以及资金计划和目标：

- 基线表示当前观察余额；保存草稿与确认写入账本是不同动作。
- 截图或文件先经系统选择并上传，再按服务端能力生成草稿；解析失败不代表账本已写入。
- 成交、现金与划转保留账户、币种、日期、原因和当前修订。提交成功后重读失败会单独提示，不要求重复提交。
- 定期资金与定投计划在服务端调度，手机处理计划和发生项状态。
- 永久删除须明确确认；有关联记录时由服务端拒绝并显示原因。

账户与账本语义沿用[核心模块说明](2026-08-18-user-guide.md#账户与持仓录入)及现行领域合同。

## 市场与风险

在“市场”搜索或选择标的，查看报价、K 线/净值、窗口、周期、复权和指标，以及参考资料、新闻公告和已收录原文。不同分段可能分别可用或失败；价格来源、时间和质量状态随结果保留。图表支持原生页面内拖动与缩放。

组合中的风险入口提供规则与事件、试算/扫描及审计；策略风险应用从策略工作区进入。试算、预览和确认应用是不同动作，不能把预览成功理解为规则已经生效。通知显示送达或失败状态，查看失败详情不会自动重新发送。

## 研究、复盘与策略

报告中的“研究材料”提供全部冻结材料入口；“工具调用历史”显示同一报告范围内保存的审计记录。刷新失败会保留已读正文；切换实际/模拟后，按新范围重新读取历史。

“研究”提供报告、引用、工具证据、历史和比较/复核入口，也可进入投资复盘及“策略与回测”：

- 复盘区分确定性事实、可编辑草稿、AI 解释及不可变历史。事实或草稿改变后，按提示重新分析；旧结果不自动覆盖当前输入。
- 新研究先检查能力与模型条件；提交标识和输入用于找回原请求。失败或结果未知时先读取原任务，避免重复创建。
- 策略工作区支持定义、版本、辅助编写和修改建议，以及普通/净值回测、实验与策略风险应用。建议采用、输入冻结及版本升级需明确确认。
- 回测与实验由服务端执行；手机查看进度、终态、证据及允许的取消/重试动作。应用进入后台不会在手机继续计算任务。

未知模型费用、不可用来源、预算或能力不足会保留具体原因，不以零费用或连接成功代替用途可用。详细经济口径见[策略与回测说明](2026-08-18-user-guide.md#strategy-与-backtest)。

## 来源、模型与自动化

“更多”的“配置与运行”区域包含：

| 入口 | 用途与关键反馈 |
| --- | --- |
| AI 模型与来源 | Provider、模型、用途、价格、生成/超时设置及研究默认模型；连接验证、用途验证、验证保存与启用分别显示 |
| 行情来源与账号 | 凭证、启停、账号能力和权限；准入、探测与保存分开处理 |
| Longbridge 网页授权 | 由服务端创建会话，在系统浏览器继续；返回应用后重新读取会话，返回本身不等于授权成功 |
| 行情路由配置 | 展示期望配置与实际生效状态，保留修订冲突与同步/验证反馈 |
| 标的目录与同步 | 目录任务进度、失败、重试条件以及标的确认 |
| 自动化任务 | 创建、编辑、启停、允许的删除、立即执行与历史；系统托管任务按权限限制修改 |
| 来源与通知诊断 | Provider 健康、数据质量和失败通知的筛选、分页与详情 |

秘密字段采用安全输入，不写入手机持久化草稿；提交、取消或离页后按提示重新填写。修订冲突时先显式采用最新配置再编辑，不自动覆盖他人的修改。取消等待或网络恢复不会自动重发有副作用的命令；结果未知时先重读服务端状态。

OAuth 需要有效客户端、真实账号授权及浏览器到服务端回调的可达路径。应用展示“服务端已确认授权成功”才表示已读到成功终态；本地测试状态与真实授权验收分别记录。

## 文件、恢复与设备条件

CSV 输出通过系统分享面板处理；面板打开不代表文件已经发送。外部原文与授权页通过系统浏览器打开，返回后查看应用中的读取结果。首次系统权限、浏览器条款或账号授权按其实际提示处理。

应用恢复到前台时重新读取适用状态。加载、空数据、失败、陈旧和结果未知含义不同；读取失败不应当作空列表，历史成功数据也不代表最新读取成功。

运行验收分别使用 Android Emulator 和 iOS Simulator；本机编译、构建产物、模拟器运行、当前源码 CI 与业务实源分层记录。当前条件缺口见[实施任务](../tasks/2026-10-22-web-mobile-feature-parity.md#第-6-批收口)，受控数据通过不代表业务实源已经验收。
