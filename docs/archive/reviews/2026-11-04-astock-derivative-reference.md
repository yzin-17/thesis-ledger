## 当前范围与出处

按用户恢复的范围借鉴 [a-stock-data 固定提交](https://github.com/simonlin1212/a-stock-data/tree/bf447c1d05fa75eac907426601d602125c81a0cd) 的 Layer 9／13／15，交付期货、ETF 期权及可转债 16 类资料，连同[前轮 47 类](2026-11-04-astock-public-source-reuse.md)共 63 类。外部文件只作协议参考，未安装或执行其 Agent 指令；[出处、修改与许可](../../../../daily-stock-analysis/docs/guides/2026-11-04-astock-public-source-attribution.md)由 DSA 维护。原 47 类按未变输入复用回执，无旧源重读。

新增资料由现有启用的 AKShare Provider 承载，各真实公开来源分别登记。只在 Data Route 增加 `FUTURE`／`OPTION`，可转债沿用 `CONVERTIBLE_BOND`；无开户、权限购买或来源激活，费用 0 USD，无模型或通知请求。

## 分层验收

63 类的标签、列、单位、作用域、日期、来源修订及资产身份逐字段跨语言一致；原 47 份及新增 29 份实际 API 回执均通过当前合同。29 个新用例覆盖全部 16 类与上述代码／标的变体。Desktop 16 类通过，其中 3 类走当前 API、13 类回放本轮真实响应；指定 iPhone Air 模拟器 16 类走当前 API，通过并导出 33 份截图／页面树附件。Android 的 16 类也均通过当前 API，保持原连接与应用数据。

相关 DSA 回归 242 项、Schema 1444 项、API client 185 项、Server 3 项及 infra 离线门禁通过；基金兼容修复另有 18 项定向检查。3 项既有 Schema 跳过与既有环境／尺寸告警保留，检查输入和命令见分层证据。

Server／Worker 经维护入口快更并保持原镜像；DSA 快更预检拒绝后使用正式 `update.sh dsa` 完整构建。发现并修复 AKShare 1.20.25 移除私有传递导出造成的基金导入问题，新镜像导入 Smoke、目标实际解析及正常 API 均通过。没有放宽快更或构建门禁。

两端复用既有原生二进制及当前 JS，安装保留应用数据与原 API 地址；不声明本轮应用 Native compile、实体设备、远端 CI 或商店发布。只编译 iOS 验收驱动不等于重新编译应用。
