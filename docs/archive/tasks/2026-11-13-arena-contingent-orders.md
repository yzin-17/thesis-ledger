## 阶段一　父单整笔成交后自动激活单一止损

- [x] **合同与状态。** 确定版本及字段，为独立委托、待激活子单、有效保护和终态分配可持久化的身份。区分父／子期限、未成交撤单、成交但等待可卖。保留旧账户、旧决策和旧 OCO 的读取与回放。
- [x] **执行。** 提交即保存整份计划，只预留入场现金。复用现有账户版本和事务锁；一次事务落账入场成交及保护，等待下一份有效市场证据撮合。证明零成交零卖出，不因子单误占老仓，重试幂等。
- [x] **模型与人工查看（源码与隔离入口）。** 更新相关系统提示、示例和精确错误字段。由正式配置生成中文确认，独立呈现模型摘要、自动委托、研究预约、父子关联、有效期及可保护数量。TOPT 样本只生成价格预约时，确认页明确显示自动卖单为零；本地实际模型三例正确配置经捕获回放通过。真实 Provider 资格与目标运行态另按验收叶完成。
- [x] **验收。** 用 359.50／355／27 的独立例完成领域、并发仓储、实时与回放对照及开发容器内模拟验证。覆盖未成交、全成、撤销、到期、无法出售、报价过期或跳空、模型不再运行、重复领取及恢复。正式快更通过；真实历史决策未修改，未向真实比赛提交验收委托。

## 阶段三　动态止损与分批建仓／退出

- [x] 移动止损显式选择可执行行情和激活后高点，支持百分比／金额与不含费成交均价保本。只在合格后续行情上移并保存高水位；触发后保持触发，即使分次成交期间反弹也不撤回。实时与回放比较通过。
- [x] 分批建仓区分并行与前批全成激活；全部预算提交时预留，每批独立数量、期限及退出归属。前批未全成结束则取消后批；后批不能消费前批激活那份行情。
