# 收费资料检查操作一致性

> 日期：2026-11-09
> 状态：已完成
> 规格：[统一自动化记录](../../specs/2026-11-09-rule-monitor-automation.md)
> 证据：[操作验收](../evidence/2026-11-09-rule-monitor-controls.md)

## 当前状态

Desktop 收费资料检查现与其他系统任务统一启停、编辑、立即运行操作，当前页共享面板支持编辑和草稿保护。沿用既有 Market 配置与幂等检查契约、每24小时频率和原调度器。36项相关回归、构建、定向 lint、边界/尺寸门禁及四宽度浏览器通过。真实配置维持用户当前修订2、启用、一个来源；真实写入、外部检查和通知均为0，未提交代码。

## 实施清单

- [x] T1：复用监测配置与幂等检查能力，提供当前页编辑、启停及已保存来源立即运行。检查读取失败、缺少来源及配置冲突保留行为（AC8）。
- [x] T2：统一表格操作与共享编辑面板，保存刷新任务列表及历史，关闭沿用草稿保护；定向测试覆盖真实请求内容和错误恢复（AC8）。
- [x] T3：Desktop 类型/构建、导入与尺寸检查、四宽度浏览器受控操作及真实只读页面验证。最终复核合同与证据并归档（AC7、AC8）。

## 实施前复核

已有 API 支持带修订号的配置更新和带请求标识的检查；可在客户端复用，无需新的 Server 写入接口或数据库升级。表格采用相同操作控件，监测编辑复用既有来源选择。验证使用拦截的配置/检查响应，不触发真实资料请求。该补充改动的唯一验收入口为本任务。

## 最终复核

AC8 及受影响的 AC7 已通过。新增管理职责收敛在独立面板、Hook 和编辑组件；原有任务操作继续交由既有处理器。历史与版本行为回归通过，配置与执行保持同一事实源，来源读取失败不会显示成停用。真实写入由受控请求验证，不计真实外部执行验收；无本任务剩余实施项。
