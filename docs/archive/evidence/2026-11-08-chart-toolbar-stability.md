# 行情工具栏加载稳定性验收

日期：2026-11-08；对应[常用选项规格 AC5](../../specs/2026-11-08-common-chart-choices.md)与[归档任务](../tasks/2026-11-08-chart-toolbar-stability.md)。

## 原因与修复

周期选项分别消费普通周期、年度、原生分钟及派生分钟能力查询。初始只有已知可用选项，后续查询确认周线等能力后加入按钮，原周期组按内容计算宽度，导致后面的工具栏分组换行。

共享选项控件增加预留空间能力，由周期入口使用：常用栏预留四项的空间，更多入口保留固定宽度；没有其他可用项时保留禁用的更多入口。仍只渲染原查询确认可用的周期，保留原偏好和不可用回退。区间继续沿用现有布局。仅修改 Desktop 展示，不改变服务端判断、查询顺序、缓存或来源请求。

服务端现有普通周期能力会检查市场与标的类型、交易日历窗口和当前复权口径的价格来源可用性，同时评估 MA、MACD、RSI 的历史窗口；本轮只核对其实现，没有修改这些检查。

## 验证结果

- 周期合同及实际交互两文件共 17 项通过，覆盖原可用性、能力失效回退、周期与区间独立偏好，以及更多菜单操作。
- 最终 Desktop `pnpm build`、变更文件与浏览器夹具 ESLint、导入边界及 `git diff --check` 通过。
- `check-chart-toolbar-stability.cjs` 在 1440、1024、768、390 全部通过：受控能力缓存先缺周线，再补齐周线，随后仅保留日线，再恢复全部能力。逐阶段比较工具栏宽高与各分组相对工具栏的位置、尺寸，完全一致；未开放的选项继续隐藏，更多入口在无额外选项时禁用，未发生横向溢出。
- `check-chart-choices.cjs` 同样四宽通过：常用项数量、更多列表、中文回显、股票与 ETF 间保留偏好、自定义日期取消、Esc 关闭及无横向溢出保持正常。
- 已目视核对桌面完整能力与 390 宽仅日线状态，预留区域及窄屏换行正常。

实际浏览器使用本机 Vite、Microsoft Edge 和 Playwright。受控样本通过已有 TanStack Query 缓存分阶段注入能力结果，验证真实组件的布局响应；未声称执行了真实慢接口或新的来源能力验收。两套脚本均没有新增 API 读取或浏览器错误。截图及结果位于 `/tmp/codex-market-range-qa/toolbar-stability/`、`/tmp/codex-market-range-qa/toolbar-stability-choices/`，构建日志为同级 `toolbar-stability-build.log`，均不纳入 Git。
