# 行情参考工具区布局验收

日期：2026-11-08；对应[交易叠加交互合同](../../specs/2026-11-04-market-trading-overlays.md#交互)。

## 实现结果

模型模拟买卖点进入“交易参考与测量”的展开区，与成交、成本、止损输入和区间测量使用同一排操作控件。默认收起时只显示一个入口；窄屏由共享工具行自然换行，模型与区间测量可利用同一行的剩余宽度。

参考区与图表之间统一使用 `gap-3`，当前主题下为 12px。没有交易参考入口时，独立模型按钮与图表沿用同一间距。模型比赛选项为空的容器采用原子类 `empty:hidden`，避免空容器额外占据分组间距。

`ArenaPriceLayer` 继续拥有模型开关、身份隔离、会话偏好和点位查询，仅提供通用的控件渲染槽；行情页把该入口组合进已有参考工具区，没有新增跨 feature import 或改动服务端契约。
