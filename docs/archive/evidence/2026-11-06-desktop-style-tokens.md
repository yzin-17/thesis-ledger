# 桌面端间距与字号验收

## 排查范围

检查 Desktop 的三份样式表和生产 TypeScript 源码，定位全部 19 个页签调用位置，涵盖一级页面、路由型页签、详情、抽屉与表单。检查项目字号声明、原子类任意值、内联样式以及共享页头、表格、卡片和页签。标准文字及业务布局使用同一主题尺度。图表库的数字字号、键帽对齐偏移、安全区域、边框与焦点宽度按各自单位保留。响应式断点、金融颜色和图表坐标具有独立语义。

## 浏览器实测

- Chromium 访问本机开发页面。收益分析在正常数据下，调整前「配置目标」与「交易」从页签栏底部到标题顶部为 44px 和 20px。配置目标在空内容组之后叠加了 24px。
- 修改后在 1440、1024、768、390 宽度，两页签均测得 16px，标题均为 20px。最终源码再次读取实际数据核对这两个页签，各宽度页头到正文均为 24px。
- 在 11 个页面入口核对页头、响应式字号与横向溢出。收益、账户、风险、策略、复盘、数据与自动化、市场数据的 24 个顶层页签，在四种宽度上获得 96 组面板测量。另选含交易和定投功能的账户，补查持仓、成交记录、现金、定投计划。卡片保留自身内边距。
- 在四种宽度测试键盘左右切换、配置目标编辑与取消、账户管理抽屉开关和边界；采用浅色和深色配色检查。不提交业务表单。
- 批量访问期间本地 API 曾返回 429。页头的独立验收使用受控读取失败状态，11 个入口、四种宽度共 44 组；截图中的两个数据页签另用真实接口复核。嵌套详情与原生应用未逐屏遍历，详情页签纳入源码扫描。
