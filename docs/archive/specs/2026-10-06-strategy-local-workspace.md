# 策略中心本地工作区

状态：默认本地工作区已交付；执行与实际验收见对应 Task。

用户目前只用于本人本地研究，不需要注册、登录或密码验证。策略编写原先把所有草稿读写绑定到用户会话，导致进入策略中心就出现登录表单。本次改为默认本地工作区：服务端提供稳定的本地归属，客户端读取工作区上下文后直接使用草稿和策略。

## 行为与边界

- 默认模式为 `local`；策略库、新建/恢复草稿、保存版本、回测和任务事件均无需登录。草稿重启或刷新后仍属于同一本地工作区。
- 服务端身份模块拥有固定本地标识，客户端只能读取上下文，不能自行选择归属。原有草稿修订、并发更新和保存规则保持。
- 已有公开策略继续可读。本地模式不修改旧账号所属数据、不自动迁移账号草稿，也不创建用户或会话记录。
- 原账号能力仅在明确配置 `STRATEGY_IDENTITY_MODE=account` 时使用，保持原会话和所属用户检查。此配置服务于兼容已存在的账号部署，本地无需设置。
- 保留身份模块对稳定归属的所有权。新增只读 `/api/v1/identity/context` 合同，客户端用 TanStack Query 读取，不创建伪造会话。
- 没有依赖、数据库结构或原生配置改动。目标同步使用 infra 正式脚本，与费用任务串行协调。

## 验收

1. 无会话直接访问策略库不显示登录/注册/密码表单。
2. 无会话创建、读取和更新本地草稿；刷新后继续读取同一草稿；保存后策略和回测消费使用同一归属。
3. 本地任务事件不因缺少会话而被丢弃。
4. 明确账号模式保持原隔离与失效会话行为。
5. 定向测试、包级构建和目标 HTTP/真实页面分别记录，未完成的运行验收不能用单元测试替代。
