# 删除 NVIDIA 官方新闻数据源

## 目标与范围

移除 `nvidia-news` 生产来源注册、专属适配器及页面说明。DSA 的来源目录、静态库存和可选路由不再提供该来源；其他新闻来源保持原有行为。

历史新闻、研究冻结记录和历史验收文档保持原样。当前政策中的该来源通过既有政策 API 精确移除，使用版本并发校验并保留历史版本，不直接修改业务数据库。保留其他已选来源及其顺序；若路由因此为空则关闭该路由，不另选来源。

## 验收标准

- AC1：生产注册、目录和静态库存不再包含 `nvidia-news`，专属执行模块及测试清单同步清理。
- AC2：新闻面板移除该来源专属用途说明，其他新闻读取和展示测试通过。
- AC3：通过正式更新入口同步 DSA 到目标运行态，独立读取目录、当前政策与宿主 Desktop 页面确认该来源消失；快更仅证明容器可写层更新。

## 风险与验证

检查既有来源失效逻辑，避免旧政策恢复已删除的来源。先运行 DSA 注册/库存及 Desktop 新闻定向测试，再运行相关边界门禁；最后进行目标运行态检查。当前工作区有其他任务未提交改动，保留其内容并明确验证边界。
