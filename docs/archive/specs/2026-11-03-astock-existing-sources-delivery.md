# A 股数据现有来源条件交付规格

日期：2026-11-03。任务标识：`astock-existing-sources-delivery`。状态：条件交付完成，历史规格归档。对应[任务](../tasks/2026-11-03-astock-existing-sources-delivery.md)。承接[可行性评估](../reviews/2026-11-03-astock-followup-feasibility.md)的原编号 4～10；现行产品由[市场资料规格](../../specs/2026-11-03-market-reference-data.md)维护。

## 目标与决定

用户要求：“如果现有数据源没法满足就取消，先尝试完成”。本轮正式尝试交付七组保留范围；每个独立子项先确认现有来源的合格样本，通过后完成实际消费与验收，现有来源确定不能满足时按用户决定取消该子项并保留原因。取消和验收通过分别记录。期货、ETF 期权和可转债的既有取消决定保持。

来源以当前前端已配置启用的 Provider 及真实上游来源家族为边界。同一既有上游的新字段／接口可以核对和接入；不能因为 AKShare 收录某接口就把新的发布机构视为已经存在。现有规则／交易状态等专用官方来源不得冒充任意官方数据读取入口。

不新增供应商或账号、不购买权限、不启用停用来源、不申请 Tushare／RQData 额外权限、不绕过认证或反爬限制。仅使用已有免费数据路径，新增费用为 0；模型调用与通知发送为 0。真实请求按每个叶的固定来源、最小单页／单标的和当前配置限频执行，记录实际请求、错误及修正复测；不把第一次临时故障判为永久不可用，不无限重试。

## 条件交付契约

1. 原编号 4：分开处理研报 EPS 原始预测和一致预期。年度、币种／每股口径、机构、发布时间及引用不明确时不能生成合格预测事实。
2. 原编号 5：估值历史、三类报表、行业与指数参考分别判断。报告期、生效日、来源可见时间和抓取时间分别保留；比率、金额与价格不可混用。
3. 原编号 6：宏观、利率与日历分别判断。只接现有真实上游能够交付的指标，保留聚合来源身份，不将聚合数据声称为官方直连。
4. 原编号 7：ETF 产品份额、两融／股东、大宗及业绩／调研等事件分别判断；现有净值、分红或筹码不替代新事实，未知状态不补造。
5. 原编号 8：新增快讯、央视节目元数据与沪深问答分别判断。稳定出处和市场范围满足现有新闻／引用合同后才可消费；复用已验新闻，不重复作为本轮新增成果。
6. 原编号 9：仅交付来源明确的单类事实，保留缺值、统计口径及时间；不迁入上游复合评分，不用量价代替资金流。
7. 原编号 10：分笔与独立盘后批量包分别判断；分笔不称 Level-2 逐笔，不将全市场批量作为单标读取的隐式 fallback。

## 交付及取消边界

来源采证必须先有唯一标识、限定对象／窗口、原始来源摘要及字段结论。来源名称、SDK 函数存在或 HTTP 200 都不替代合格数据。确定缺权限、超出现有来源家族、缺必要字段／历史范围或在现有配置与可修正复测后仍无可用路径时，可以取消对应交付，不能推断来源永久失效。缺产品代码不能作为“数据源不满足”的取消理由。

通过采证的子项再细化独立数据合同、DSA 执行、Server／工具消费、客户端和目标运行态叶；按实际变化选择已有更新入口。每个新增能力在必要的真实消费验收前保持未完成，不用采证工具代替产品功能。只读事实不写账本、不改持仓或策略，不触发模型生成和交易。

## 验证与保护

维护入口先离线检查参数、目标身份、来源白名单、出站计数、失败分类和只读配置保护，再运行真实最小样本。实现按定向测试、包级检查、仓库门禁、目标运行态与消费面逐级验证。已有高成本证据按输入复用。

保留原 Provider／路由／准入、凭据和业务数据；不得自动延长准入。跨仓职责遵循现行文档规则，Docker 变更只经 infra 维护脚本。原 WIP、HEAD 和索引保全，不暂存、提交或推送。

## 验收标准

- AC1：七组所有保留子项均有当前来源判断、证据和交付／取消归属，不遗漏或重复计算原已完成能力。
- AC2：真实调用限于本轮既有来源与免费路径，实际请求和修正复测留证，没有模型或通知调用。
- AC3：每个通过来源验证的子项有独立严格合同和实际产品消费，必要的目标运行态验收通过。
- AC4：每个取消子项有具体来源限制和对应用户条件决定，不以实现困难代替来源结论，不继续挂回 TODO。
- AC5：失败与未知结果、来源身份、单位、时间和覆盖语义保真，未用受控样本代收实源资格。
- AC6：原数据、配置、凭据与 WIP 受保护，三仓文档和任务入口一致，全部条件交付结果对账后再归档。
