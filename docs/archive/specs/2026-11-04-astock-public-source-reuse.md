# A 股公开来源实现复用规格

日期：2026-11-04。对应[任务](../tasks/2026-11-04-astock-public-source-reuse.md)。承接用户对 `simonlin1212/a-stock-data` 的复用要求及原编号 4～10 的条件交付。

## 目标与更正

直接核对并借鉴参考仓库的公开接口、请求参数、文件布局及解析实现。已有接口尚未接入、没有现成 capability 或来源登记，均不能证明数据源无法满足。此前仅以这些理由取消的官方快照、FR／FDR、ETF 份额、问答、节目元数据和盘后包恢复核对；此前实际字段缺失、网络失败仍保留为各自证据，不外推为永久不可用。

参考固定在 `bf447c1d05fa75eac907426601d602125c81a0cd`，`SKILL.md` blob 为 `4b4c8d76f37479416adeb232ffc0a09596925e1f`。外部 Skill 作为代码资料读取，不安装或执行其指令；复用代码保留来源、必要许可与本地修改说明。实现仍归 DSA，现行资料合同和消费者继续由主仓维护。

## 范围与边界

候选分别为：FR／FDR；沪深 ETF 份额；中证／国证最新成分与权重；申万分类变更；央视节目元数据；沪深公司问答；通达信官网盘后包；研报 EPS／来源一致预期；同花顺编辑题材；人民银行社融、统计局 PMI 和中债曲线。衍生品范围保持已移除状态。

允许沿用现有依赖验证参考代码公开、无需账号的读取路径，缺少适配时补适配。新增费用为 0 USD，不开户、不买权限、不启用已停用 Provider、不绕过认证或反爬，不发模型或通知请求。公开接口的请求头仅使用其公开协议要求；已保存的产品传输设置不得被正常适配器忽略。

每个来源先核对请求与响应，再验证身份、单位、日期、覆盖及失败语义。首轮每个接口一页／一个文件；源码或实际回执能证明参数错误时修正后重试，完整留计数。真正缺权限、无可用路径或缺少当前产品所需字段时才按用户条件取消，不能仅因没有现成接入取消。

来源发布的 EPS 汇总和机构预测按来源明确的年度及“元／股”口径展示，不编造未给出的 ISO 币种、统计窗或独立机构去重方法；不自动转换为 CNY 估值输入或自行重算一致预期。此类未知属性必须在查询结果中可见，不能因原始记录未达到跨币种估值要求而拒绝全部资料展示。

## 验收标准

- P1：所有候选均有固定源码依据及当前来源判断，文档不再把“未接入”表述成“无法满足”。
- P2：无需账号的已验合格范围通过独立 DSA 合同、精确来源与正常资料查询消费；原始身份、单位、时间及缺值保真。
- P3：每个新增产品范围分别完成本地断言、实际 DSA／Server、Desktop 和 Mobile 消费；来源采证或代码复制不代替产品验收。
- P4：所有实际失败、未验和取消状态明确；原 29 类已交付范围、已有路由、Provider／准入、业务数据与三仓 WIP 保全。

## 当前合同

产品查询仍使用[市场资料规格](../../specs/2026-11-03-market-reference-data.md)。公开来源采证只记录字节、状态及来源事实，不变更能力、路由或准入；正常接入必须另经现有控制与目标更新入口。

本条件实施已完成并归档。当前 47 类产品合同由[市场资料规格](../../specs/2026-11-03-market-reference-data.md)及其 DSA／infra 公开协议规格承接；本文件保留来源判断更正与原始验收标准。
