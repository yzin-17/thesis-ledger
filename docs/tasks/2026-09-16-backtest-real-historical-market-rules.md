## 历史收费实现方案（2026-10-06 讨论稿）

> 范围：回答「完整历史收费如何实现」，讨论本人本地研究的首个收费切片。以下是实施建议，未改变 Spec 或任务启动条件，未修改代码、安装数据或操作运行态。

建议通过「官方依据 → 版本化本地收费表 → DSA 区间核验 → Snapshot 冻结 → 现有费用引擎」实现。来源整理与回测执行分离：运行使用已核验的规则数据，重放只读取冻结的 Snapshot。当前先收敛收费叶的来源资格，完整 T1 仍需其他规则叶就绪。

### 1. 先形成一份可审阅的收费表

范围采用目前的调查候选：CN / 普通 A 股 / XSHG / 竞价 / CNY，执行窗口 `2023-08-25..2023-08-29`。具体支持范围待证据确认，研究预热与最终策略需求另行匹配。

先逐项整理印花税、过户费、监管费、经手费。每项记录稳定代码、适用侧、计费基础、费率、最低额、生效起止、来源 URL/文号/摘要及历史可用时间依据。缺少最低额依据时保留未知，不写成 `none`；缺少某项时不写成零。仅证明候选窗口内的适用规则和实际变更，不将完整市场矩阵或所有历史审计链引入本切片。

已核实的印花税、经手费在 2023-08-28 发生变化，因此保留切换前后分段。监管费先确认候选窗口延续性；过户费先补正式依据和计费说明。本地规则数据随源码维护，只有取得并核对的内容进入来源表。第一份可审阅产物是该窗口四项费用的来源对账表，而不是一份填满默认值的运行时配置。

### 2. 在现有费用能力上补区间与来源

已读代码表明 `FrozenExecutionModelFees` 已有五项费用：佣金、印花税、过户费、监管费、经手费，支持 `charged`、`includedInCommission`、`notApplicable`，并已有 Decimal 计算入口。实施优先复用现有计算能力，集中补来源映射和有效期选择。

法定费率与佣金研究参数分别记录来源，不把客户佣金标为官方历史事实。佣金配置必须表达是否含经手费/监管费；含规费时避免重复加收。计费基数使用成交价与成交股数形成的成交额。计算结果保存分项金额，便于核对总费用和买卖净现金。

现有引擎固定按逐笔分项、四舍五入到分处理。此项是当前模型实现，尚未证明与所有历史官方计费口径一致：收费来源补齐后先核对，匹配则复用；不匹配则在 T2 中明确扩展所需的舍入/扣收契约。只取得费率不能声称精确还原券商账单。

### 4. 验证顺序与关键断言

1. 来源对账：先核对四项项目是否齐全、适用身份、生效日、最低额和必要舍入依据；来源未齐时停止该项准入。
2. 契约与领域定向测试：切换前后买入/卖出、非收费侧、最低额、最低额附近舍入、含规费佣金去重、分段缺口/重叠和未来事实。
3. DSA/Server 定向集成：真实来源表解析及 `missingInputs`，实际选中版本与 Snapshot 内容对应。
4. 冻结/重放：修改当前来源库后重放旧 Snapshot，分项费用和结果 checksum 保持一致。
5. 局部验证、包级检查、仓库门禁通过后，再执行独立目标运行态验收；本次讨论没有执行这些代码或运行态检查。

### 5. 收费数据从哪里取得、怎样补齐

核心办法是从收费制度的发布机关取得正文和附件，整理成可校验的本地历史规则数据集。BaoStock 等行情接口继续提供价格、交易日与既有状态字段；收费规则采用独立来源。目前没有取得可以直接返回完整历史收费的已接入 API，因此本切片采用有界、人工核对的规则整理流程。

#### 5.1 印花税：税务部门的法律正文与调整公告

具体入口是[上海市税务局公布的《印花税法》](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202106/t458595.html)、[官方法律文本及附表](https://www.hengqin.gov.cn/lab/flfg/fl/content/post_3517835.html)，以及[财政部、税务总局 2023 年第 39 号公告](https://shanxi.chinatax.gov.cn/web/detail/sx-11400-545-1780448)。前两项核对税率、卖侧、成交金额基础和法律生效日；第 39 号公告核对减半执行日。

候选窗口的费率可以分成两段：08-25 卖侧 `0.001`，08-28、29 卖侧 `0.0005`。买侧依明确的征税对象规定处理。公告的「减半」必须与法律基准组合，不能只下载公告就把完整计税依据算作取得。

还要查适用于 2023 的计税与扣缴细节。税务部门的[2022 年制度变化说明](https://liaoning.chinatax.gov.cn/art/2022/6/30/art_1187_84335.html)提示旧的不满一角免税和尾数处理规定已删除；本次只读到搜索索引摘要，正文打开失败，该材料尚未作为合格计费输入。下一步沿《印花税法》及同期财政部、税务总局征管文件核对，不复用已废止的尾数规则，也不把税款按周解缴等同于回测现金延后扣除。

#### 5.2 经手费：交易所的收费通知与完整指引

入口是[上证发〔2023〕136号](https://www.sse.com.cn/lawandrules/sselawsrules/repeal/rules/c/c_20230818_10776219.shtml)及[上证发〔2023〕137号完整收费指引](https://www.sse.com.cn/lawandrules/sselawsrules2025/charge/c/c_20250610_10781461.shtml)。136 号正文说明从 2023-08-28 起，A 股经手费由成交额 `0.00487%` 双向收取调整为 `0.00341%` 双向；规范化后分别是 `0.0000487` 和 `0.0000341`。137 号附件用于核对普通竞价的适用项目与免收/其他业务条件，原字节已封存。

普通竞价、协议转让和大宗交易分开核对；协议转让的最低额或大宗优惠不移入本候选场景。当前页面标记失效表示它已被后续制度替代，仍可用于证明相应历史区间。向更早年份扩展时再取得目标起点之前的有效版本及窗口内全部调整。

#### 5.3 监管费：发改委/财政部的费率依据与交易所执行材料

本次已实际读到[发改价格规〔2018〕917号](https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/201806/t20180627_960950_ext.html)：对上海、深圳证券交易所按股票交易额 `0.02‰` 收取证券业务监管费，业务监管费标准自 2018-01-01 执行；规范化费率为 `0.00002`。这比仅依据 2012 年通知更接近候选窗口。

继续组合[上交所/中国结算 2012 年执行通知](https://www.sse.com.cn/lawandrules/guide/other/c/c_20230116_5312163.shtml)、[发改价格〔2021〕1947号](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202201/t20220107_1311590_ext.html)及[上交所 2023 年业务指南规则目录](https://www.sse.com.cn/lawandrules/ma/c/10648768/files/b4497849b02e40179546f025dcbc9b0e.pdf)，核对规则身份和候选窗口延续性。2021 年文件主要涉及机构监管费恢复和北交所适用；机构监管费与股票交易业务监管费必须分开。2023 年目录列有该 2012 年执行通知，是历史适用性的交叉材料，目录本身不提供逐笔计费细节。

还需区分证监会向交易所征收的制度费率、交易环节代收与客户佣金是否包含规费。将「对交易所收取」机械转成「每个客户额外再付一笔」会重复计算；最终收费组合按已明确的佣金处理方式确定。

#### 5.4 过户费：中国结算的历史通知与对应收费指南

第一入口仍是中国结算《关于降低股票交易过户费收费标准的通知》的[官方地址](https://www.chinaclear.cn/zdjs/gszb/202204/f89e788c65a241e88e7f0d0348de586f.shtml)。此前实际请求重定向维护页，本次没有把重复请求计作进展。

本次搜索取得[中国结算官方大事记](https://m.chinaclear.cn/zdjs/dsj/about_dsj.shtml)线索，记载 2022-04-28 发布通知、总体下调 50%；[上海市金融管理部门刊载的报道](https://jrj.sh.gov.cn/SCDT197/20220429/f715759a877b4158812eb6df70ccb49e.html)给出 2022-04-29 生效及沪深 A 股从成交额 `0.02‰` 双向调整到 `0.01‰` 双向。这两项目前作为定位和交叉核对线索，报道不是收费通知原件；不会仅凭它们将最低额、舍入和完整适用性标为已取得。

获取顺序是：官方收费通知正文/附件 → 中国结算官方历史收费表或同期业务指南 → 交易所、财政/监管机关公开的同文归档。找不到原站时可以用具有清晰文号、附件和时间来源的官方归档，不要求只能从发布机关当前在线地址取得；需要核对它是否确实保存原文件。券商转载和新闻报道可用于定位与对账，不能独立补出文件未载明的计费条件。原文与条件取得后再确认候选窗口适用性；暂不把候选 `0.00001` 写入合格运行时数据。

#### 5.5 最低额、舍入和佣金：分别落实依据

四项法定费用逐项标记最低额、扣收粒度、金额精度和舍入来源，不以「公告没写」推定没有最低额。先查财政/税务征管文件、中国结算业务指南和交易所收费细则，再核对现有引擎的逐笔分项、四舍五入到分模型能否复用。未明确时记录未知；若采用研究计算假设，必须单独披露并与历史事实区分，不能将它用于声称完整历史计费已验证。

佣金继续采用用户明确的研究参数：费率、最低额、是否含经手费/监管费。需要核对实际账户时可另使用用户已有的券商收费说明或交割单；本 Spec 不要求取得某客户历史佣金协议。交割单可以验证选定交易的计算结果，但它不能独立证明所有日期和交易场景的统一规则。

#### 5.6 从文件整理成数据的具体操作

1. 固定上述候选窗口及业务身份，建立四项费用的来源清单；每项先列已知字段和未知字段。
2. 取得允许用于本人研究的 HTML/PDF/DOCX 正文或附件，记录来源 URL、文号、发布日、生效日、取得时刻和 SHA-256。PDF/DOCX 先程序提取，扫描页进行原页核对。保存足以重验本窗口事实的原件，不扩大为所有历史公告的审计归档项目。
3. 将核对后的字段整理成规则记录：市场/资产/业务类型、费用代码、币种、收费侧、计费基础、费率、最低额、必要舍入/扣收方式、有效区间及来源引用。来源发布日期只有日期精度时保留精度，并明确保守的可用时间推导，不编造精确历史时刻。
4. 确定窗口起点有效的基准规则，再收集窗口内变更。把所有变更日期取并集形成整体分段：本候选至少在 08-28 切换；过户费和监管费若窗口内未变则保留自己的有效依据。明确区分原规则生效区间和本次核验覆盖区间，核验到 08-29 不表示规则在次日失效。
5. 自动检查四项项目完整、区间覆盖、无重叠、身份匹配、费率单位正确、最低额/舍入可表达和历史可用时间。审核通过的数据才进入 DSA 规则来源；未知项返回具体缺失原因。
6. 用切换前后各一笔买入、卖出及最低额/舍入边界手算预期值，与现有引擎分项金额、总费用、净现金对账。若用户提供交割单，再在相同佣金配置和成交条件下作独立核对。
7. 本地规则表及其内容摘要按版本维护，Server 冻结实际选中记录与来源版本；增加或修正当前规则表时不重写历史 Snapshot。扩大市场或日期区间时，先补新的基准/变更和适用性证据，再声明覆盖。

本次补查扩大了监管费官方依据和过户费取得线索；没有完成收费准入或代码实施。当前最具体的下一产物是四项收费来源对账表：印花税/经手费填入已核事实；监管费补 2018、2021 与 2023 执行材料的对账；过户费补通知原件及计费说明；最低额和舍入单独保留待证字段。
