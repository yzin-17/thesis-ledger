## 优先级与执行规则

先修资金、风险和回测正确性，再推进数据基础与最小研究链，之后补研究闭环，最后评估条件性增强。P0～P3 是排期层级；缺陷严重程度与任务是否已具备执行条件分别判断。

执行时按有效授权、已满足的依赖、排期和写集选择下一叶。外部条件未变时不重复请求，不通过改路由、购买权限或降低门槛解阻塞。各任务已有数据保护、调用次数和费用边界继续有效。
