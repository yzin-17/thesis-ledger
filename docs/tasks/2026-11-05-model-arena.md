## 当前状态与接续

比赛已接入按身份创建、读取、启动、暂停和结束。生产路径按收盘日历调度，先在一个事务内校验所有参赛者及全场的请求、令牌与费用额度。隔离 PostgreSQL 与 Redis 验证单方不足、合计不足、定价未知、并发恰好足额，以及中途回滚后重试。费用单位为预算币种的百万分之一。

两名受控模型读取同一份封存材料，分别输出目标仓位和观望。隔离 PostgreSQL 验证并发领取只发两次、按已知用量退还剩余额度、下一交易日开盘价 12 元买入 41 股、剩余现金 508 元。强制成交事务中断再重试，开盘证据仅取一次，成交与扣款各发生一次。成交前后核对既有交易、持仓及账本事件条数。按身份和比赛读取指定轮次可查看决策、引用与成交，跨身份／跨比赛读取被拒绝。桌面策略中心和移动研究下的策略页已有比赛、轮次及比较入口。两端可从合格模型及目录标的创建草稿，也可复制自选分组。用户启动比赛后由后台调度。标的日线可选择比赛与模型，按模拟成交点进入相应轮次。实际浏览器与移动宿主仍待验收。

可复跑入口为 `ARENA_WITH_REDIS=1 node scripts/test-journal-review-postgres.mjs test/model-arena/schedule-queue.integration.test.ts test/model-arena/admission-postgres.integration.test.ts test/model-arena/decisions-postgres.integration.test.ts test/watchlist/storage-postgres.integration.test.ts test/watchlist/http-postgres.integration.test.ts`。第 43 次迁移下五文件十例通过。成交纯规则另有四例。市场执行目前只对具备完整交易规则与开盘事实的境内股票生成成交，其他样本保留证据不足原因。真实模型、正费用和真实前向样本尚未验收。

收盘估值按轮次保存，整轮额度不足时亦保存每个模型的收盘持仓。比较接口覆盖同区间净值、收益、回撤、换手、费用、现金和等权基准；来源或公司行动口径缺失时，保留不可算状态。跨周隔离样本用周五决策、周一成交和未开轮、周二单方输出无效对账；两模型有效决策为 1/1、0/1，买入 20 股的模型期末净值 1,039 元，交易费 1 元，等权基准 1,197 元。现金与份额仅在比赛模拟账中变化。

定向复跑入口另见 `apps/server/test/model-arena/performance.test.ts`、`apps/server/test/model-arena/cross-week-postgres.integration.test.ts` 和 `packages/api-client/test/arena-setup.test.ts`。竞技场与周报队列均由同一维护脚本准备真实隔离 Redis；客户端测试使用受控响应。在隔离库新增验证：队列查询中断保留待投状态，租约耗尽收敛失败；模拟模型派发后暂停、恢复结算时先记未知，迟到回执可对账并退还已知未用额度，重复领取不产生第二次请求或成交。目标 Worker 故障注入和真实连续交易日仍开放。
