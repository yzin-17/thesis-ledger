- 产品范围、交互语义和验收标准以对应 Spec 为准；本文件只跟踪实施拆分、状态和验证证据。

- 行情不完整或任务失败时保留 partial、缺失标的和失败原因，不伪造完整收益数据。
- 只有实现完成且对应验证通过后才能勾选任务；真实定时任务运行验收必须单独记录。
