# V0.9：自动化与日报

> 阶段目标：让系统在用户不打开 App 时自动采集、扫描、落库、报告和通知。

- [x] T233：定义 Automation Job 模型
  - 涉及范围：包含 jobType、schedule、timezone、enabled、lastRun、nextRun、retryPolicy。
  - 完成条件：任务配置可持久化和启停。
  - 验证方式：创建日报/同步两个 job 并查询 nextRun。

- [x] T234：实现 Scheduler
  - 涉及范围：支持 cron、交易日相对时间等基础调度，使用统一 timezone。
  - 完成条件：Server 重启后 schedule 可恢复。
  - 验证方式：安排测试 job 并重启验证。

- [x] T235：实现 Job 幂等与锁
  - 涉及范围：同一时间窗口同一 job 只运行一次，支持分布式锁。
  - 完成条件：多实例不会重复执行收盘同步或日报。
  - 验证方式：并发触发两次，只有一个执行。

- [x] T236：实现 Job Retry/Backoff
  - 涉及范围：按错误类型和 retryPolicy 重试，永久错误进入 failed。
  - 完成条件：重试次数和错误可查询。
  - 验证方式：模拟两次失败后成功。

- [x] T237：实现 Job History
  - 涉及范围：记录 start/end/status/traceId/result summary/error。
  - 完成条件：自动化故障可审计。
  - 验证方式：执行成功/失败任务各一条并查询。

- [x] T238：实现交易日感知调度
  - 涉及范围：自动化使用统一 Trading Calendar，休市日跳过市场任务。
  - 完成条件：周末/节假日不执行盘中扫描。
  - 验证方式：模拟交易日和休市日。

- [x] T239：实现盘前持仓事件检查
  - 涉及范围：拉取当前持仓相关公告、财报、分红、停复牌等事件。
  - 完成条件：只关注持仓/自选，不全市场泛滥。
  - 验证方式：用固定公告 fixture 生成盘前列表。

- [x] T240：实现盘前风险预览
  - 涉及范围：基于昨日收盘或最新可用数据运行静态风险检查。
  - 完成条件：报告标记数据时点，不冒充盘中实时。
  - 验证方式：休市日/盘前执行并检查 timestamp。

- [x] T241：实现盘前 Digest
  - 涉及范围：聚合持仓事件、风险预览和当天关注项，可发飞书。
  - 完成条件：低优先级信息以一条摘要发送。
  - 验证方式：生成并发送测试 Digest。

- [x] T242：实现开盘或竞价扫描入口
  - 涉及范围：在可用数据范围内执行开盘价格/异常扫描，不依赖 L2。
  - 完成条件：功能明确标记数据限制。
  - 验证方式：Mock 开盘行情触发价格事件。

- [x] T243：实现盘中 Risk Scan
  - 涉及范围：按配置周期批量 Quote→Portfolio→Risk Evaluation。
  - 完成条件：批量任务考虑 Provider 限流和数据 completeness。
  - 验证方式：模拟 50 持仓扫描，确认不重复刷通知。

- [x] T244：实现 Data Health Automation
  - 涉及范围：盘中监控 Provider 健康、陈旧行情和落库异常。
  - 完成条件：严重数据问题可生成 system alert。
  - 验证方式：停止主 Provider 验证告警。

- [x] T245：实现收盘 Daily Bar Sync
  - 涉及范围：交易日收盘后增量同步持仓、自选、策略需要的日线。
  - 完成条件：同步完成后运行 completeness 检查。
  - 验证方式：模拟一个交易日收盘执行。

- [x] T246：实现收盘 Portfolio Snapshot
  - 涉及范围：行情同步后生成当日 Snapshot 和 Performance。
  - 完成条件：同一日重复 job 幂等。
  - 验证方式：执行两次行数不增加且值一致。

- [x] T247：实现 Daily Risk Summary
  - 涉及范围：汇总当日触发规则、仍在风险、已恢复风险和通知情况。
  - 完成条件：报告可按账户聚合。
  - 验证方式：使用一日事件 fixture 核对。

- [x] T248：实现投资日报
  - 涉及范围：包含总资产、今日/累计收益、benchmark、贡献/拖累、风险、筹码变化、重要事件、AI 总结。
  - 完成条件：AI 总结仅解释确定性数据。
  - 验证方式：固定日数据生成报告并人工核对。

- [x] T249：实现 Weekly Performance Review Job
  - 涉及范围：每周生成收益、回撤、风险、交易和行为摘要。
  - 完成条件：使用明确周区间和交易日。
  - 验证方式：固定周数据生成。

- [x] T250：实现 Weekly Strategy Review Job
  - 涉及范围：汇总策略最近信号、回测变化和实际执行关联，不自动修改策略。
  - 完成条件：策略建议只能进入 research/decision log。
  - 验证方式：生成一份包含策略条目的周报。

- [x] T251：实现 Automation Settings UI
  - 涉及范围：可启停盘前、盘中、收盘、日报、周报，并查看 schedule/history。
  - 完成条件：修改后 scheduler 实时生效或明确需重载。
  - 验证方式：人工启停一个 job 验证。

- [x] T252：建立 Automation E2E
  - 涉及范围：模拟完整交易日：盘前→盘中→收盘→日报。
  - 完成条件：所有阶段按顺序完成且重复运行幂等。
  - 验证方式：使用加速时钟或手动触发跑完整 E2E。

- [x] T253：更新自动化运维文档
  - 涉及范围：说明调度、timezone、交易日、重试、幂等、失败排查和通知。
  - 完成条件：用户能定位“为什么今天没发日报”。
  - 验证方式：由未参与实现者按文档排查一个失败 job。

- [x] T254：完成 V0.9 一致性 Review
  - 涉及范围：检查自动化与手动 API 使用同一 Market/Risk/Portfolio/Report 逻辑。
  - 完成条件：不存在独立复制的一套盘中风控算法。
  - 验证方式：架构 Review + E2E + Spec checklist。
