## 逐页盘点

| 页面 | 页面级入口及覆盖范围 | 保留的独立操作 |
| --- | --- | --- |
| 投资组合 | 已有顶部入口，账户、估值、盈亏和当前交易；复用此前修复并回归 | 当前分段错误重试、行情弹窗交互 |
| 账户数据 | 新增顶部入口，当前估值、账本、现金定期入账、基金定投及已打开审计查询 | 成交/现金录入、对账候选读取、编辑与局部失败恢复 |
| 收益分析 | 新增顶部入口，活动历史、序列、汇总、分层、目标与配置计算 | 目标保存、失败时重新获取汇率或局部恢复 |
| 风险中心 | 顶部入口补齐当前组合、通知路由、策略风险应用及策略说明 | 风险扫描、规则测试、规则编辑、审计失败重试 |
| 策略中心 | 顶部入口覆盖活动策略根查询与作者工作台读取，包含当前任务/任务详情、净值回测、实验/比较 | 新建、启动、取消、再次运行、重试执行与生成操作 |
| 投资复盘 | 新增顶部入口，账户、当前候选、对象、历史快照及已有 AI 任务状态读取 | 手动计算周期复盘、JSON 分析、生成解读、筛选与错误恢复 |
| 研究助手 | 普通列表刷新移至页头，覆盖当前报告读取和服务能力状态；列表不再重复提供普通刷新 | 新建研究、读取失败重试、分页、过滤及详情操作 |
| 数据与自动化 | 已有顶部入口完整覆盖配置、路由设置、健康历史、自动化与诊断；标签统一为中文 | 测试连接、模型查询、运行任务及编辑操作 |
| 市场数据 | 顶部入口覆盖市场控制/来源/目录和已提交的证券资料；证券资料缓存键纳入 Market 范围 | 同步目录、提交证券查询、资料/行情弹窗和局部错误重试 |

当前路由以 `apps/desktop/src/app/routes.tsx` 与策略中心嵌套路由为准。旧复盘页面与重定向入口不作为重复刷新入口迁移对象。错误后的重试、独立 Sheet/Dialog 的读取恢复与具有执行意义的按钮均保留，页面级刷新不调用这些 mutation。

## 实现与验证

`features/shared/usePageRefresh.ts` 只使用 TanStack Query 的过滤、计数与 `refetchQueries`，统一选择活动查询；各页面声明范围。共享层不 import 业务 feature 或 API 客户端，对应约束已写入 `scripts/check-boundaries.mjs`。重叠范围由单次缓存筛选去重，Query 自身继续拥有账户、模式、筛选、分页、错误与加载状态。

- 新增 `page-refresh.ui.test.tsx`，3 项真实 QueryClient 测试通过：范围与参数保留；停用/未展示查询不执行；重叠范围不重复；慢查询未完成时保持刷新；失败结束状态并可恢复。
- 页面定向回归：策略、风险恢复、市场数据、数据与自动化、收益账户范围、目标保存、账户写入恢复、复盘、研究隔离与研究账户模式均通过。研究列表与自动化页的现有入口断言已同步维护。
- Desktop 构建通过；任务相关 ESLint、模块边界及 `git diff --check` 通过。改动页面均未超过文件尺寸阈值。
- Node 26 的原生 Web Storage 与 jsdom 环境相互影响；回归使用 `NODE_OPTIONS=--no-experimental-webstorage`，由 jsdom 提供测试存储，不修改应用存储行为。

## 全量测试边界

最终运行：`NODE_OPTIONS=--no-experimental-webstorage pnpm exec vitest run --reporter=json --outputFile=/tmp/desktop-refresh-full.json`。

结果为 **1178 / 1180 项通过，2 项失败**，不能声称桌面全量测试通过：

1. `ui-contract.test.tsx` 的统一日期控件断言：本次未修改的 `MarketReferenceSheet.tsx` 中两个原生日期 Input 仍触发门禁；该问题在本会话前序局部验证中已经出现。
2. `NewResearchSheet.test.tsx` 的策略版本回显用例在全量运行失败；随后独立运行该文件的 4 项全部通过。本次没有修改实体选择器，不把独立通过等同于全量通过，也不宣称已修复该不稳定表现。

这两项未被移入 TODO 或改写测试以降低标准。机器报告保留在 `/tmp/desktop-refresh-full.json`，完整输出为 `/tmp/desktop-refresh-full-output.log`。本次刷新行为的相关验收单独成立，全量门禁仍保持未通过结论。

## 本地真实浏览器

使用 Desktop 构建产物的 Vite preview（`127.0.0.1:4173`）连接现有真实本地 API。检查九个主页面，并补查策略任务列表、实验列表、已有回测任务详情、已有实验详情与风险“策略应用”标签。

- 各页面页头均只有一个普通刷新入口；刷新结束后恢复按钮，旧列表的普通刷新没有并存。
- 策略任务详情实际重读 `/backtests/runs/:id`；实验详情实际重读实验及比较接口；策略任务和实验列表分别重读当前列表接口。
- 风险“策略应用”标签实际重读风险基础数据、当前组合、风险应用及策略说明；未打开标签的查询不被新建。
- 收益页包含历史、序列、汇总、分层、目标及 `/performance/allocation`。后者虽然使用 POST，但已检查 Server 的 `PerformanceAnalysisService.allocate` 为纯配置计算，不保存配置或发起交易。
- 数据与自动化页独立复核捕获 8 个 GET，全部返回 200，刷新结束。首轮巡检在页面初始化与点击切换时未取得完整记录，以独立复核及后续嵌套巡检的完整结果为准。
- 实际请求未出现新建研究、创建/运行回测、风险扫描、目录同步、通知发送或保存操作。页面运行异常记录为空；已有数据不足或接口失败仍通过各页面自身反馈展示，不据此宣称所有来源健康。
- 账户、收益、复盘和研究列表的 390px 布局没有横向溢出，页头仍只有一个刷新入口；桌面截图已检查。

巡检材料位于 `/tmp/desktop-refresh-browser/`：主巡检 `report.json`、嵌套页面 `nested-report.json`、回测详情 `job-detail-report.json` 及各页截图。临时 preview 验证后停止。本次未执行 Docker 更新、安装包更新、远程 CI、提交或发布。
