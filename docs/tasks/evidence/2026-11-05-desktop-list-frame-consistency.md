# 桌面列表边框一致性验收记录

日期：2026-11-05。范围为 Desktop 源码及本地生产构建预览。

## 统一规则与边界

独立表格、账户/现金/定投操作列表使用一个整体外框和内部行分隔。已有同组卡片边框时，内部只保留滚动与行分隔。新闻、公告、资料和简单历史记录使用留白及轻分隔；需要独立编辑、选择或展示复杂证据的对象保留逐对象卡片。使用现有 `rounded-md`、`border-border`，不新增样式选择器或覆盖规则。

菜单选项、输入控件、正文项目符号、图表、指标、告警及字段说明不是本次业务列表。组合指标继续保持原样，走势图保留原有外框。原先确认的文字/状态靠左、数字靠右、操作靠右规则继续有效。

## 表格完整盘点

业务源码共有 32 处表格声明：22 处原生 `table` 与 10 处共享 `Table`。抽取组件在运行时可生成多张表，因此声明数量不同于页面实例数量。

| 所有者 | 表格声明与处理 |
| --- | --- |
| 数据与自动化 | `ProviderSettingsSections` 四张提供方、健康、自动化和任务历史表格复用带框容器。 |
| 投资组合 | `PortfolioOverview` 持仓、`PortfolioTradeView` 交易、`PortfolioPositionObservation` 快照表格带框；`PortfolioTradeDetailSections` 的复用明细表分别承担独立子表边界。 |
| 收益分析 | `PerformanceTrendSection` 历史表格带框；`PerformanceSections` 配置区域包含状态、滚动表格和辅助内容，由一个显式复合外框统一承担边界，内部不加框。 |
| 账户数据 | `AccountDataSections` 账本表格带框；详情、审计与导入审核不改变事实读取和写入协议。 |
| 风险中心 | `RiskSections` 两张规则/事件表格带框。 |
| 策略常规列表 | `StrategySections` 两张表、`StrategyLibraryPages` 策略与版本两张表、`StrategyBacktestJobsPage` 任务表、`StrategyExperimentListPage` 实验表带框。 |
| 策略详情 | `StrategyBacktestDetailSections` 的复用明细表分别带框；`StrategyBacktestEquityDetails` 的展开区域已有整体外框，内部 `TableContainer frame="plain"`；`StrategyExperimentDetailPage` 比较区域由 Card 承担外框，内部 plain。 |
| 净值回测 | `NavBacktestJobs` 一张表与 `NavBacktestResult` 两张表各自已有 Card，均显式 plain。 |
| 市场数据 | `MarketReferenceResult` 独立参考表格带框；`SecurityStaticInfoPanel` 资料属性表位于同组 Card 内，显式 plain。 |
| 研究助手 | `AiRunList` 的桌面表格和窄屏行共享原有结果外框，桌面表格显式 plain，不再叠框。 |
| 投资复盘 | `JournalMetricTable` 一张、`JournalSourceFacts` 两张、`JournalCandidateBrowser` 一张表格是工作区内独立子表，使用带框默认值。 |

共享 `TableContainer` 拥有 outlined/plain 模式，默认 outlined；共享 `Table` 继续承载 table 属性，并组合相同容器。原生表格复用该容器。复合收益区域有实际边框并声明所有权。新增契约检查遍历所有原生业务表格，要求共享容器或真实复合所有者，不使用按文件忽略清单。

Table 的 HTML `frame` 属性与新语义同名，组件类型显式排除原生属性，避免出现类型交叉冲突或把该语义泄漏到原生 table。共享单元格统一左右内边距；移除旧全局“首列内边距为零”覆盖，避免有框表格首列贴边。超限 `PerformanceSections.tsx` 保持 929 行，未增长或调整阈值。

## 其他列表族盘点

| 列表族与入口 | 最终处理及原因 |
| --- | --- |
| 已有账户、持仓快照操作 | 一个组外框与行分隔。已有账户由原子类表达原字号、行布局及操作，删除仅供该列表使用的旧 `.account-list` 样式；保留 `.edit-list` 规则。 |
| 现金结算、现金账本、定期入金 | 独立列表整体带框与行分隔；复合计划区域只在外围加框，内部分组用分隔线。多指标现金概览保持原样。 |
| 基金待确认、当前计划、已结束、已跳过 | 有记录时按组带框；历史折叠区域承担外框，展开内容只用顶部/行分隔；零待确认保留一行说明，首次读取未知不产生空边框。计划定位、自动展开、版本操作和确认流程保持。 |
| 标的目录、市场提供方、路由配置 | 已有设置 Card 承担边界，内部只有行分隔，移除目录的额外上下边线。权限、凭证表单和功能选择保持原模式。 |
| 风险规则工作台与策略风险应用 | 具有独立选择、编辑与操作的对象卡片保留边框，统一圆角；选中环与状态色保持。 |
| 导入审核行、对账候选、审计链 | 每个对象有独立编辑/选择/审计上下文，保留逐对象卡片，统一圆角和边框；相应独立空态采用相同边界。 |
| 新闻、公告、关联资料 | 使用留白和轻分隔，取消公告/资料逐条小框；新闻空态不单独套框。正文中的关联范围项目继续按正文列表展示。 |
| 复盘候选旧记录、快照历史 | 外部 Card 或区域拥有边界；旧记录取消逐条框，快照历史为无框操作行加轻分隔，保留选择和分页。 |
| 复盘交易事实、证据状态、研究观察、来源链、审计和研究报告对象 | 外部 Card 或独立复杂证据对象保留；来源链引用的对象边框统一圆角。正文结论、证据条目和引用链接继续按其内容层级展示，不将正文列表做成操作表格。 |
| 策略实验记录、模型尝试、候选比较和采纳差异 | 实验记录所在 Card 内改为行分隔；模型尝试、独立候选和差异对象有独立语义，保留其既有卡片。 |
| 草稿/AI 任务选择按钮、账户/标的选择器、参数项、披露说明 | 属于导航、选择或正文内容，保留现有控件与披露层级。未把这些入口改为业务列表外框。 |

独立列表的空态和加载骨架与正常区域使用相同边界；已有 Card 内的状态不增加第二层空框。错误沿用明确的 Alert/状态提示。回测任务首次读取未知或失败时只显示对应状态，不再渲染多余空表头；有缓存数据时仍可展示原有记录。

## 浏览器发现与修正

实际实验列表在 768px 出现筛选栏撑出页面、长名称穿入相邻列的问题。筛选栏仅在宽屏组合成一行，实验表格设定合理最小宽度并在容器内滚动；名称截断且保留完整 title，进度和更新时间允许换行。回测任务表同样保留合理最小宽度，避免窄屏挤列。以上均在既有 DOM 与组件上组合原子类，没有新增展示分支。

## 图片与最终复核

沿用现有应用方向，使用 taste app 检查。组合、提供方、最终定投页面的三种宽度均为 0 FAIL；输出的首屏与整页图已查看，另查看交易、来源定位与修正后实验列表的宽窄屏图。

1. 独立多列表格有明确边界，首列保留呼吸空间；文字、金额、状态和操作仍能按列扫描。
2. 同组 Card 内不再叠一层表格或逐行小框，背景、字体和线色沿用应用现有 token。
3. 公告、资料和历史行以轻分隔建立节奏，复杂审核对象保留能说明操作归属的独立边界。
4. 独立列表的成功、空态和加载骨架保持相同外轮廓；失败明确显示错误，未知数量不显示为零。
5. 当前计划与历史计划维持业务分组，折叠后按实际内容收缩，不用空框填充页面。
6. 窄屏表格在自身容器滚动，原有固定操作列保留；实验筛选栏换行，长标题不会挤入下一列。
7. 走势图仍保留外框，组合指标不加框；没有为统一列表改变这些已确认的视觉层级。

保留的整页 WARN 有具体范围：既有英文页头、系统字体回退和辅助小字号未改变；单个已结束计划使画布留白，但内容区域本身收缩。提供方降级提示出现时，既有告警文案触发 4.4:1 对比度 WARN，该状态文字颜色未由本次修改。源码 taste app lint 为 0 FAIL，保留既有代码标识等宽、旧投影和编号等 WARN；未引入新的渐变、投影或图标装饰。
