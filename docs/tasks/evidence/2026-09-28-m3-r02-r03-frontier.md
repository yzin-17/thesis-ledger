独占路径：DSA 新增 `data_provider/sina_index_identity.py`、新增 `tests/test_sina_index_identity.py`；仅修改 `data_provider/akshare_fetcher.py` 的 `get_main_indices` 接缝，旧模糊选择移至明确 helper 后删除，避免扩大存量大文件；主仓新增 `docs/tasks/evidence/2026-09-28-r02-11-index-identity.md`。不改 Manager、MarketAnalyzer、Runtime、manifest 或 Schemas。

依赖满足范围：既有 endpoint、六个身份映射和 native Consumer 均已存在；只实现确定性身份校验，无需新凭据或单位事实。局部验证拟用 `python -m unittest discover -s tests -p 'test_sina_index_identity.py'`，mock SDK，覆盖唯一精确匹配、缺失、近似代码、重复代码、缺代码列及现有输出保持；再对三个独占 Python 文件做现有 lint。真实时点/单位/权限仍是后续 G0-M，不因此关闭 R02.11。

### R02.13-row-selection：指数日线按身份与日期选择最新行

前行为：`TushareFetcher.get_main_indices` 直接认为 `df.iloc[0]` 是最新一天。后行为：对返回行核验 `ts_code` 等于请求、`trade_date` 是严格有效日期且在已请求的五日窗口内；乱序唯一日期行可按日期选最大值，重复日期或错身份拒绝该指数，由现有逐指数异常/空结果处理收敛。不得以本机时间冒充来源收盘时点，不扩大五日窗口、不改变量额转换，不添加实时性标记。

稳定输入为请求 `ts_code/start_date/end_date` 与 index_daily DataFrame；输出为选中的原始一行，再交现有字典映射消费。独占路径：DSA 新增 `data_provider/tushare_index_daily_rows.py`、新增 `tests/test_tushare_index_daily_rows.py`；仅修改 `data_provider/tushare_fetcher.py` 的 `get_main_indices` 行选择；主仓新增 `docs/tasks/evidence/2026-09-28-r02-13-index-row-selection.md`。不改 TushareExactDailyMixin、M24/事件路径或任何共享合同。
