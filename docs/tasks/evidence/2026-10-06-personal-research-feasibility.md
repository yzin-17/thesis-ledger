## 一、结论

**现有数据足以推进个人价格策略研究；真正需要优先处理的是收益口径、分红和交易成本，而不是给所有数据补齐专业级证明。** 本轮完成真实冻结样本对照、新增免费公开样本取数和独立离线计算；不是只列预研计划。

159516 的 68 根日线中，HiThink 与腾讯前复权的 272 个 OHLC 值完全相同。三种预先选择的策略换源后，信号、成交日期及收益／回撤均一致。腾讯前后复权在该窗口的策略累计收益最大差约 0.052 个百分点，可以作为本样本中近似影响较小的依据，不应继续为这类微小差异阻塞普通研究。

但 510300 跨分红窗口中，漏掉已知现金分红会使累计收益少计约 1.621 个百分点；供应商前／后复权价格比值也没有与原始价格＋现金分红完全一致。不能把“前复权收益”“后复权收益”和“现金收益”无条件当成同一个指标。

**本轮建议实施的方向是复用已有研究链路、保留简单的来源／口径／假设说明，按实际依赖限制单项功能。** 不新增研究／审计两套系统，不创建复杂质量评级平台，不因缺少严格 PIT 或异地灾备停掉普通回测。本报告不自行更改现行 Spec 的验收范围，也不将原五项高级验收勾选为通过。

仅对现有腾讯公开能力做六次无凭据、无付费请求：`newfqkline/get` 的 510300 不复权／前复权／后复权各一次，基础 Quote 双标的一次，以及旧 `fqkline/get` 的前／后复权各一次用于解释异常差异。六次均 HTTP 200，没有失败重试或遍历新的收费来源。

### 2.3 独立策略计算

采用标准库 Decimal、40 位精度的独立离线模拟器，不调用 Server／Worker 或产品回测引擎。初始模拟资金 100000，入场使用当时权益的 50%，连续归一化数量；日线收盘形成信号，下一根已有 Bar 开盘成交，末日未成交委托不补造未来成交，期末不强制平仓，以最后收盘价估值。

策略为原验收使用的“空仓时收盘高于开盘入场，持仓后离场”，另加 SMA5 高于 SMA10 和收盘高于五日前收盘两种预选相对规则。未做参数搜索、收益优化或样本外优劣宣称。两种新增策略与原验收策略共用同一独立模拟规则；本轮数值不是产品引擎重新验收结果。

基线费用为零；成本敏感性另外使用单边 5／10 基点的成交金额比例扣费，代表人为设置的综合摩擦情景，不是历史真实佣金或滑点标准。没有将其写入项目收费规则或其他对话负责的文件。

## 四、现金分红与本地派生的真实验证

### 4.1 510300 分红样本

使用[基金管理人 2023-01-09 分红公告](https://static.cninfo.com.cn/finalpage/2023-01-09/1215552905.PDF)：每 10 份现金 0.6400 元，即每份 0.064 元；登记日 2023-01-13，除息日 2023-01-16，现金发放日 2023-01-19。公告内容与此前本地证据一致。本轮读取了公开 PDF 解析正文，页面截图请求超时，未据此声称完成页面图像复核；公告的当前可读性不证明历史同期捕获。

假设 2023-01-03 收盘买入一份，持有至 2023-02-01 收盘，不计成本、税费及其他未纳入事件：

| 计算口径 | 累计收益 |
| --- | ---: |
| 未复权价格比值，不计分红 | 6.102811% |
| 未复权价格＋已知现金分红，现金不再投资 | 7.723474% |
| 供应商前复权价格比值 | 8.460472% |
| 供应商后复权价格比值 | 6.790865% |

漏掉这次已知分红，收益少计 1.620663 个百分点。前复权价格收益比“原始价格＋现金”高 0.736997 个百分点，后复权价格收益低 0.932609 个百分点。旧、新腾讯端点返回的该窗口前／后复权 OHLC 分别完全一致，差异不是简单换端点即可消除。

**这里不能声称“后复权天然等于现金再投资收益”，也不能把差异一概当舍入。** 本轮未完整解释供应商后复权算法、基准和历史修订，后复权作为独立序列研究可继续，但该窗口的精确现金收益应采用原始价格与事件计算。该结论不要求整个数据源停用。

人为比较“除息日收盘立刻再投”和“发放日收盘再投”，收益分别为 7.741860% 和 7.735947%，仅差约 0.005913 个百分点。前者只是敏感性假设，不代表资金在除息日即可使用。本样本说明遗漏整个分红比数日再投资时点近似更重要，不能外推到高杠杆或其他现金约束策略。

### 4.2 分别取得的原始行情＋事件能够组合计算

这 17 日中，原始价格减腾讯前复权价格的差额在除息前为 0.344，除息日起为 0.280，变化恰为公告的每份 0.064 元。

以研究窗口末端为锚，本地进行等差现金分红调整：除息日前 OHLC 减 0.064，除息日及以后保持原始 OHLC。把腾讯前复权全段加 0.280 对齐末端基准后，**17 日共 68 个 OHLC 值全部一致，最大绝对差为 0.000。**

这证明“原始行情＋独立事件响应＋明确基准”的小窗口计算方案可行，不需要价格和事件在同一个 HTTP 响应中返回。但它只证明本样本等差调整，不是上市以来完整因子、乘法因子、严格 PIT 或实盘现金记账已经验收。

### 4.3 现有代码边界，纠正此前理解

只读检查 `apps/server/src/market/market-derived-raw-window-v3.ts`：`rawResponseHash` 要求转换资料绑定具体原始行情窗口，而不是要求因子和价格由同一个 HTTP 响应提供。转换对象本来就是单独传入。此前将这一约束概括为“必须同一个 HTTP 响应”不准确，**不应为放宽限制而删除数据集身份绑定**。

`apps/server/src/market/market-derived-series-v3.ts` 只接受 `multiplicative-price-factor`，算法是原始价格乘因子再除固定锚点。此次验证的等差分红调整不能塞进该乘法合同。需要本地派生时，应显式增加对应经济模型或先走原始价格＋现金事件路径；不能只关闭校验让两种公式混用。本轮未修改这些文件。
