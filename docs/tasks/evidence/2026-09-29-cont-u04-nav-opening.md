# U04 基金净值首次读取回归修复

## 问题与改动

Desktop 基金详情首次打开时未指定 `include`，请求适配层因此将其识别为日线图表读取，先向仅支持股票/ETF 的 V3 图表计划端点请求口径。计划失败会阻断净值详情读取。

现行详情挂载向请求链传递基金身份，基金首次请求明确包含 `fund-nav` 与 `fund-nav-history`；日线图表继续按原路径校验完整窗口与价格口径。NAV 的分段重试仍只请求对应净值能力。

## 本地验证

- 新增挂载级基金首次请求回归；与适配层测试合计 16 项通过。
- Desktop 全包 509 项、typecheck 与 build 通过；改动的两份生产文件 ESLint 通过，`git diff --check` 通过。
- 三份受影响文件的整文件 Prettier 检查未通过；集成测试文件的 ESLint 仍有本叶未触及的四处 `any` 访问错误。未为本叶扩大写集处理其他区段。

## 验收边界

本地测试只确认基金首次请求不进入图表计划门禁。目标浏览器/Electron、真实 NAV 数据、图表口径切换及完整 U04 行为仍待验收；U04、G-UI、AC15 与 AC19 不勾选。
