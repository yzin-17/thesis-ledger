# R06.18 当前行业资金流榜单本地证据

## 来源合同

当前 DSA 安装版 AKShare 1.18.94 的 `stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")` 请求 EastMoney 板块排名，转出行业名称及 `今日主力净流入-净额`。AKShare [官方板块资金流文档](https://akshare.akfamily.xyz/data/stock/stock.html)的当前输出表将同一净额列记为 `主力净流入-净额`，并说明新板块数值 `-` 会转换为 `NaN`。两个精确列名分别允许，但同表两者并存拒绝；不按“主力/净流入”模糊匹配。官方文档没有给净额金额单位、可靠来源时刻或历史可见性，本轮不推断。

同一安装版与官方文档都表明 `stock_sector_fund_flow_summary(symbol="电源设备", indicator="今日")` 返回**该行业内个股**，表内有股票 `代码`、`名称`，不是跨行业排名。旧适配器把它作为无参候选二，若排名失败会把股票名称放进行业 top/bottom；现已移除这一跨能力回退。R06.19 作为另一个候选能力，仍缺指定行业和当前 Consumer 合同。

## 实施与验证

- 新 `data_provider/eastmoney_industry_fund_flow_rank.py` 校验行业行：名称非空且唯一、无股票 `代码` 列、净额列精确且唯一；官方说明的 `NaN` 金额过滤，比例列不可代替，全部无效则不发布榜单。有效行按金额与名称确定性排序，保留原有 `top`/`bottom` 输出形状。
- `AkshareFundamentalAdapter.get_capital_flow()` 只请求显式今日/行业排名，坏表追加 `capital_sector:invalid_rank_rows`，排名请求失败不再调用指定行业的个股汇总；股票资金流仍独立处理。
- 合成反例覆盖比例列先于净额、个股汇总行、重复行业、全空金额、双净额列及排名请求失败。新测试修前有 7 处失败；修后新测试和相邻请求/研究上下文共 `48 passed`。旧作用域测试首次 6 个子测试仍要求无参行业调用，按本叶新合同更新后唯一重跑通过。
- 新 helper/相关测试完整 `flake8` 初次仅两处续行格式错误，一次修正后通过；旧适配器关键 `E9,F63,F7,F82`、`py_compile`、`git diff --check` 通过。适配器本叶 711→704 行。

没有真实来源请求、目标容器更新或已失败的 DSA 官方全包重试；本地表形状不证明来源金额单位、快照时刻、分页/覆盖、许可或 G0-M。当前研究榜单不能当历史回测证据，R06.18 整体与 R06.19 独立消费仍开放。
