## 写入和读取边界

- 当前基线为十二账户、三份 AI 配置、研究默认修订 2、策略路由修订 162；保护 JSON 为 `f572f9214cad03ba756c032a206931be67c43fb894b170f48082d1e6fef2b325`。
- 专属配置名固定为 `controlled-config-contract-20261021`，创建前必须确认不存在；正常 API 创建，始终 `enabled=false`，地址固定为 `http://127.0.0.1:9/v1`，不承担默认引用。不得运行连接、目录、模型、用途或费用测试。
- 模型为 `controlled-model-a`、`controlled-model-b`。A 研究报告用 `native_schema`，参数优化用 `json_validated`；B 研究报告用 `json_validated`。三个用途分别保留 90000/45000、60000/30000、30000/15000 毫秒首输出/间隔覆盖，均为手动输出策略。A 价格为 USD 0.1/0.2，B 为 CNY 0/0.05；不因此获得生成或费用授权。
- 初始优先级 991，仅通过 Web 改为 992 并普通保存。认证验证只使用两份明确的占位值，检查隐藏、留空保留、取消、确认清除及重新输入；不读取、复制、编辑或发出现有用户 Key。

## 数据保护和收尾

每一阶段绑定计划指纹、固定名称及创建后 ID，核对目标身份、专属配置仍停用、默认未指向它，并只允许本阶段列出的字段变化。原 ProviderConfig 摘要通过 SQL 精确排除唯一自有 ID 后比较；其余全部保护状态不作排除。未测试状态和调用计数必须保持，原账户、事实、旧配置及默认不可被改写。

普通保存沿用兼容合同：`enabled: true` 与省略等义，旧显式用途的 `modeOverridden` 省略与 true 等义；显式 false 仍须区分。仅将这两类表示规范化用于独立比较，保留原始前后快照和初次严格差异；其他模式、覆盖、价格、元数据、密文和范围外状态仍精确比较，不放宽业务行为。

结束时通过正常删除 API 和当前修订清理唯一专属条目，再比较完整保护 JSON。正常新增审计保留，不伪造旧版本或回写旧时间；失败保留具体阶段与回执，不覆盖原配置。Web 恢复原账户页、模拟模式和主题。

这组控制数据不冒充当前用户的历史混合配置或真实有效认证；旧格式读取/序列化沿用 E2 与 AC-29 的对应证据。通过后只关闭实际覆盖的配置/交互条件，真实认证、生成、费用和业务继续暂停。
