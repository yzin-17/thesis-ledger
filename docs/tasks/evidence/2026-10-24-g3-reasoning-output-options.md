# G3 保留推理的结构化输出路径评估

> 本文件保留原因分析与候选方案阶段的事实。后续用户要求选择其他免费模型并切换；本文件提出的原样直连未执行，当前接续见[免费模型切换](2026-10-24-g3-free-model-switch.md)。

## 当前范围

用户要求保留推理并考虑其他处理办法。研究默认仍为 openrouter/free，正式 mode 仍为 native_schema，reasoningEnabled 未保存显式值；此前失败未修改业务配置。V2 关闭，当前剩余 11 次冻结。本轮仅只读核对代码、规格与官方文档，不调用模型或修改业务代码／配置。

## 当前证据支持的判断

- 原生直连的请求体与 G3 失败样本完全一致，HTTP 200／SSE 正常，但标准正文仅 2 字符，推理 24,729 字符；SDK 外已复现正文不足。
- 固定原实际免费模型并关闭推理的一次直连返回有效 V2；这说明存在可用输出路径，但不证明关闭推理是唯一解，也不证明随机路由的所有端点都有相同行为。
- 保留 openrouter/free 默认的正式复验返回端点强制推理、不能关闭；配置没有保存。当前路线按用户要求保留推理，不据此切换研究默认。
- 原直连报告输出 tokens 为 8,414，其中推理 8,411，请求 max_tokens=20000；finish_reason 未留存，无法断言达到总输出预算。仅增大 token 上限目前缺少直接依据。

## 原因定位与证据边界

| 环节 | 已有事实 | 判断 |
| --- | --- | --- |
| HTTP 与 SSE | 同一请求体直连 HTTP 200，2,537 个可解析事件，0 个错误事件，响应读取完成 | 该样本的传输和事件格式正常；不能反推此前未留存的 Provider returned error 响应 |

| SDK 消费与解析 | 原生 HTTP 已绕过 SDK 复现正文不足；当前适配器分别观察 text-delta／reasoning-delta，消费流后读取最终 output | 未发现 SDK 丢失完整正文或混拼推理通道的证据；不能据此保证所有历史失败均为同一原因 |
| 最近一次正式复验 | reasoningEnabled=false 请求被上游以推理强制开启拒绝，业务配置未保存 | 属于参数能力拒绝，未进入 JSON 解析；不是又一次无效 JSON 结果 |

当前已定位到上游标准正文不足，但具体机制尚未闭合：尚不能区分实际模型没有完成最终回答、供应端通道映射、原生结构化约束或预算限制。推理开启与原生结构化输出的组合、端点提前结束均只是待验证假设。一次关闭推理成功不能证明推理本身不受支持，也不能证明必须关闭推理。原直连没有保留正文两个字符的原文，不能声明其精确内容。

本地依据为 apps/server/src/ai/ai-sdk-generation.adapter.ts 的流消费／完成检查，以及 apps/server/src/ai/ai-generation-output.ts 的输出策略与完整 Schema 校验。[OpenRouter 结构化输出说明](https://openrouter.ai/docs/guides/features/structured-outputs)明确严格约束的执行方式随端点而异；参数声明受支持不能替代本次实际正文验收。

## 候选处理：JSON Mode 与原本地验收

[OpenRouter 参数文档](https://openrouter.ai/docs/api_reference/parameters#response-format)支持 response_format.type=json_object，并要求在提示中明确输出 JSON。现有 AiSdkGenerationAdapter 的 json_mode 使用 Output.json，完整输出随后仍调用同一 schema.parse；研究 V2 和业务证据校验保持。

只有结束证据支持进一步对照且用户确认后，才考虑将诊断请求的 response_format 改为 json_object；其余材料、输出预算与完整 V2 校验保持。该方向用于检验上游原生 Schema 约束与推理组合是否影响正文，尚未证明能够修复当前失败。

只有该诊断通过且用户确认后，才按正式用途验证、配置指纹／冻结及 G3 顺序接续；不直接把业务配置切为新模式，不自动回退或修补不合格正文。

## 候选处理：原生 Schema 的非流式诊断

保留 json_schema 和推理，临时以 stream=false 请求相同材料并移除仅流式使用的 stream_options，记录完整响应。该诊断用于分辨流式返回与完整返回是否存在差异；若通过，正式研究执行还需显式传输配置、预算／超时和冻结证据，不能把一次直连当成目标接线完成。
