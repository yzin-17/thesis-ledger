# 账户数据单账户范围验收记录

日期：2026-11-05。范围为 Desktop 源码与本地生产预览。

## 结果与职责

账户数据聚焦具体账户的持仓快照、成交、现金和适用的定投计划；跨账户汇总由投资组合承担。账户选择器只列出当前模式的具体账户，管理账户入口继续可用。

删除重复汇总组件 `AccountDataAllAccountsView` 及其聚合估值读取。`account-data.selection` 解析具体账户，`useAccountDataNavigation` 保留模式独立记忆、地址规范化与切换保护。页面在当前账户的查询与内容之间组合，不新增接口或共享模块。

## 地址与上下文

- 有效具体账户地址优先；默认恢复当前模式最近使用且仍有效的账户，没有记录则使用范围内第一个账户。
- 旧 `accountId=all`、失效账户及旧 all 记忆回落到有效账户。地址采用 replace 规范化，记忆写回具体 ID。
- 目录加载或读取失败时保留深链与记忆，成功后才判断缺失；当前范围为空时提供创建账户入口，不读取另一模式账本。
- 旧地址携带的录入入口与定投定位在账户不匹配时失效，不自动打开另一个账户的表单。地址规范化清除对应参数；账户目标变化清理旧编辑/审计/快照上下文。
- 账户切换仍经过导航草稿与忙碌保护；现金账户的页签限制、基金定投来源、管理账户和跨页恢复保持。

当前规则同步到持仓录入模型与估值需求门禁规格。投资组合的全部账户范围及共享缓存/失效规则继续由原模块拥有。
