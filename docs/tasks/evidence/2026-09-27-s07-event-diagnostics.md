# S07 事件能力诊断

## 实现与边界

事件选择器在已固定请求后发生上游失败或响应校验失败时，保留该请求；未通过控制面、目录或准入选择时不伪造目标。选择顺序、请求次数及不隐式切源的行为不变。

事件收集器保留各能力的失败观测，通过稳定错误载体交给预检。诊断逐项返回 `CASH_DISTRIBUTION` 或 `SPLIT_EVENT`、RouteKey、标的、精确窗口、已知请求目标及失败原因。成功能力不生成错误，覆盖不完整与来源不可用分开；底层异常和覆盖说明不直接进入用户诊断。实际 Snapshot 冻结仍拒绝不完整事件集合。

初次验证发现新增错误子类触发既有汇总导出的初始化循环。已将 Backtest 非价格依赖错误定义提取到 `backtest-snapshot-v3-dependency-error.ts`，保持原导出路径和错误码，避免错误类型反向依赖读取/装配模块。原大型依赖文件规模缩减，未新增跨 feature 依赖。
