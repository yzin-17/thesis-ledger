## 标的目录搜索

旧包实际复现：`/market-data` → 标的目录，输入“验收无匹配”并搜索。`GET /api/market-data/instruments/search?q=…&limit=50` 返回受控 503 后，按钮从“搜索中…”恢复，结果区域没有错误说明。该入口与已过 T5.R2 的凭证、公告、能力检查不同，不能复用后者关闭。

`InstrumentCatalogPanel` 现在分别显示尚未搜索、读取中、没有匹配与可重试的读取错误；`MarketDataPage` 传递当前查询状态，并把重试交给原 TanStack Query `refetch()`，没有新请求通道。失败不清除输入，重试 GET 不同步目录或确认标的。

挂载测试 `instrument-catalog-search.recovery.ui.test.tsx` 先复现状态缺失，再验证受控 GET 503→相同 URL GET 200 空数组，输入保持、同步/确认均零调用。IAB 在最终生产包逐项检查初始状态及失败→重试加载→无匹配，三个状态加一个受控长名称结果，各有双主题三视口，共 24 组；没有页面横向溢出，六组错误态的重试按钮均可聚焦且在视口内。正向结果为符合现行 Schema 的固定样本，确认入口禁用，未打开行情详情。

上述证明客户端呈现与读取恢复，不证明在线目录覆盖率、同步成功或行情来源可用。最后清除截获并重新读取真实页面，恢复“尚未搜索标的”，真实目录仍为 35,385 个。
