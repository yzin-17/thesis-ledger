# 模型每周复盘实施任务

任务标识：arena-weekly-review。首次建立：2026-11-05。[对应规格](../specs/2026-11-05-arena-weekly-review.md) · [任务总入口](README.md)

## 当前状态与接续

周报已接入竞技场冻结账、PostgreSQL、独立 Redis 队列以及两端入口。比赛时区决定周一周界，最后一个应有交易日结束后形成一期；整周休市按自然周截止。首次发布、相同输入重算和历史修订分别保留稳定身份。Desktop 从投资复盘或比赛进入，Mobile 从研究下的复盘或比赛进入，均无需投资账户。

基础报告按决策封存日、成交执行日和收盘估值日归期。报告包含模型与基准区间比较、开轮及决策覆盖、交易费与模型费、盈亏贡献、同轮仓位分歧和 5／20 个交易日价格观察。观察依据为交易日历、后续已冻结的日线及公司行动覆盖；证据不全保留原因，未到期显示未成熟。报告链接可回读原轮次。

受控证据：`apps/server/test/model-arena/week-rules.test.ts` 检查跨年、休市、夏令时与观察窗。`apps/server/test/model-arena/cross-week-postgres.integration.test.ts` 在维护脚本提供的隔离 PostgreSQL 与 Redis 中自动发布两期；周五报告没有周一成交，周一交易费和收益只进入后一周。人工受控输入与真实前向周单独验收。隔离 Worker 中断、目标部署和真实自然周分别取证。

周报进程在算完报告、发布前被终止，租约到期后新 Worker 以第二次领取发布，旧领取重放仍只有一版。无投资账户通过真实 HTTP 读取周报，错场或跨用户被拒绝。Edge 从投资复盘或竞技场进入相同周报，分别定位成交与观望模型，返回原修订；Mobile 组件验证两个入口分别携带参赛者身份。

目标库已升级到周报结构，Desktop、Android 与 iOS 模拟器均从投资复盘打开实际周报列表，结果为空。完整周报、原修订与故障恢复使用隔离库取证。[本机开发环境验收](../evidence/2026-11-06-watchlist-arena-target.md)

[本地验证记录](../evidence/2026-11-06-watchlist-arena-weekly-local.md) 汇总本轮使用的环境、命令和验收边界。

11-07 本地刷新展示补充：比赛、轮次及周报同范围读取保留结果，相关请求全部结束后移除单个居中提示；Desktop 页面刷新范围及周报按钮已覆盖。四宽 Desktop 冻结生产资源与 Mobile 受控浏览器宿主、定向回归及本轮输入的包级验证见[刷新验收证据](../evidence/2026-11-07-arena-detail-refresh.md)。该受控证据不替代 RG1–RG5 的目标运行态、实际移动宿主、真实前向或自然周条件，原未勾选项继续保留。

## 执行入口

先读[竞技场任务](2026-11-05-model-arena.md)、[投资复盘工作区](../../apps/desktop/src/features/journal/review/JournalReviewWorkspace.tsx)、[移动研究导航](../../apps/mobile/src/app/ResearchNavigator.tsx)。R01 先对账跨周样本中净值、现金、费用、动作、证据、时区及日历各自的来源键；字段缺失退回 A12 修订输入，不用展示层推测。

每行拥有一个结果及相应定向测试。先执行所属包的定向用例，再运行受影响包测试与 build、仓库依赖和结构门禁；以真实场景验证对应行的最后一列。沿用工作区 AGENTS.md 的 RTK、原生编译和 Docker 入口约束。涉及新表时以新增 migration 保数据，维护 migration matrix、打包输入和必要的 raw-owned 登记，隔离 PostgreSQL 通过后才可通过相邻 infra 的 `./scripts/update.sh thesis-ledger` 更新获准目标。跨 feature 的新增依赖同步维护 `scripts/check-boundaries.mjs`。保持现有未提交工作与业务数据。依赖未就绪、超出写集或缺少外部条件时，记录受影响的叶与下一次可验证条件。
