# V1.0：稳定性、发布与最终验收

> 阶段目标：把各阶段能力产品化：迁移、备份、安全、可观测性、性能、跨端发布、测试和最终一致性 Review。

- [x] T255：执行 Domain Model 总审计
  - 涉及范围：Review Account/Ledger/Position/Portfolio/Risk/Strategy/Journal/Automation 的关系和冗余字段。
  - 完成条件：不存在互相冲突的事实源；废弃字段有迁移计划。
  - 验证方式：生成 domain map 并逐表检查 owner/source-of-truth。

- [x] T256：建立 Migration 测试矩阵
  - 涉及范围：覆盖从空库、V0.1、V0.3、当前版本升级到 V1.0。
  - 完成条件：所有支持路径可自动执行并保持数据完整。
  - 验证方式：在多个数据库快照上跑 migration CI。

- [x] T257：建立回滚与恢复策略
  - 涉及范围：明确数据库 migration、应用版本、DSA image 的回退流程。
  - 完成条件：出现发布问题能恢复到上一兼容版本。
  - 验证方式：在 staging 演练一次升级→回退。

- [x] T258：实现数据完整性检查命令
  - 涉及范围：检查 Ledger balance、Position projection、Snapshot、orphan FK、重复 externalUid 等。
  - 完成条件：可输出错误报告并给出修复建议，不自动破坏数据。
  - 验证方式：故意制造异常 fixture 验证检测。

- [x] T259：实现数据库 Backup
  - 涉及范围：提供本地/部署环境备份脚本和保留策略。
  - 完成条件：备份文件带时间、版本和校验。
  - 验证方式：执行一次全库备份。

- [x] T260：实现 Restore
  - 涉及范围：支持从备份恢复到空环境，并验证 migration 兼容。
  - 完成条件：恢复后核心 E2E 数据完整。
  - 验证方式：备份→删除库→恢复→执行 integrity check。

- [x] T261：实现用户数据导出
  - 涉及范围：导出 Account、Ledger、Portfolio、Journal、Strategy、Risk/Notification history 的结构化文件。
  - 完成条件：导出格式有版本；不包含 Secret。
  - 验证方式：导出测试账户并检查内容。

- [x] T262：执行 Secret/Credential 最终安全审计
  - 涉及范围：检查 AI Key、Provider Key、Feishu Webhook、数据库凭据的存储和日志。
  - 完成条件：Secret 均加密或环境化并脱敏。
  - 验证方式：运行 secret scanner + 手动日志 Review。

- [x] T263：实现 Upload Security 加固
  - 涉及范围：限制文件大小/类型、路径、临时文件权限和清理；防止恶意文件名或超大文件。
  - 完成条件：截图导入不执行文件内容；临时文件按策略清理。
  - 验证方式：安全测试伪 MIME、超大文件、路径穿越名称。

- [x] T264：实现 API 输入验证与限流
  - 涉及范围：所有公开 API 使用 Schema，上传/AI/重任务有合理限流。
  - 完成条件：非法输入统一错误，不泄漏堆栈。
  - 验证方式：Fuzz/边界输入测试。

- [x] T265：实现日志脱敏与结构化日志
  - 涉及范围：统一 traceId、service、operation、duration、status，脱敏 token/webhook/PII。
  - 完成条件：跨 Server→DSA 调用可用 traceId 关联。
  - 验证方式：执行一次请求并检索完整链路。

- [x] T266：接入 Error Tracking
  - 涉及范围：捕获 Server、Desktop 关键异常和版本信息，不上传敏感 Portfolio 内容。
  - 完成条件：staging 能看到受控错误事件。
  - 验证方式：主动抛错验证。

- [x] T267：建立 Metrics
  - 涉及范围：至少覆盖 API latency/error、Provider health、Job、Import、Notification、AI、Backtest。
  - 完成条件：能回答系统哪里慢、哪里失败。
  - 验证方式：生成负载并检查指标变化。

- [x] T268：实现 Provider/Automation 运维 Dashboard

  - 验证方式：注入 Provider/Job 故障人工验收。
