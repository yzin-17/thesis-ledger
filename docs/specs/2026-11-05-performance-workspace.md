# 收益分析统一入口与四页签工作区

## 目标

将 Desktop/Web 的投资组合与收益分析合并为唯一的“收益分析”入口，按组合概览、收益分析、配置目标、交易组织现有能力，保留现有计算口径和业务操作。

## 页面与路由契约

- 唯一导航入口为“收益分析”，规范地址 `/performance`，默认“组合概览”。页签以 `tab=overview|analysis|allocation|trades` 保存，无效值回退组合概览。
- `/portfolio` 保留为旧地址入口，使用替换跳转进入 `/performance`，保留账户、页签及其他查询参数。根地址和未知地址进入统一工作区；旧逻辑导航标识 `portfolio` 解析至规范地址，不再生成第二个侧栏入口。
- 顶部只有一份当前实际／模拟模式下的启用账户筛选。四页签共享 `accountId`，切换页签、刷新和前进后退不丢失账户；无效、停用、跨模式账户及模式切换沿用原有校验与回退。
- 组合概览展示原有总资产、今日收益、累计盈亏、已实现盈亏、当前持仓、行情详情、空态及首次使用引导。
- 收益分析展示原有时间加权和资金加权收益率，图表区域按[同图契约](2026-11-05-combined-performance-trend.md)同时展示累计盈亏与资产总值，共享区间与时间轴，使用独立金额轴。两类曲线继续使用各自的查询、采样时点、缺口、币种、当前点及历史口径；不把资产增减当作收益，不修改收益公式或将图表区间冒充收益率计算区间。收益摘要明确其全历史口径。
- 配置目标展示原有当前配置、目标权重、偏差和再平衡建议；[带符号现金](2026-11-05-negative-cash-allocation.md)参与净资产与配置分母，真实负现金不应导致读取失败；保留编辑、校验、版本、保存、失败草稿、重试和保存后读取语义。汇率合并与基准币种位于四页签外，与账户范围组成公共工具栏；切页保留选择，单账户和单币种沿用原禁用条件，换算继续作用于原收益与配置计算，不重解释概览估值或交易原币种。
- 交易保留原有账户／标的／生命周期筛选、分页、详情、退出与复盘入口；顶部账户筛选复用，不重复展示交易账户选择器。
- 账户与页签切换经路由草稿保护；配置编辑期间的本地换算控制切换复用现有转换保护，保存／确认读取在途不得丢弃草稿或切换作用域。

## 实现边界

跨功能页面编排由 `app` 层拥有；Portfolio 提供组合内容，Performance 提供分析与配置内容。特性模块不得反向依赖 `app`。大型既有文件不继续增长，按展示职责提取稳定组件；同步维护边界门禁。请求继续使用 TanStack Query，保留缓存隔离、失败与迟到结果处理。

不修改 Server、数据库、收益和分配算法、目标存储协议、历史快照、账户数据页面、Mobile 或原生工程。不提交、推送、部署、改变 Docker 或执行外部 Provider 调用。
