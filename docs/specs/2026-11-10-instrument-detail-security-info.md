# 标的详情内自动展示证券资料

当前导航约束见[业务流程内选择证券与港美股票支持](2026-11-10-instrument-selection-workflow.md)：独立目录入口已移除，本合同的共用详情资料行为继续适用。

## 目标与范围

将 Desktop 原有独立证券资料查询并入共用标的详情；用户从标的目录、自选或持仓打开详情即可读取，无须再次选择证券并提交查询。沿用现有证券静态资料 API、路由和权限，服务端、DSA、Mobile、数据库及部署配置均不变。

## 行为与约束

- 港股、美股股票及 ETF 打开详情时自动请求当前证券资料，查询按完整代码与证券类型隔离，传递取消信号；未知类型、A 股、基金和指数不发请求。
- 资料区独立于行情成功与否展示，保留名称、证券 ID、每手股数、上市日期、退市标志、交易所、来源及观察时间。字符串数值原样保留，缺失显示未知；当前资料历史变更未核验，供应商已废弃的上市日期仅供参考。
- 使用 TanStack Query 管理缓存、错误和请求竞态；初次读取在数据区域中央显示加载圈，同范围刷新保留数据并叠放加载圈，刷新失败保留上次资料及错误提示。资料区复用共享表头刷新图标，错误支持重试。
- 移除目录页的独立查询表单；目录搜索、确认、行情、持仓和新闻交互保持。现有行情弹窗的主刷新继续负责行情，证券资料由自身分区刷新，盘中自动刷新不轮询静态资料。
- 不修改真实业务数据、路由配置，不扩大资料来源能力，也不修复本次范围外的确认状态文案。

## 验收标准

- AC1：共用详情挂载受支持标的后自动读取正确代码及类型，无须额外提交；ETF 与股票缓存隔离，切换标的无旧资料串入，关闭时取消未完成请求。
- AC2：不支持的市场或类型不请求静态资料，行情失败不遮挡证券资料，资料失败不遮挡行情。
- AC3：全部原有资料语义与数值精度保留，缺失值、上市日期及历史有效性说明明确。
- AC4：初次加载、缓存复用、同范围刷新、失败保留与重试按项目加载规范工作。
- AC5：目录不再渲染独立表单，共用详情原有交互测试通过；1440、1024、768、390 浏览器验收覆盖资料、刷新/失败、弹窗边界、滚动、关闭及返回焦点。
