# 风险通知提供方多选

日期：2026-11-07。对应[实施任务](../archive/tasks/2026-11-07-risk-notification-providers.md)。

## 范围与行为

通知页签提供“通知提供方”多选与保存操作，用于后续风险通知投递。默认按可用提供方的优先级升序、名称升序选第一家；不以浏览器本地状态冒充服务端设置。

- AC1：候选项来自服务端完整可用通知配置，支持同渠道不同提供方；仅启用、凭证有效且有投递适配器者可选。候选返回稳定名称、渠道、优先级，不返回凭证。
- AC2：未保存选择时默认最高优先级的一家；支持保存多家并跨页面重读。至少选择一家，失败保留编辑值。后续提供方被禁用或失效时保留选择意图并提示不可用，不静默切换到其它家。
- AC3：保存仅影响后续风险通知，现金、定投、研究等通知保持原路由规则。每个所选可用提供方独立入队、冷却与幂等，同一飞书渠道可有多条独立投递；历史投递消息和目标不改写，改变选择不重放历史事件。列表使用实际提供方名称区分同渠道的多条记录。
- AC4：TanStack Query 管理读写，使用共享多选组件，触发器与选项共用中文标签映射；四宽覆盖默认、多选、保存、失败恢复、加载及无候选状态。真实业务数据只读，不发送真实通知。

## 验证边界

复用 Provider 优先级与凭证校验，通知模块拥有选择设置和路由投影。设置持久化与投递执行分别验收，旧读取接口保持兼容。数据库结构若新增，先验证迁移 SQL、结构矩阵与隔离数据库，再按维护脚本验证目标运行态；运行态未通过不能记为完成。禁止为了多选而扩大可投递渠道或 Provider 资格。
