# 公告来源与已收录资料展示

实施与验收：[完成记录](../archive/tasks/2026-10-07-local-history-package-display.md)。

## 目标与范围

数据源按停复牌、风险警示、现金分红等通用能力命名，已收录的公司与日期属于具体公告／规则资料的内容。用户可查看现有公告列表，判断当前资料的覆盖范围。覆盖当前五个内置公告／规则 Provider 的九个资料文件及路由选项。继续使用现有读取、启停、读取检查和移除接口。

## 展示与契约

- DSA 清单以可选 `sourceKind: local_history` 标识资料类来源；每个来源的可选 `localHistory` 提供数据集身份、标的或交易范围、实际覆盖日期，以及原始文档标题、链接和发布日期。信息从读取器使用的 JSON 文件读取，不根据名称推断覆盖范围。
- 资料包缺失或元信息损坏时保留资料包分类，显示“覆盖范围未提供”，不推断就绪或全市场覆盖。旧清单兼容五个既有资料包 Provider ID，但不补造日期。
- 数据源页沿用单列表布局，每个来源一行展示名称、配置来源、健康状态、上游或资料类型、能力徽章及操作。具体公司、原文、发布日期和实际读取范围在公告列表中展示。
- “检查资料包”先打开公告与规则资料列表，支持按标题／标的搜索，展示原文链接、发布日期及关联资料类型；同一原文链接归集为一条文档并保留所有资料引用。用户可另行进入现有读取检查。缺失清单与空列表分别说明。
- 路由触发器与选项复用同一通用中文标签，包含“本地资料”和来源类型；公司与日期在收录内容中展示。停复牌与风险警示的来源身份及读取语义保持独立。

## 验收标准

- AC01：九个资料包的元信息与实际文件一致；现金分红显示实际覆盖日期 2023-01-03～2023-02-01，而非仅凭名称显示一月份。
- AC02：来源及路由名称采用通用类型；公告列表可查看原文、发布日期和全部关联类型，支持搜索和同原文归集；缺失元信息有明确回显。
- AC03：主备选项和已选值使用相同完整中文标签；凭证禁选、启停、读取检查和移除行为不变。
- AC04：定向契约／行为测试、包构建、目标 API 和浏览器展示验证通过；启停和路由配置不因展示变化而写入。

## 边界

本次完善现有公告展示；覆盖范围仍由实际收录内容决定，不新增抓取服务、不修改数据库、凭证或准入记录。部署使用既有脚本；代码快更只证明容器可写层已更新。
