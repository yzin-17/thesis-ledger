# 规则监测来源选择随目录扩展

## 范围与约束

共享合同、Server 代理与 DSA 必须允许选择全部已登记来源，目录继续增长时无需修改数量常量。来源标识格式、去重、未知来源拒绝、非空要求、认证与配置修订保持。来源目录响应也不得以当前目录数量设上限；执行与保存交互遵循[执行规格](2026-11-15-rule-monitor-execution.md)。

不提交真实监测来源修改，不触发外部资料检查，不改调度时间、冻结事实或数据库结构。通过 infra 正式快更入口同步两仓代码；若预检拒绝则按现有规则选择完整更新。

## 验收

- AC1：共享合同和客户端接受十项及继续扩展的来源，配置、状态和任务结果可完整往返；非法、重复与不合法空值仍拒绝。
- AC2：Server 转发全部选择；DSA 根据同一次目录快照验证成员资格，创建、配置、手动入队及读取不依赖固定来源数。未知或重复来源不产生写入与外部请求；完整目录执行及资源保护遵循执行规格。
- AC3：保存失败显示错误并保留选择，用户通过原创建或更新入口再次提交，提交时读取最新配置修订；读取失败不写入，也不启动资料检查。现行验收由执行规格 AC3 持有，首次实现过程保留在已归档证据。
- AC4：定向回归、相关包验证和门禁完成后，经正式入口同步本地；检查部署代码与真实只读响应，并用受控浏览器请求验证十项保存和读取恢复，不改真实配置。

实施与验收见[已归档任务](../archive/tasks/2026-11-15-rule-monitor-source-selection.md)及[验证记录](../archive/evidence/2026-11-15-rule-monitor-source-selection.md)。
