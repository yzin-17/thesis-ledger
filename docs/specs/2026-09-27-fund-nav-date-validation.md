# 基金净值日期一致性

归属 M3 R03.1–R03.4。最新净值与净值历史复用来源日期解析，非法日期、重复时点在 Provider 边界拒绝，保留既有来源回退。最新值按解析后的实际时点选择，不能按日期字符串字面顺序选择。历史数据继续要求严格升序；本次不增加历史修订、披露时间或盘中估值语义。

日期允许 ISO 日期或日期时间；既有无时区日期按 UTC 午夜兼容表示，有时区日期统一到 UTC。该表示是净值日期，不是公告发布时刻。日期不同写法代表同一时点时视为重复，不合并可能冲突的净值。

验收包括非法日历日期、同一时点不同写法、带时区的最新值选择、历史倒序拒绝、真实路由输出及既有网关回归。目标部署与真实来源可用性独立记录。
