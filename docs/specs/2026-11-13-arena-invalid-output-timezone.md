# 自主竞技场：模型无效输出诊断与时间展示

## 现象及证据
- 2026-11-13 14:35:19Z（美东 09:35）本地模型 lmstudio 的研究周期失败，原因为 model_output_invalid。
- requestAudit 最后一次调用为 schema_invalid，响应是有效 JSON；独立校验定位至 decision.orders[0].exitGroup。
- 模型错误地把限价买入单和一笔止损卖出单设置为相同 exitGroup；该字段只能用于同数量、同标的的一对卖出止盈与止损委托。该决策没有进入正式模拟交易。
- 历史决策时间显示使用比赛市场时区 America/New_York，却没有标注，容易让用户误以为是本地时间。

## 需求与边界
- 历史决策、近期决策、模型账户时间、概况时刻统一按设备本地时区展示，并附 IANA 时区标识（例如 Asia/Shanghai）；纯业务日期和市场交易日保持原有语义。
- 无效输出列表直接显示结构化审计中的明确错误字段和原因；不将完整模型回复、提示词、凭据展开到错误摘要，审计明细仍在原入口。
- 在模型系统提示中明确 exitGroup 配对退出规则和先入场成交、再建立止盈止损的顺序，减少误填；Schema 和撮合约束保持不变。
- 不自动重试失败模型，不把不合法交易指令悄悄修正为合法指令，避免改变策略含义或额外消耗模型额度。
- 保留现有未提交修改，仅修改必要的模型竞技场呈现和提示词。

## 验收
- 可从既有 requestAudit 的 schema_invalid/expiresOn/output_truncated 等信息生成可理解的错误说明；缺失或未知字段安全降级。
- 2026-11-13T14:35:19Z 的失败条目在本地时区展示正确转换及 IANA 时区，不再固定显示美东 09:35 而不注明时区。
- 模型系统消息包含 exitGroup 及 fill 事件约束，既有 Schema 未改变，相关定向测试和类型检查通过。
- 如果需要刷新 Docker：使用所属 infra 仓库正式脚本并核对退出码、容器健康与新版编译产物；不主动调用付费模型。
