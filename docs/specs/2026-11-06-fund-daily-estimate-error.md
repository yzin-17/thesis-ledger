# 单基金每日估值误差

[实施任务](../tasks/2026-11-06-fund-daily-estimate-error.md)。收盘后从既有分钟事实冻结同基金、交易日和算法最后有效点及同次来源证据，保留原覆盖。仅对有效样本运行，不补造停机或缺料分钟。

- AC1：按上海交易日收盘判定；同一身份只冻结一次，重启后可找回。只有能绑定该次估算的完整快照与证据才可冻结。
- AC2：先用当前控制代次的已存正式净值；同完整代码、同净值日、有限正单位净值、来源和抓取时间才可比较。在 21:40 后且确有待比较估算时，同一基金日最多一次沿当前 AKShare／东方财富公开主来源读取。须在 DSA 执行边界限制来源，不重试或切换备用；结果未公布继续等合格缓存。
- AC3：以原值算带符号、绝对、相对绝对误差，保留实际抓取、缓存和回退信息。展示当日或最近一次比较的日期、质量和限制。定时任务不调用股票行情、模型或通知。
- AC4：隔离测试日期错位、停机恢复、幂等及低覆盖；目标库保数据升级，复用已有分钟和同日净值验收。
