# 自选价格与日内区间的非零展示

## 问题与目标

自选共享投影对报价、净值、涨跌额、今开与区间价格采用最多四位格式，极小非零值会显示为零；涨跌幅及 Desktop 振幅仍直接乘 100，极小值归零、最大有限值可能溢出。

在 watchlist-display 的价格事实所有权内统一紧凑数值：普通值保留四位和千分位，极小非零或巨大有限值使用科学计数，无效值显示不可用。比例复用现行 Domain 合同；日内振幅由 Desktop 原公式取得比例后使用同一投影。只调整展示，不改变来源数值、查询、状态或计算数据。

## 验收标准

- AC1：报价、净值、涨跌额、开/前收/高/低普通四位保持，极小正负不显示零，零、负零和未知区分；最大有限值不形成无穷文本，原始输入不变。
- AC2：涨跌幅和日内振幅保留普通两位，极小非零可读，大比例避免乘 100 溢出；前收无效、缺报价、缺区间仍保持不可用。原有商数超出 number 范围时不自行计算或猜测新值。
- AC3：来源、币种、行情/净值日期、休市、陈旧、刷新失败与未知原因保持；核对 Desktop Table/Range 和 Mobile Screen 全部三个消费者。
- AC4：先有失败回归，定向后完成相关完整包、构建、lint、边界/依赖/尺寸；真实组件在四个代表宽度验证文本、内部滚动、菜单/选择入口与状态。
- AC5：保存稳定输入和控制边界，归档闭合任务并继续 Goal。

## 所有权与边界

数值紧凑展示是自选价格事实的私有能力，不新增通用 utils 或共享包导出；比例单向消费同包 ratio-percent。Desktop 仅改 WatchlistRange 的振幅格式，不改 SVG 定位或原表格结构。Mobile 继续消费共享投影，不为验收改产品查询或导航。

浏览器采用真实业务组件、隔离缓存与必要原生环境适配；适配仅提供运行环境，不替换数值投影和业务行。明确区分 Web 环境的 Mobile 读数与真实 Native 导航/编译，不扩大发布结论。没有来源、模型、Docker、真实写入或部署动作。
