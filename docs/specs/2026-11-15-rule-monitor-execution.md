# 规则监测完整目录执行与来源保存

## 行为与边界

规则监测按当前登记目录生成一次执行快照，覆盖所选来源的全部去重文档；任务总文档数量随登记目录扩展，不以当前来源或文档数量设置常量。相同地址每轮只请求一次，顺序执行，单文档继续限制2MiB、总耗时最多15秒、连接5秒，其他网络阶段最多10秒，无重定向或自动重试，总读取时限300秒。到期后停止外部访问，对剩余有限项目记录 `run_budget_exceeded` 并完成终态收敛。来源包大小、白名单、快照文本大小、认证、任务领取与终态保护保持。连接保护校准及后续真实检查见[轻量正文规格](2026-11-15-rule-monitor-lightweight-document.md)。

普通后台检查逐件落库并释放正文结果；只有现有单来源按需检查需要返回捕获内容。状态与历史合同允许登记目录增长后的文档数量和全部失败明细，分页与最近观察窗口保持。

来源保存失败保留当前选择并显示错误。用户通过原有创建或更新任务来源按钮再次提交；每次明确提交先读取当前配置修订，读取失败不写入，冲突不自动重发。成功后清除草稿与错误并更新展示。

## 验收

- AC1：实际登记目录的全部来源和29个去重地址，在受控文档响应下完成；扩展到更多文档仍通过，去重和历史完整往返成立。
- AC2：超时后不再发请求；单文档大小、停止、串行、租约、重复任务保护继续通过。后台运行不累计保留正文结果，单来源按需读取仍返回所需快照。
- AC3：失败只显示错误，保留全部勾选；原保存入口能使用最新修订重试，读取失败不写入、重复点击不重复投递，成功后错误消失。
- AC4：定向回归、相关包检查、构建与门禁后，使用正式入口同步本地；部署文件与宿主一致，真实只读响应及四宽浏览器受控保存验证通过。真实配置和历史保持只读，不触发真实外网资料检查。
