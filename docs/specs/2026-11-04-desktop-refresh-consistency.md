# 桌面页面刷新入口与范围一致性

> 任务标识：desktop-refresh-consistency
> 日期：2026-11-04
> 对应任务：[已完成任务](../archive/tasks/2026-11-04-desktop-refresh-consistency.md)

## 目标与范围

检查当前桌面 Web 九个主页面及策略中心子路由的刷新行为，使页面级刷新位于顶部、覆盖当前正在展示的数据，并等待该范围的全部查询完成。投资组合已有顶部统一刷新，本次复用其已通过证据并检查回归；其他页面按核实的遗漏修正。移动原生工程与发布不属于本次范围。

## 刷新语义

刷新只重读当前页面已启用且有活动消费者的 TanStack Query。保持查询自身的账户、模式、筛选、分页、草稿与缓存键，不重新挂载页面，不启动未启用或未打开区域的查询。重叠范围只执行一次查询。刷新中的禁用及旋转状态由同一批活动查询驱动，不能在较慢的子查询结束前提前恢复按钮。

共享刷新 hook 只调度缓存中的查询，不依赖具体 feature、API 客户端或业务写入。各页面声明自己拥有的查询范围。失败保留现有数据与原错误展示；错误处重试与独立弹窗刷新继续承担明确的局部恢复职责。

普通页面刷新不得执行同步目录、重新运行回测、风险扫描、AI 生成、通知发送、保存或其他 mutation；这些具有独立业务意义的操作保留。已经就绪的页面只有一个页面级普通刷新入口。

## 已确认修复面

- 策略中心：活动策略列表、任务、任务详情、净值回测及实验查询纳入同一页级范围；状态覆盖子页面。
- 风险中心：基础风险、通知路由、当前风险应用及其策略说明、已加载组合数据纳入范围。
- 市场数据：市场控制/目录及已提交的证券资料查询纳入范围，状态覆盖子区域。
- 收益分析：顶部入口覆盖已启用的历史、序列、汇总、分层、目标与配置计算，保留局部失败重试。
- 研究助手：列表刷新移至页面顶部，保留列表错误恢复与新建研究；不重新执行研究。
- 账户数据与投资复盘：提供页面顶部的只读刷新，保留现有账户选择、编辑草稿和局部重试。
- 数据与自动化：核对现有入口完整性与状态，保持连接测试和运行任务独立。

## 验收

- AC1：九个主页面与策略子路由有可追溯的入口、刷新范围及保留操作清单。
- AC2：共享调度仅刷新匹配的活动查询；停用、未展示、其他范围保持；范围重叠不重复；失败与慢查询状态正确。
- AC3：各页面顶部入口与当前数据匹配，健康态无重复普通刷新；筛选、分页、模式、草稿和独立恢复不被清空。
- AC4：相关定向测试、桌面构建、边界与本地浏览器检查通过；只声明实际验证的 Web 范围。

保留既有工作区与数据，不提交、推送、调整来源或发布。通过维护入口更新运行态时明确记录目标、参数及结果；界面源码与本地构建证据不自动代表镜像或安装包更新。
