# AI 提供方状态说明

## 目标与范围

核对 Cloudflare 两条执行配置的真实阻断原因，改善 Desktop 与 Mobile 的状态表达。只读读取真实服务，不调用远程模型、不授权费用、不修改配置、验证记录或业务执行门禁。

## 行为与验收

- AC1：记录两条配置各自的模型、用途、版本、原因，以及目标运行服务实际支持的版本；区分源码与运行态。
- AC2：预算是具体任务的授权条件。仅缺预算时显示“待任务费用授权”，使用次级状态；只有其他阻断条件才计入“配置待处理”。服务端原始状态与原因码保持原样。
- AC3：逐条显示模型、中文用途、用途版本与对应原因，历史测试通过明确标为历史结果；不把不同配置的原因合并为同一句。
- AC4：两端消费 domain 中稳定、纯粹的状态展示投影；未知原因仍保留可读反馈，不静默丢弃。
- AC5：通过投影回归、现有提供方测试及类型检查；真实 Desktop 浏览器覆盖 1440、1024、768、390，Mobile 使用受控配置检查。真实数据保持只读。

## 所有权

`packages/domain` 维护跨客户端的业务展示投影，仅接收必要状态原语，不依赖 Server 适配器或 schemas。Desktop 与 Mobile 负责各自布局和交互。诊断记录维护在独立证据中。
