# 模型点位首次点击与图表实例稳定

## 目标与行为

修复模型点位首次点击没有空结果 Toast，以及切换图层时图表重建闪动的问题。

- 图表始终保持同一个组件与原生实例；开启、关闭、加载、空结果和失败仅改变模型数据与叠加层，保留缩放、拖动和当前可视范围。
- 空结果时恢复为关闭，清理已持久化的开启状态。再次主动点击会重新查询并显示 Toast；恢复的空结果本身保持静默。
- 有效数据的开启状态和已选比赛、模型继续按既有作用域保留。开关外观明确表达当前状态。
- Toast 仅响应本次主动开启，等待成功空结果后显示一次；关闭、切换周期/标的/身份后拒绝迟到提示。后台刷新、恢复和全屏迁移不自动弹 Toast。
- 查询使用 TanStack Query，关闭状态不发起新的模型请求；加载失败与空结果分别表达。保持模型点位、比赛跳转和原图表交互。

## 验收

- AC1：真实组合测试覆盖冷启动空结果、恢复开启的空结果、再次点击、加载中取消和有数据状态，验证 Toast 次数与按钮状态。
- AC2：开关和查询完成均不卸载图表，缩放与节点保持；四种宽度浏览器验证原生 canvas 身份与交互。
- AC3：既有 Toast、周期、全屏、取消和错误行为回归，前端构建、类型和复杂度检查通过。
