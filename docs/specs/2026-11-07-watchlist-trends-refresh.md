# 自选走势与刷新

目标：自选列表增加可点击迷你走势、日内区间与来源时间，页面可见时按当前实际来源的最小已接入原生周期检查报价和走势，后台暂停。同一数据域保留原值直到请求结束，错误与旧值并列。基金采用近期净值，股票/ETF可选择分时或近20交易日日线；不以报价拼接历史。

复用既有 Market 请求规划、控制、预算与质量校验，仅请求 bars/fund-nav-history；可见行才加载图表，手动刷新覆盖名单、报价和可见图表，等待最后相关请求结束。图表始终单独标出实际截止时间，缺分钟不跨缺口连线，日线不冒充分时。日内区间只有价格、最高最低符合范围时显示，零振幅保持真实值。

Server 返回来源最短请求间隔与已验证日历下次时段边界。客户端取实际来源最小周期与请求下限的较大值，ETF当前600秒为请求下限，休市已覆盖最近时段则等下一开市；未知日历降频并明示。日历向前覆盖14日，未覆盖下次开市时6小时复查日历，不猜节假日。

明确边界：DSA持久600秒硬窗口由前台和后台共享；现有源协议没有已验证的分钟级调用许可/更新SLA，本轮不修改预算、不切路由或购买权益。当前ETF实际分钟级更新尚不可用；按最新用户要求使用已接入最小周期，不把每分钟检查缓存当成分钟行情。后续持仓数值、风险与研究列不在首版实施范围。

## 来源最小周期修订

按用户补充，以实际返回数据的 provider/upstreamSource、市场、资产类型匹配现有完整来源能力目录，选择 ready 且账户资格有效的最小原生 bar 周期作为列表检查基准。派生周期不作为来源最小粒度。报价的请求下限与该基准取较大值；目录缺失、来源身份不完整或无对应能力时不猜测分钟周期，暂停自动行情读取并允许手动检查。当前目录仅声明原生1m/1d，不能凭空声称已接入5m原生来源。基金净值按每日发布语义检查。不同来源的报价按各自到期时间选择批量请求子集，不能因同页有快来源而每次拉取慢来源。源时间与检查时间继续分开。
