# 自选报价时段、刷新与信息展示

自选报价保留来源价格、来源时间、抓取时间及原 stale/freshness。服务端基于已有展示交易日历，独立投影最近已结束交易时段的收盘后快照、盘中/旧快照、日历未知；不把收盘后报价认证为官方收盘价。日历不可用时降级到原时效语义，不按周末猜测交易日。

刷新失败与时间老化分开传递稳定码。ETF 请求缓存及失败后的重试窗口遵守 DSA 每来源每标的 600 秒限制，手工刷新同样不绕过窗口；控制代次和原始质量校验保持生效。

经对应市场日历确认收盘或休市且覆盖最近结束时段的快照，不因单纯年龄阈值显示陈旧；日历未知保持未知，开市后及未覆盖最近时段单独判断。覆盖 CN、HK、US 时区、假日和缺失日历。

Desktop 使用已有开高低、前收、涨跌额、来源、双时间提升列表密度；未知量额不填零。Mobile 同步消费公共状态投影。加载圈遵循共享可见区域中央契约，共享加载指示可选沿竖向避让文字，优先居中，避免覆盖价格。覆盖真实页面、受控慢请求、未知来源时间、旧交易日、休市、重开和失败；不新增付费或受限来源调用。
