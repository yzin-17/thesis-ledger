# 模型每周复盘规格

标识：arena-weekly-review。首次建立：2026-11-05。[实施任务](../tasks/2026-11-05-arena-weekly-review.md) · [方案来源](../reviews/2026-11-05-thesis-ledger-feature-proposals.md#10-codex-本地复核)

## 入口与所有权

Desktop 可从「投资复盘 → 模型周报」查看自己各场的周报，也可从「模型竞技场 → 比赛详情 → 模型周报」按场查看。Mobile 从「研究 → 复盘 → 模型周报」进入。模型周报由比赛领域根据[竞技场冻结事实](2026-11-05-model-arena.md)生成，投资复盘提供阅读界面。独立校验 owner、比赛、周次及对象归属，无须当前投资账户、交易复盘候选或账户模式。报告链接定位周次及修订。

## 生成与内容

用比赛时区的自然周和版本化交易日历覆盖该周有效赛期。最后一个应有收盘估值的交易日结束后自动生成；赛季提前结束时封存截至结束日的最后一期。跨周休市且整周无应观察交易日时给出休市状态。报告逻辑身份为比赛、周起始日、方法版本；同一输入版本只发布一次，每次正式更正使用新修订号；生成与发布按状态／attempt 原子提交，重启后补未完成周。输入缺失时按覆盖率标为资料不全，禁止用零价或后见资料补成完整周。来源后续更正以新增修订记录承接，保留原周报与旧深链。

周报冻结来源版本和输入摘要，采用竞技场冻结的收益、回撤、换手与费用口径，在该周内重新计算区间指标，比较相同区间的期初期末净值、扣交易费收益、最大回撤、相对基准、比赛已开轮次／计划轮次、各模型有效决策轮次／已开轮次、交易费用和模型调用费。期初取上一应有交易日的收盘估值（按日历跨过休市日），首周用比赛初始资产；若应有的期初估值缺失，保留未知，不能跨过缺数日借用更早的旧价。缺期初或中间必要估值时对应指标标明不可算。列出可由流水解释的主要贡献、仓位分歧及主动观望；市场或现金流影响无法归属时单列。事实描述与可选的模型点评分开，自动产出基础周报不要求额外推理。排名注明时间范围与样本量。整轮因预算未开时单列比赛原因，模型的观望和失败计数均不增加；全周零开轮时模型决策覆盖率显示“不适用”。开轮后的单方失败计入该模型的已开轮分母。

周界分别按决策封存日、成交执行日和收盘估值日归属。周五已封存的动作可出现在本周决策列表，下周一发生的成交、换手与费用计入下周；旧周报只展示其截止时已知的状态。

看一笔决策时，先展示当轮可见依据，再单列其后出现的资讯和行情。观察窗自规则约定生效时点起算，按比赛交易日历给出 5／20 个交易日表现及区间高低变化；未成熟、缺价或调整口径不一致分别显示。冻结周报只显示截至该周截止可知的结果；后续成熟结果进入新一期并引用原决策。择取分歧用同轮同标的目标权重差；并列使用稳定标识排序。点击典型操作到准确轮次、模型、标的与可选成交，返回同场同周。观望案例可定位原决策。

## 验收

| 标准 | 可验证结果 |
| --- | --- |
| R-AC1 | 客户端关闭后按日历产出正确周次，覆盖节假日、半周赛季与整周休市；并发、重启及补投只发布一份同版周报。 |
| R-AC2 | 两模型、同周、同基准的收益和回撤可独立复算，贡献可对账；周五决策与下周一成交分别归期，期初缺值不跨周借旧价。证据不足与未成熟窗口可辨，模型成本不混入模拟交易费；预算未开轮与开轮后单方失败的计数可分别核对。 |
| R-AC3 | 原周报可按冻结输入重放，事后资讯与研究原文分开，后到更正可追版本、旧链接可读。 |
| R-AC4 | 无投资账户也能直接查自己的周报；浏览器和移动端均能从周报定位决策／成交再返回，同身份不同比赛不串，其他身份不可读。 |
| R-AC5 | 实际部署的周调度、Worker、数据库和两端通过对应门禁，并取得至少一个自然结束比赛周的前向周报；受控时钟仅证明规则和恢复。 |

基础周报复用比赛留存的事实。5／20 日观察需要自然时间和合格价格；未成熟状态可单独验收，不能以回放冒充已取得的前向经济结果。外部推送及付费点评不属于本合同。
