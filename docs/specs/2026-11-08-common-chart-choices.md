# 行情周期与区间的常用选项

日期：2026-11-08；对应[实施任务](../archive/tasks/2026-11-08-common-chart-choices.md)。

周期能力分批返回的历史验收见[归档任务](../archive/tasks/2026-11-08-chart-toolbar-stability.md)，当前展示以本规格为准。

## 行为与范围

- AC1：周期常用项为 1 分钟、日线、周线，仅显示能力已确认可用的项；5 分钟及其余可用周期收进“更多”。保留原能力查询、偏好与不可用回退，不新增来源请求。
- AC2：股票、ETF、基金共用区间控件，今日、一月、一年直接显示，一周、半年、三年、自定义区间位于“更多”。常用项选中状态直接可见，其他项选中后“更多”触发器复用中文标签回显；选择其他项时不把选项自动增加到常用栏。
- AC3：保留区间日期语义、自定义日期编辑、校验、取消、Esc 层级与历史按需读取；周期和区间偏好互不覆盖。更多菜单可键盘操作，收起后不占额外空间。
- AC4：定向测试、类型和样式检查通过；实际浏览器覆盖 1440、1024、768、390，检查默认密度、菜单展开、较少使用项回显、自定义区间、取消和横向溢出。

- AC5：周期按实际内容占宽，不预留固定空位；以三项常用周期控制密度。未确认可用的周期仍不提供点击，更多无可用项时隐藏入口；可用项变化或容器不足时按实际宽度自然换行。

## 实施边界

复用共享 ToggleGroup 与 Select，通过行情模块的同一选项控件组合常用栏和更多菜单。只修改 Desktop 展示与测试，不改价格口径、历史记录、服务端、数据库或部署。真实数据只读。
