# 策略标的按目录结果确定身份

## 目标与边界

修复手动编写新策略按默认内地股票筛选搜索、要求用户手选资产类型的问题。Desktop 与 Mobile 共用策略领域的选择规则。用户已选择使用已有富途账户补齐港美股票和 ETF 目录；新增有界目录读取、分市场合并及现有同步入口的范围参数，不修改历史版本、交易、账本或原生依赖。

真实目录检查发现当前只有内地记录，既有 DSA Catalog Loader 也仅实现内地股票、ETF 和基金集合。上述界面交付不能作为真实港美可选的完成证据；必须通过真实来源同步和实际搜索验收，不手工构造证券身份。

## 展示与提交契约

- AC1：交易所模式同时搜索内地、香港、美国的有效股票和 ETF，不按当前所选市场或类型锁定候选。净值模式只提供现有支持的内地场外基金。
- AC2：选中目录结果后，根据完整结果原子更新执行标的代码、市场、资产类型及 `execution` 信号源的身份；不按代码形状猜测类型，不修改独立信号源、周期或资金精度。
- AC3：资产类型和市场只读展示，未选标的不展示默认内地股票。输入搜索词或清空选择时不能把搜索文本或上一标的身份提交为新选择；已有策略加载不触发修改。
- AC4：新建、编辑与高级 JSON 保留既有校验、保存及导航保护；自然语言确认页已按目录自动识别，保留其现有流程。目录失败、无结果、过时请求和不支持类型不能形成新选择。
- AC5：领域反例、两端定向测试、类型检查与相关包构建通过；实际浏览器覆盖 1440、1024、768、390 的搜索、选择、切换、清空及边界。真实目录只读，写入使用隔离受控请求；移动端测试不代表真机验收。
- AC6：目录任务可显式指定 `scope=HK_US`，默认 `CN` 保持兼容。范围持久化，领取、去重与恢复不得误把另一范围任务视为本次完成；港美超时不自动新建重试任务。每次刷新只替换对应市场，保留范围外的已有完整记录，后续内地刷新不得移除港美。checksum 使用代码、市场、类型元组的稳定顺序，与 DSA 保持一致，覆盖变长美股代码及类别分隔符。
- AC7：富途读取仅使用已启用且已配置的已有账户，不自动开启来源或修改行情路由。`get_stock_basicinfo` 不传代码列表，依次读取 HK/US × STOCK/ETF 四个完整集合；逐行校验原生市场、类型、名称、退市标记与唯一身份。原生代码按协议中的不透明标识处理，仅校验市场前缀、非空、长度与控制字符；不得套用产品交易所代码字符集。原生记录校验与产品可选范围分离：明确退市记录排除；当前报价身份合同不支持的原生代码不纳入可选目录，记录分集合排除数量，不截断、补位或猜测代码。来源错市场、重复、错类型、未知退市标记或任一晚到失败均整体拒绝，每集合至少有一个可选条目，不发布部分集合。子进程硬期限 60 秒，每个集合最多一次，无来源切换；无新增费用。
- AC8：通过现有持久目录任务、快照校验、Server 投影及 ACK 完成真实目录更新；验证香港与美国股票、ETF 的真实搜索和策略只读身份。内地目录内容、真实策略与交易事实保持不变。部署使用 infra 正式入口，记录来源、运行态与受控界面证据的边界。

领域模块负责策略可接受的市场/类型及身份更新，客户端负责目录检索、交互和只读标签。领域不依赖客户端或 Schema 包，不新增通用工具集合。
