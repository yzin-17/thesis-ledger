# 回测图表的标的走势

日期：2026-11-11。对应[归档任务](../archive/tasks/2026-11-11-backtest-instrument-chart.md)与[验收记录](../archive/evidence/2026-11-11-backtest-instrument-chart.md)。

## 行为与边界

普通行情回测的权益图同时展示本次冻结的标的收盘价。标的价格采用紫色并使用独立左轴，权益使用右轴，回撤保留原区域；图例标明标的、币种及复权口径。三条序列共用时间轴、缩放、平移和时点查看。买卖点附着于标的走势线，按标的价格定位，方向沿用买卖配色；时点读数保留真实成交时间、数量和成交价。

日线来源可能将日期记在零点，而权益记在收盘。两边在来源时区的同一日期均只有一个点时，仅将价格的绘图位置对齐到已有权益时点；原始价格时间仍保留。日期不匹配、多点或非日线时保持原时点，不跨日期补点。价格轴出现、刷新或主题变化保留当前可见时间范围。

日线成交匹配来源时区的同日期有效价格；非日线匹配同日期成交之后的首个有效价格点。缺失、歧义日期或无效成交信息只计入未显示数量，保留原始成交明细。

读取本次快照的执行行情，不发起 Provider 请求、不替换为当前行情，不改变回测、冻结记录、指标或成交。独立基金 NAV 结果页不在本次范围。

## 合同与读取约束

- AC1：新增按任务 ID 绑定的只读冻结标的序列合同及客户端。Server 复用身份与结果读取门禁，受限任务在读取产物前拒绝；只读取对应快照执行产物并校验完整性、来源、复权和请求区间。
- AC2：合同保留原始十进制收盘价、时间及冻结来源元数据。缺失、损坏、不支持或未准备好返回具体不可用原因；不猜测、插值或补造历史点。
- AC3：Desktop 在同一图表展示标的走势，独立价格轴、图例与时点读数。时间轴和键盘交互覆盖三条序列；刷新保留曲线并在可见图区共享加载圈，错误不遮蔽已有权益。
- AC4：真实既有回测可读取冻结标的并绘制；四个代表屏宽检查缩放、查看与缺失状态，部署前后原结果摘要一致。

## 实现所有权与验证

Schemas 拥有新增读取合同，API Client 提供解析及任务身份校验；Backtest 拥有冻结产物读取，不增加 Market 远程调用。Desktop 以 TanStack Query 管理查询与同范围刷新。分别验证合同、服务端冻结读取与权限、图表投影和交互，再执行包构建、边界检查、正式更新和真实页面验收。

不变更数据库、Worker 状态机、历史快照格式或原生依赖。没有待用户决定的问题。
