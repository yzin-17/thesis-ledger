# 自主交易竞技场与独立观战入口

## 目标与协议边界

将模型竞技场提升为 Desktop 一级导航与 Mobile 底部独立页签。每场固定 A 股、港股或美股市场及币种，模型管理独立模拟账户，比赛以赛季收益曲线、排名、持仓、委托、成交和公开决策说明为中心。支持指定标的池与全市场股票／ETF 选股，主动网页搜索按比赛配置。可选择一个或多个不同的显式模型绑定，参赛者采用等额本金、同一工具权限和预算上限。

旧版日频比赛、冻结输入、成交、排名及周报保留原协议。自主比赛使用独立持久化与版本化契约，不转换旧比赛或向真实／影子账本写入。新功能不能以旧版回放替代自主交易验收。

## 已确认的行为

- AC01：两端独立入口覆盖比赛列表、创建、观战、模型详情与状态控制；旧链接保留定位及返回来源。Desktop 首页直接列出自主与历史日频比赛，保留各自详情入口；原历史列表链接归并到首页。首页操作置于 PageHeader，刷新复用共享图标按钮，通过统一目录查询读取两类比赛；加载、无匹配、空列表、失败及同范围刷新分别表达。
- AC02：比赛启动时执行首次研究。模型随后自行预约时间、价格或成交事件；至少提供一种有效预约，可只预约事件并持续休眠。模型不订阅成交事件时，成交不额外唤醒研究。
- AC03：预约持久化、原子领取及一次性消费；同模型串行研究，重叠事件合并。新决策原子替换预约；调度恢复只恢复已预约且到期的工作。休市与未知会话按 Market 正式事实处理。
- AC04：研究工具只读。模型研究结束后统一提交公开说明、委托、撤单与预约，提交核验账户版本；过时结果不得产生委托。无有效预约的输出属于协议失败；保留仍有效的既有预约，无预约时显示待处理。
- AC05：支持即时、限价、止盈、止损及撤单。只按委托生效之后实际观察到的合格行情触发，不推测采样间价格路径。即时委托仅在当次交易会话有效；其他委托可指定当日或赛期内到期日。按创建时间及稳定 ID 处理同次采样，成对退出委托共享数量，成交后撤销另一方。
- AC06：资金与可卖份额原子预留及释放；使用十进制运算，交易费、滑点、交易单位、涨跌限制、结算及公司行动事实可追溯。行情缺失、陈旧、延迟或来源时间不明时拒绝成交；网页不是成交价格来源。
- AC07：暂停保留挂单并冻结研究和成交，估值读取仍可进行；恢复重新核验，不回补暂停期间成交。结束撤销未成交指令，保留持仓，按共同有效估值封存；数据不足明确标记未完整。预算耗尽停止新研究，已有合格委托仍按协议执行。
- AC08：模型可按市场查询目录、行情、K线、指标、新闻与已接入资料；全市场模式不等于轮询全市场。搜索关闭时服务端拒绝搜索；开启时复用已配置来源，记录来源、发布时间及取得时间。所有调用计入冻结预算及审计，不静默切换模型。
- AC09：独立于模型研究生成共同估值批次。净值等于全部现金（包括委托冻结现金）与持仓市值之和；所有模型和基准按共同合格时点比较。赛季累计收益率等于净值除以初始本金减一；时间筛选只裁剪主曲线，期间收益单列。缺失区间断线，不以不同时间的行情制造排名。
- AC10：曲线支持收益率／净值、今日／近一周／近一月／全部、图例显隐与触摸／悬浮读取；选择模型联动账户与动态。同范围刷新保留数据，结果区共用加载圈。模型调用费与交易费分开显示。
- AC11：数据库为任务事实源；领取与提交带状态和 attempt 条件。明确失败、超时、身份未核实、预算不足、未知耗用及账户冲突。无法确认已出站请求时不重复发送；队列不可用时保留待投递及原因，不同步降级执行。
- AC12：覆盖三市场真实行情与规则准入、隔离数据库、受控模型、两端实际页面及运行态恢复。真实业务数据默认只读，不自动创建消耗未授权预算的比赛。
- AC13：自主比赛的开始、结束日期分别可选，省略或空表单归一为 `null`。未指定开始日期时从手动启动起参与后续合格交易会话，未指定结束日期时持续运行至手动结束；填写日期时保留原日期边界及截止自动封存。两个日期均存在时才校验顺序。运行中和暂停时均可手动结束，原子取消委托与预约、保留持仓及估值语义不变。不限期不表示无限预算，额度与日历未知门禁继续生效。旧日频协议及历史冻结文本不变。
- AC14：自主比赛的每模型与全场请求、令牌、费用总额度分别可选；缺省或空白表单归一为 `null`，表示该维度不限总额度。明确填写的非负数继续限制，`0` 保留零额度语义，旧数值协议及剩余额度不自动转为不限额。不限额维度不扣减或退款为数值，有限维度仍事务预留／结算并阻止超额并发。所有调用的实际用量、费用及未知结果继续审计，未知结果和身份／定价门禁不因不限额而放宽；单次令牌限制由 AC15 定义，研究步骤及时限由 AC16 定义，标的数与委托资金保护继续生效。两端创建默认留空总预算，展示“不限额”，不以零或占位大数代替；真实调用仍由用户显式启动比赛触发。
- AC15：自主协议的单次输入、输出令牌上限分别可选，缺省或空白归一为 `null`，默认不附加单次限制。明确的正整数仍生效，零和非法值不表示无限。输入不再受应用单次上限拦截时，仍用保守输入估算预留有限总额度；输出未设上限但模型或全场令牌／费用总额度有限时，以剩余额度计算本次输出边界并事务预留，额度不足出站前拒绝。全部相关总额度无限时不向 SDK 传入输出上限；上游自身能力仍生效。路由忽略输出上限而本次存在有效边界时拒绝调用，不更改路由。实际耗用、未知结果、身份和定价审计保留。

- AC16：自主比赛的研究步骤上限与研究时限独立可选，缺省或空白表单为 `null`，分别表示不限制模型轮次／工具次数和本次研究耗时；模型提交最终决策时完成本次研究。明确正整数保留原校验，零不表示无限。无限时研究不设置 SDK 总超时，不因交易时段结束强制截断。有限时研究保留原截止及会话边界。后台执行租约独立续约，租约失效按原未知结果／有限重试政策恢复，不用固定租约时长冒充业务时限。暂停、结束和 Worker 停止须向在途模型／工具传递中止信号并阻止后续调用；已出站用量无法确认时保留未知结果，不补发。有限预算、上游能力、账户冲突和委托的市场／行情／资金校验继续生效。

- AC17：自主与日频比赛均支持单个模型参赛，模型绑定数量为 1 至 12，继续拒绝空列表及重复绑定。单模型的创建、启动、研究、账户、收益／基准展示和手动结束沿用现有流程；不为满足参赛数量补充模型，不改写历史协议。未选择模型时在模型组提示“请选择参赛模型”，单模型选择后提示解除；两端和服务端契约保持一致。

### 自主比赛配置可选性

- AC18：设定过去的开始日期时，从该日期按历史时点回放研究、预约、模拟成交和估值，追至当前后以同一账户继续实时运行。历史资料可见性、断点恢复及独立验收由[历史回放与实时衔接](2026-11-12-arena-replay-live.md)定义；已有比赛保留事实，用户已选择另建同配置回放比赛。

| 配置 | 不填写时 | 仍需保留的约束 |
| --- | --- | --- |
| 比赛名称 | 使用“自主模型比赛” | 已填名称去首尾空白且不超过 200 字 |
| 开始／结束日期 | 启动时开始／手动结束 | 双边填写时顺序有效；市场日历未知继续拒绝自动执行 |
| 每模型／全场请求、令牌、费用总额度 | 对应维度不限额 | 显式零为零额度；两级有限额度同时生效 |
| 单次输入／输出令牌上限 | 对应单次限制关闭 | 有限总预算、上游能力和运行时保护继续生效 |
| 模拟本金、单标的仓位上限 | 100000 市场币种、5000 万分比 | 本金大于零，仓位上限不超过 10000 万分比 |
| 买入／卖出费率、最低交易费、滑点 | 均为 0 | 显式非零保持精度及原校验；不代表真实市场免费 |
| 研究步骤上限、研究时限 | 不限制，由模型提交最终决策结束本次研究 | 有限预算、人工停止、独立执行租约及未知结果保护仍生效 |
| 监测标的上限 | 50 | 监测集合有界，原范围校验保留 |
| 行情观察间隔、可成交行情最大延迟 | 30 秒、60 秒 | 仅观察、撮合和已有预约检查，不添加周期研究 |
| 网页搜索、费用币种 | 关闭、USD | 搜索权限及来源配置、模型费用币种校验保持 |
| 市场、选股范围、参赛模型 | 表单默认 A 股／固定池；模型须显式选择 | 协议必须确定市场与范围，选择 1 至 12 个不同且已验证的绑定；固定池必须有标的 |
| 资金币种、时区、日历身份、基准、决策截止、基础设施重试 | 由市场、范围和研究时限生成 | 无需手填；不得猜测日历覆盖或更改已有冻结事实 |

表单可清空默认型数值，保存时采用表中默认值，并在输入框提示默认值。留空不限额与留空使用默认值必须有不同说明。服务端在省略可选字段时采用相同默认值；非法值及明确零不得静默替换为默认值。自主协议兼容字段 `decisionDeadlineMinutes` 随研究时限派生，未设时同为 `null`，不参与设置隐藏截止。旧日频协议不使用此表改变语义。

自主比赛未提供完整日期范围时，不要求预先取得无限未来日历覆盖，创建时 `calendarVersion` 可为空；每次执行、估值及委托到期仍读取 Market 的正式事实，不使用远期占位日期、静态日历或无限委托到期时间。已有冻结日历版本和有日期比赛保持可读。

## 所有权与交付

Desktop 比赛列表提供名称／参赛模型／来源名称搜索、比赛类型／市场／状态筛选，固定按创建时间倒序并支持每页 10／25／50 条分页。筛选、页码和每页数量保存在 URL，改变筛选重置页码；详情返回保留这些条件。旧 URL 的排序参数归入默认时间顺序并清除。搜索框与搜索按钮位于工具栏左侧，新建比赛在同一行右侧，其下放置筛选与清空；刷新保留在页头。服务端在当前 owner 的两类比赛全集上筛选、计数及分页，不把原自主接口的 200 条截断当作全量结果。统一查询为只读单次数据库快照，旧接口与冻结协议不变；无匹配、真实空列表、读取失败和刷新分别表达，清空筛选入口保持可见按钮样式。

竞技场拥有模拟账户、预约、委托、成交与估值；Market 拥有目录和市场事实；AI 拥有模型执行与通用工具审计；DSA 拥有外部搜索适配。共享类型由 schemas、纯领域计算由 domain、请求由 api-client 单向消费。维护 check-boundaries 门禁及 migration matrix，不提高复杂度阈值。

实施状态由[任务](../tasks/2026-11-12-autonomous-model-arena.md)维护。实际检查和运行证据由[实施记录](../evidence/2026-11-12-autonomous-model-arena.md)维护。旧版[竞技场规格](2026-11-05-model-arena.md)继续拥有旧协议。

本地收费资料超出日期覆盖时按需获取最新资料；成功完成检查且没有新增／变更资料时推进已核验覆盖，失败或新资料待处理时保留原范围。DSA 的[独立规格](../../../daily-stock-analysis/docs/specs/2026-11-12-local-rule-demand-refresh.md)拥有刷新、证据和覆盖投影，不改写已冻结的竞技场输入与成交。

## 三市场当前规则证据

### 采样模拟政策 v1

本节定义自主比赛的采样研究合同。自主比赛统一采用 `simulationPolicy: sampled-v1`，本次不建设旧比赛兼容或迁移。该政策用于采样价格研究，实际支持范围及验收由 Task 维护，不据此认证交易所委托、订单簿流动性或完整总收益。

- 三市场股票／ETF 的账户可卖与资金再投资采用[研究模拟账户规则](../design/2026-11-23-research-account-policy.md#买入后可卖与资金再投资)，并随比赛规则冻结。各标的执行仍需证券身份、币种、正交易单位及适用价位、当前会话和合格来源时钟；已知停牌或退市不成交，未知状态不得写成正常。账户政策适用不代表该标的的实际执行输入已齐备。
- 仅收取协议冻结的 `fees`（双侧费率、最低额及滑点），策略与基准相同。公共法定费不额外叠加；缺少资料不解释为已核验免费。证据明确记录固定模拟费用及完整市场收费未计入。
- 默认不模拟涨跌停，策略与基准均不消费每日价格边界，证据记录该研究假设。HK 使用已登记普通股票价位表，US 模拟价位为价格不低于 1 美元时 0.01、低于 1 时 0.0001；不据此认证适用的交易所规则。
- 公司行动读取按用途分开。覆盖不完整时默认无事件，不阻断研究净值及排名，证据保留该假设；已知持有区间事件尚未记账时，受影响标的停止成交及完整估值。现有无事件证据继续复用。新政策不强制每次取得完整无事件证明，不自动把事件当成零。
- 估值及研究不申请新委托执行资格。后续日历只读取实际可卖、交易资金解锁所需交易日；到期日单独按所属委托核验，不能让另一标的远期到期阻断当前观察。未来行情、未完成分钟和历史不可见资料仍禁止。

AC06／AC12 在新政策范围分别验收源码、隔离业务闭环和目标来源消费；旧严格执行资格、真实模型准入、完整历史追平及远端 CI 独立保留，不能用新政策追认旧失败。下文严格制度证据描述继续适用于没有 `simulationPolicy` 的旧比赛。

AC06 的账户政策验收须沿正式领域入口，以隔离账户逐市场核对设计规定的可卖日期、扣款及卖出款再投资，并验证未成交资金预留、份额占用以及策略／基准一致性。文档确认不替代源码、隔离闭环或目标运行态验收。

### 旧严格合同的制度证据

- A 股竞价公共收费与证券可交易性分别核验。现有上交所 A 股包可以用绑定原包的官方正文及附件基线推进覆盖。费用查询返回已核验的费项及来源，成交仍须取得当前可交易状态、适用的价格限制及合格报价。已核验的上交所收费范围按实际交易所和资产类型使用。
- 港股实时研究报价可以返回两项独立参考。每手股数从已有香港股票独立路由读取，保留实际来源与观察时点。港交所常规港元股票 code 01 价位表按生效日期提供各档上限和价位，明确适用证券类型；只有报价币种已确认时才计算该报价所在档位。每手股数缺失保留诊断与可用的价位参考。
- 港股参考规则不授予下单资格。当前交易状态、适用的价格限制、费用、结算及合格报价继续由执行证据核验，ETF 使用其独立规则范围。历史回放继续消费其冻结来源，不把当前每手股数写回历史。
- 美股沿用当前股票／ETF 证据链。已记录的休市延迟报价可用于来源和规则核对，开市撮合仍要求来源时刻及当次会话合格。

### 沪港当前执行输入
