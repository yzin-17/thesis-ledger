# 策略版本关联生成实验

## 目标与合同

正式策略版本的“AI 实验”页签应展示生成此版本的实验，以及以此版本为基线开展的实验。原版本的采纳来源与采纳记录已保存，当前缺口是查询仅匹配基线，且客户端排除了从零探索来源。

- `strategyVersionId` 筛选精确匹配实验基线或 `OptimizationAdoption.formalStrategyVersionId`，不扩大到同一策略全部版本。继续保留当前用户、搜索、状态、来源类型、分页及总数语义；同一实验只出现一次。
- Desktop 使用服务端关联结果，不额外限制来源类型或按基线再次过滤；分别显示“生成此版本”和“基于此版本”。已有创建入口继续锁定当前版本，原实验详情保持可访问。
- Mobile 当前没有版本关联实验列表，不新增入口；公共筛选合同保持兼容。
- 真实业务只读，不回填或重写版本来源，不执行采纳或模型调用；通过正式快更更新本地运行态。

## 验收标准

- AC1：隔离 PostgreSQL 验证采纳版本 v1、v2 和实验基线均能关联原实验；无关版本为空，同实验不重复，总数正确，显式来源筛选仍有效。
- AC2：Desktop 展示两类关系，创建入口与分页继续按当前版本隔离，定向组件测试通过。
- AC3：本地正式快更后，原正式 v1 的实验列表 API 返回原实验；四宽浏览器展示、点击原实验、刷新及返回通过，无真实写请求或页面溢出。
