# 基金持仓未知披露时间

归属 M3 R04。持仓抓取时间不等于公告披露时间。现有来源仅提供季度和持仓时，DSA 必须返回 `disclosureDate: null`，继续用 fetchedAt 记录获取时刻；不得推导季度末或当前时间作为披露时间。

共享 Schema 允许 disclosureDate 明确为 null，既有合法日期仍兼容，不允许字段缺失。绩效估值遇到未知披露时间时沿用不可用路径：零估算调整、零披露/定价覆盖率和诊断，且不读取持仓行情来制造估计。该数据仍可作为当前研究材料，但不能证明历史时点可见。

部署顺序为先消费端再 DSA。验证包括 Schema 的已知/未知时间、实际采样服务的未知时间拒绝、DSA 输出及目标接口。旧实现将同一 fetchedAt 值同时写入 disclosureDate，共享解析层遇到两个时间相等时保守投影为未知，覆盖现存 24 小时缓存及滚动部署期间的旧响应，不修改缓存原始内容或历史证据。独立且不同的已知披露时间保持兼容。
