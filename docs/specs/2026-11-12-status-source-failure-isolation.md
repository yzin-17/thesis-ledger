# 独立状态来源失败的分类与隔离

## 问题与目标

价格冻结问题修复后，`300058.SZ` 的实际复算首轮被独立状态来源的标准 `invalid_response` 错误终止；后续同输入成功。公共费用的不可用响应还沿用旧格式，被误判为 Data V3 协议损坏。修复这两条错误处理链路，避免可选来源的一次坏响应终止整个研究。

## 契约与边界

- AC1：DSA 公共费用与独立状态入口使用 `dsa-data-v1` 错误信封，保留 requestId、稳定错误码及安全中文信息。不可用、权限、限流、参数和格式错误分别表达。
- AC2：Server 区分经过严格校验且关联到本次请求的“来源报告数据无效”与“传输／协议响应无效”。前者可按现有人工配置尝试备用目标；全部来源失败时，组合保留来源失败。错误信封畸形、请求关联错误、成功响应格式或身份错误、认证及政策错误仍立即阻断。
- AC3：可选能力来源失败只冻结失败事实和警告，不伪造正常状态或丢弃其他能力；必需能力缺失仍由既有完整性评估阻断。旧快照继续可读。
- AC4：完成定向合同测试、包级构建与门禁，再通过 infra 最小更新入口同步实际服务。以原失败任务的冻结价格验证正常路径和受控来源坏响应路径，分别记录结果；实际研究记录、账本、路由与 AI 调用保持不变。

不增加外部请求重试次数，不自动启用来源，不扩大来源列表，不恢复真实实验。SDK 当前成功不能证明历史坏响应原始字节；诊断结论必须保留这一证据限制。

## 所有权

DSA 拥有 HTTP 错误生产；Server DSA 适配层拥有来源错误分类与人工主备；Market 拥有状态组合；Schemas 拥有可冻结失败值；Backtest 沿用既有采用规则。实施见[任务](../archive/tasks/2026-11-12-status-source-failure-isolation.md)，运行方式见[维护指南](../guides/2026-11-11-backtest-return-research.md)。
