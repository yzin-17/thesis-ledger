# 策略风险规则的独立通知设置

## 目标与边界

生成策略风险规则时，每条规则可以独立设置严重级别和冷却时间。应用级配置作为默认值，通知开关和渠道仍归应用管理。配置保存在现有通知 JSON 中，不修改策略、监控条件、历史规则或历史通知。

## 行为与验收

- AC1：按稳定的 `sourceKey` 保存单条规则设置。严重级别与冷却时间分别可继承默认值；冷却时间接受 0–10080 的整数，零表示不等待，空输入表示继承。
- AC2：创建、更新和读取保留设置；未知规则键必须拒绝。冻结规则的严重级别、风险事件和通知投递使用该规则的有效设置，其他规则继续使用默认值。
- AC3：升级时按 `sourceKey` 保留仍存在规则的设置，新增规则继承默认值；已移除规则的设置不参与执行或出现在当前编辑器中，历史审计保持原值。
- AC4：生成预览与风险中心编辑均提供逐条控件，预览不可评估也可配置通知。编辑失败保留输入；提交中禁用控件。Mobile 保留并提供相同设置入口。
- AC5：覆盖 1440、1024、768、390 宽度的实际浏览器验收；真实业务数据只读，保存与失败恢复使用受控请求验证。

## 验证归属

契约测试验证输入边界；Server 定向测试验证冻结规则、更新和运行时有效配置；客户端定向测试验证逐条编辑、提交与旧配置兼容；浏览器验证真实组件布局与受控请求。实际运行态使用正式快更入口并独立核对。
