# 策略版本关联回测与实验记录

日期：2026-11-08。对应[归档任务](../archive/tasks/2026-11-08-strategy-version-records.md)及[验收证据](../archive/evidence/2026-11-08-strategy-version-records.md)。

## 目标与行为

用户要求策略详情的“回测记录”和“AI 实验”页签展示基于当前版本创建的记录。服务端已有策略版本关联和按版本过滤接口，本轮修复客户端消费，不新增数据库结构或业务关联写入。

- 回测页签按精确 `strategyVersionId` 读取任务分组，显示当前版本的任务、区间、状态、结果摘要及详情入口，包括准备失败任务。
- 实验页签按精确 `strategyVersionId` 和已有策略来源读取实验，显示名称、状态、阶段、产出、时间及详情入口；保留锁定当前版本的新建入口。历史实验可查看，不因当前策略定义不可执行而关闭记录页签；创建仍要求有效定义。
- 分页与查询缓存按版本和记录类型隔离，切换版本立即清空该范围分页，不暂用上一版本记录。默认每页 20 项服务端分页，主列表和任务详情入口保持原导航。
- 首次加载在结果区中央显示加载圈；同范围刷新保留已有记录并叠放一个加载圈。失败、空态和已有数据分别表达，失败可重试，不用错误冒充空态。
- 新建及后台交付使对应查询缓存失效；活动任务按已有节奏轮询，非活动记录随页签重新进入及共享页头刷新更新。接口沿用现有所有权及结果保护规则。

## 验收

- AC1：精确版本查询、跨版本隔离、分页和迟到结果正确；真实截图失败任务出现。
- AC2：已有策略实验与当前版本精确关联，创建链接锁定版本；空、失败、加载及刷新可用。
- AC3：共享状态与结果展示复用，详情导航、版本切换和全局列表保持；四宽无页面横向溢出。
- AC4：定向回归、构建、静态检查及正式快更通过；真实记录只读，实验展示及创建参数使用受控样本验证，不调用模型或创建真实实验。
