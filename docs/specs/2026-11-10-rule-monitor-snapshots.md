# 资料正文快照与版本差异

日期：2026-11-10。状态：已验收，作为当前行为合同保留。对应[归档任务](../archive/tasks/2026-11-10-rule-monitor-snapshots.md)及[证据](../evidence/2026-11-10-rule-monitor-snapshots.md)。

## 背景与目标

资料版本目前仅保留指纹与观察时间，无法查阅当时正文或理解具体变化。新增采集时正文快照、按版本读取、两个已保存版本之间的文字差异。沿用现有有限监测目录、任务领取及预算，不新增调度器，不修改冻结收费规则。

## 设计与边界

- DSA 拥有抓取、解析、SQLite 快照和差异生成；Market 代理严格合同；Desktop 消费快照和差异。Mobile 没有现存版本界面，此次不新增该入口。
- HTML 保留主体段落及参与摘要的引用链接；DOCX 保留段落；PDF 使用已有 `pypdf` 依赖提取文字，保留原有原始字节指纹语义。资料包保留当时 JSON 的稳定可读格式。原有指纹计算不变，不能因引入解析器制造全量版本变化。
- 快照按资料种类、完整身份、内容指纹唯一保存，随通过租约和 owner 检查的观察记录原子提交。失败和晚到执行不修改成功快照；同一指纹不重复保存。首次保存的可用正文不可覆写。
- 新增独立快照表并递增 SQLite 结构版本；保留全部既有任务、配置、观察和版本。旧记录无快照时返回 `legacy_missing`。以后再次观察到同指纹时可保存当次正文，快照采集时间必须为此次时间，不能回填为最初观察时间。
- 正文上限 250,000 字符，不截断后伪装完整。PDF 解析置于有硬超时的独立进程，限制页数、解压后内容和内存；扫描件、加密件、解析失败、超时及过大均保留指纹并返回稳定的快照不可用原因。
- 新增只读 `/version` 查询：kind、identity、contentHash、可选 baseHash，返回选择版本的快照和明确基准的差异。所选或基准版本不存在返回 404，不静默回退其他版本。内容只作为纯文本渲染，不执行 HTML。
- 差异使用正文分行比较，包含新增、删除、上下文及计数。限制输入总字符、行数与输出行数；超限显式返回不可比较。基准可由用户选择，默认选择列表中的另一个版本；基准和目标均展示指纹和时间，不将最近观察顺序当成发布时间或连续执行历史。
- 版本列表继续按最近观察时间排序，最多 20 个不同指纹。正文与差异按需查询，不把所有正文塞入状态或版本列表响应。查看、切换、重试只读，不发起远端抓取。

## 验证与风险

依次验证确定性抓取与迁移、任务原子写入、DSA API、Schema/Server/客户端身份校验、浏览器交互、正式脚本更新和目标运行态。真实资料只读验证；新采集闭环通过隔离库和受控来源响应验证，目标运行态可对既有配置显式执行一次检查以建立当前快照，不修改配置或历史指纹。PDF 提取是可读文本，不保证与页面视觉排版一致，不实施 OCR。

## 验收标准

- AC1：HTML/DOCX/PDF 与资料包在有效观察时保存可读快照；正文和原有指纹语义一致；不可提取或超限有明确原因。
- AC2：SQLite 无损升级；快照和观察原子提交；重复、失败、晚到执行、重启及旧记录再观察均保持正确身份和时间语义。
- AC3：详情与比较只读，跨身份/非法指纹被拒绝；缺失记录、缺快照、首个版本、文字一致和超限分别表达；差异正确包含新增与删除。
- AC4：Desktop 能选择正文版本与比较基准，展示正文及增删内容；查询、错误重试、刷新和空状态符合既有加载契约；四宽浏览器验收不溢出并保留关闭与焦点交互。
- AC5：通过仓库正式入口使 DSA 和 ThesisLedger 运行态加载实现，验证真实读取及隔离的两版本采集到比较闭环；分别记录真实来源和受控输入证据。

## 未决问题

无。默认不自动补抓全部历史版本；无法获得的历史正文保持缺失。
