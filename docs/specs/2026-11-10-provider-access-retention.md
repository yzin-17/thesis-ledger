# 权限检查长期保留与凭证底部操作

## 目标与行为

当前已保存凭证的功能权限检查结果长期可用，不因五分钟经过、关闭页面或服务重启而失效。复用 DSA 已有权限记录表及私有指纹；凭证、端点或账号等级改变时失效，用户可手动重新检查覆盖结果。缺权限、缺凭证、认证失败与网络待验证仍分别保留。

部分完成及限频后的检查按[限频暂停与接续规格](2026-11-10-provider-access-rate-limit.md)补查待确认项，保留已确认结果；全部完成时仍可手动全量更新。

未保存输入的检查结果继续作为草稿隔离；相同输入在缓存有效期内保存时，原子绑定到新配置代次并转为长期记录，不重复请求上游。没有可复用草稿时，普通来源保存凭证保持原行为，不自动增加权限请求。Tushare 原有等级检查和保存契约保持。

全部来源的“移除页面凭证”按钮统一位于凭证弹窗底部操作栏，与关闭、检查和保存操作同区；保留原确认、取消、禁用和失败恢复行为。正文保留字段、检查结果及说明。

## 边界与兼容

- 不新增数据库结构，复用 `thesis_ledger_account_access`。无账号等级的长期记录不写 `accountLevel:null`，保持现行 schema。
- 权限记录不含明文密钥，仍按凭证指纹与认证端点隔离；启停等无关配置不抹去有效记录。
- 旧版只存在进程内存的结果无法在重启后凭空恢复；需要重新检查取得长期记录，不用截图或推断补造。
- 草稿仍采用有界缓存，只有绑定当前配置的长期记录用于路由选择。网络失败不得被解释为明确缺权限或成功。
- 保留真实凭证、启停、政策与冻结记录；真实业务验收默认只读，持久化和重启场景用隔离样本验证。

## 验收

- AC1：TickFlow 等无等级来源的当前检查结果可持久化，超过五分钟及重启后仍可读取；凭证/端点/等级变化失效。
- AC2：草稿不污染当前记录；同一输入保存可复用检查并原子绑定，配置冲突和迟到结果不会覆盖。
- AC3：各来源移除按钮仅位于底部操作栏，四种屏宽下边界、检查、取消及失败恢复通过。
- AC4：定向测试、相关 build 与边界门禁通过；最终 DSA 镜像包含修正，实际重建后的契约和页面验证通过。
