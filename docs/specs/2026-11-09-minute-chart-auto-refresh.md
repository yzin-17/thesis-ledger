# 分钟行情盘中自动刷新

日期：2026-11-09。任务标识：minute-chart-auto-refresh。本轮[结案任务](../archive/tasks/2026-11-09-market-detail-refresh-controls.md)，首次实施见[历史任务](../archive/tasks/2026-11-09-minute-chart-auto-refresh.md)。本规格继续维护当前产品行为。

## 目标与范围

证券行情详情提供手动刷新图标与默认关闭的自动刷新图标。用户选择分钟周期并开启后，在盘中同步更新实时价格、涨跌幅、曲线及指标。覆盖详情现有的全部分钟周期，继续使用服务端行情及交易日历事实；不修改数据库、Provider 路由、历史记录或原生客户端。

## 行为与边界

- 详情标题栏复用共享刷新图标，点击后重新读取行情；自动刷新使用带中文可访问名称、提示和 `aria-pressed` 的图标按钮，每次打开详情默认关闭，不持久化开启状态。开关在所有周期均可操作；日线等周期可以预先开启或随时关闭，提示说明切换分钟周期后盘中执行，当前周期继续支持手动刷新。
- 自动刷新开启后，默认间隔为 60 秒。仅详情打开、页面可见、周期可用，并且服务端会话明确为 `open` 时自动请求最新分钟行情。关闭开关同时停止定时行情和会话检查；已在途的一轮可完成。
- 通过现有报价能力轻量检查服务端会话，休市期间继续每 60 秒检查，以便开盘后恢复。未知、失败、过期或已到会话边界的状态不能授权曲线自动刷新；不在客户端推算周末、午休、节假日或夏令时。
- 自动行情请求携带 `refresh: true`，在同一详情请求中读取报价、分钟曲线及共享指标，等响应完成后一起投影实时价格、涨跌幅和图表，保留当前周期、复权口径、指标参数和窗口大小。用于日历判断的轻量报价不提前替换页面报价。手动检查最新行情同样更新报价。
- 同范围刷新保留已有曲线并复用图表中央加载圈；最后相关请求结束后收起。失败保留数据及现有重试入口。自动更新不能被旧的“检查最新”页覆盖。
- 切换日线及更长周期、后台或关闭详情时停止自动曲线刷新。历史扩窗的计算锚点用于保持历史输入稳定，自动更新走现有“检查最新”路径，不固定到旧锚点，保留已有历史曲线和当前视图。切换标的、周期与指标参数仍由现有 generation 和 AbortSignal 隔离迟到响应。
- 保留手动刷新、扩窗、回到最新和原导航。静态证券资料中的独立简图、基金估值及自选走势继续使用各自已有请求契约，本次范围为截图中的行情详情。

## 兼容、成本与风险

无新增接口与依赖。会话检查使用现有报价能力，受服务端缓存、来源控制和费用门禁约束；失败保守暂停。分钟曲线自动刷新避免请求筹码、净值等无关能力。60 秒是默认交互选择，非逐笔实时承诺。

## 验收标准

- AC1：默认关闭自动刷新；用户开启后，盘中每 60 秒同步取得实时价格、涨跌幅、分钟线和指标，强制刷新参数及选择条件正确；关闭后停止定时请求。
- AC2：午休、收盘、节假日、未知、失败和会话边界后暂停曲线自动刷新；新的服务端开盘事实可恢复。交易时段不由客户端猜测。
- AC3：同范围更新保留曲线、正确展示加载与失败；历史扩窗仍可读取最新报价及分钟线；切换、后台和关闭后不继续自动提交旧作用域数据。
- AC4：定向行为测试、Desktop 类型检查及构建通过；真实浏览器在 1440、1024、768、390 宽度验证刷新、暂停、恢复、关闭及边界，受控盘中输入与真实休市页面证据分别记录。
- AC5：手动刷新和自动刷新图标在标题栏可见，中文可访问名称与开启状态正确，重复全量刷新入口收敛到标题栏；错误与分段重试入口保持可用。

## 验证与未决问题

通过真实 TanStack Query 和受控服务端响应验证轮询和生命周期，复用现有行情详情测试回归手动操作。Desktop 的宿主页面直接载入当前源码；目标容器输入有变化时使用 infra 的最小更新入口。当前已收盘，盘中外部行情自然更新不能以受控样本冒充。无阻塞设计问题。
