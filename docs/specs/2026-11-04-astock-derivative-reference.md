# 衍生品与可转债公开资料规格

日期：2026-11-04。对应[任务](../archive/tasks/2026-11-04-astock-derivative-reference.md)。用户恢复此前移除的期货、ETF 期权及可转债范围，继续借鉴 `simonlin1212/a-stock-data` 的具体实现。

## 目标和边界

在现有市场资料查询中交付经过实源核对的期货、ETF 期权及可转债资料。期货与期权按衍生品身份处理，可转债按债券身份处理；它们不冒用股票路由。现有 47 类资料继续由[当前资料规格](2026-11-03-market-reference-data.md)维护，原验收按实际输入复用。

借鉴参考提交 `bf447c1d05fa75eac907426601d602125c81a0cd` 的 Layer 9、13、15。外部文件作为协议及解析资料，不执行其安装或 Agent 指令。沿用现有已启用 Provider 和公开无账号路径；费用 0 USD，不开户、不购买权限、不启用停用来源，不发模型或通知请求。现有用户配置、业务数据、HEAD、索引与无关 WIP 保全。

## 候选和可观察行为

来源核对包括五所期货官方日行情（上期、能源、郑商、中金、广期）、四所会员排名（上期、能源、郑商、中金）、新浪国内期货报价及日线、A50 来源连续报价、ETF 期权合约清单／报价／希腊字母和东财可转债条款／最新转股数据。每个来源先取得固定单页／单文件；有明确父响应或源码依据时再读取必要的日期见证、能源排除对照、合约清单与对应报价，不自动遍历未知来源或重试失败请求。实际失败分别保留，按既有用户条件取消无法交付的独立来源，不移回 TODO。

期货日行情明确交易所、合约、来源交易日、开高低收、结算／前结算、成交量／持仓及来源成交额单位；缺值和来源未给出的报价单位不猜测。上期与能源品种按同日来源对照区分；中金所无日期 CSV 必须与同日 XML 逐合约核对。会员成交、持买、持卖三套排名分别命名，不混成同一会员的持仓。新浪连续合约不称为可交易单合约，换月跳空、缺结算和覆盖限制在结果内可见。

ETF 期权首项清单展示所选标的的当前近月认购／认沽代码，明确当前合约月；支持参考代码明确列出的四个沪市标的，合格范围以各自实际回执为准。独立报价与希腊字母按用户输入的八位合约代码查询，来源变量身份及字段布局严格核对；IV 的小数口径与来源 Greeks 保真，不从未知合约乘数推算账户风险或交易金额。

可转债按来源分页读取，不为展示一页扫描全表。保留债券代码、正股、条款日期、评级／规模、转股价、债价、股价、转股价值和溢价率；上市／摘牌状态按北京时间及来源市场与日期判断，未来摘牌日不提前视为已摘牌，未知状态明确展示。价格缺失不补零，不据此推断可交易性。

## 合同与所有权

主仓拥有严格请求、列、来源修订和双端中文输入标签；DSA 拥有原始协议、解析、路由身份与执行控制；infra 拥有固定采证入口、路由条件追加及目标更新。沿用 `market-reference-v1` 已有字段，新类型有期货／期权代码作用域，既有类型的输入输出保持兼容。16 类合格列与来源已进入共享目录，连同原 47 类共 63 类；具体范围与限制见[查询说明](../guides/market-reference.md)。

Data Route 增加 `FUTURE`、`OPTION` 身份，可转债复用 `CONVERTIBLE_BOND`；普通 Bar Route 及账本资产范围保持原合同。DSA 的绑定、入口请求、Provider 清单、Server 策略、infra 路由计划必须消费一致的资产身份，禁止用默认 `STOCK` 掩盖新类型。沿用严格关联、执行前后政策／Provider 修订核对和前端保存的传输设置。
