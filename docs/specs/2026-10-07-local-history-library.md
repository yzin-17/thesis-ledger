# 中国内地公告获取与状态读取

> 任务标识：LOCAL-HISTORY-LIBRARY
> 日期：2026-10-07
> 状态：当前产品契约；本轮实现与目标验收已完成
> 对应任务：[历史实施记录](../archive/tasks/2026-10-07-local-history-library.md)

## 目标与范围

为 `official-states` 增加有界、手动触发的程序化公告获取，保存多家公司公告，在现有资料列表展示，并解析一种明确的停／复牌日期表达供现有状态接口读取。来源身份、主备选择、页面布局和 P6 执行模型保持。收费、分红和其他市场继续沿用各自读取器。

依据[现有展示契约](2026-10-07-local-history-package-display.md)和[历史规则主备契约](2026-10-06-historical-rules-primary-backup.md)，状态源按配置直接读取。标的匹配、日期、引用及字段校验由读取器完成，新增公司的有效事实可直接使用，不增加人工批准。

## 数据获取与保存

- 巨潮公告查询接口按用户指定日期和关键词分页；首版支持停牌、复牌及风险警示，按规范证券代码筛选。页数有明确上限；截断、查询失败和下载失败分别报告。
- 保存公告身份、标题、证券、发布日期、原文地址、获取时刻；元信息有效即进入列表。下载状态与解析状态独立，未解析或下载失败的公告仍可查看原文链接。
- 同一官方公告标识重复获取只更新该记录；原件下载后保存 SHA256。原文与JSON记录保存到 DSA 现有 `DATABASE_PATH` 相邻的资料子目录，使用原子文件替换；不新增数据库表、挂载或完整版本平台。
- CLI 和认证的显式 Control POST 保留为维护入口；目录查询、检查和状态读取不触发网络获取。单件失败不阻止其他公告保存。回测配置准备触发获取、历史缓存和每日增量更新的现行契约见[回测公告自动准备](2026-10-08-announcement-preparation.md)。
- 元信息检索数、下载成功数、已解析数分别统计，不能将它们混为公告总数。
- 既有固定资料作为已验证种子继续使用，其身份、状态和修订可重放；新增公告按库中证券选择，不为每家公司增加 Provider。

## 列表接口与展示

DSA 提供认证只读公告查询；Server 验证合同后透传；Desktop 使用 TanStack Query 查询。每页50条、上限100条，以稳定的公告标识排序支持标题／标的过滤。页面保持现有来源行与Sheet，公告项显示标题、发布日期、标的、用途、下载／解析状态及原文。过滤无匹配、空库、加载失败分别回显。

服务端清单以可选 `documentCatalog: announcements` 声明目录能力。只有声明该能力的 `official-states` 使用公告库查询，其他来源及旧服务端继续显示原有清单。旧皇台原文与新增抓取的同一公告按稳定身份或原文链接去重，保留停复牌和风险用途。查询无需先通过状态或覆盖检查。

## 状态读取

首次解析支持正文中带完整年月日的明确停牌／复牌表达；计算事实保留生效日与原文定位，不从抓取日期或标题推定。扫描件、歧义表达、进展公告或冲突不强行解析，列表标明未解析／待核对。

状态读取对请求窗口逐日返回已核实事实，其余日期为 `unknown`；局部未知不拒绝全部已知结果。未收录标的保持现有缺失返回；损坏事实、错标的或互相矛盾的已知状态不能伪装成功。不同公司不会串用资料。某个计算依赖缺失状态时由既有主备与已选研究假设决定，不让资料缺口导致整个来源失效。

既有种子资料的风险及涨跌幅事实保持；首版获取的风险公告可以展示而尚不产生结构化风险事实。计算结果复用现有冻结模型，不回填历史快照。

## 验收标准

- AC01：官方接口实际获取至少两家公司、三份不同公告；有界分页和原文地址核对通过，无需手写公司公告JSON。
- AC02：公告可幂等保存、重新加载；下载或解析失败仍可展示；各阶段数量分别统计；已存在资料不因部分失败消失。
- AC03：生产认证API、Server及现有Sheet展示真实新增公告，支持查询／分页及失败回显，现有布局、凭证和下拉焦点行为保持。
- AC04：至少一种明确停／复牌表达成功从真实原文解析并经现有状态接口读取；新增公司无独立准入记录仍能读取有效事实。
- AC05：请求中已知状态正确，其他日期未知；错标的、矛盾事实、原件摘要错误被拒绝；旧000995风险／交易事实和修订回归通过。
- AC06：定向测试、受影响包构建、边界检查、正式目标API和浏览器证据分别记录；资料位于既有持久卷目录，重启保留验证单独记录。

## 当前核实与边界

2026-10-07真实巨潮查询已核实多公司与分页；目标获取四家公司六份公告，六原件均下载，四份明确停复牌解析、两份保留未解析。2026-10-08正式DSA镜像固化、新公司HTTP、列表与持久卷重建保留验收通过。读取没有逐公司人工准入；当前合同只解析明确停复牌表达，风险公告先展示。使用纯Python `pypdf`，依赖变化仍须通过正式完整更新入口部署。

本轮不承诺全市场完整历史，也不推断“无公告等于正常交易”。机器接口失败是获取阶段的结果，不影响既有列表与资料读取。
