# 回测与优化的连续提交

[实施任务](../tasks/2026-11-06-strategy-prepared-submission.md)。用户填好策略、资金、时期、价格口径与预算，在同一入口提交准备和运行意图。准备、创建和读取结果分别可审计。适用普通回测、基金净值回测、既有参数优化和发现实验。

- AC1：意图保存身份、输入及所有者，重复提交同一意图复用原结果。准备过程中关闭客户端，后台仍能推进或保存具体阻塞。
- AC2：后台创建实验仅接受已登记输入和输出均零价的模型，模型费用预算上限为零。沿用原来源、冻结、预算与版本门槛。输入有新增需要核对的来源限制、净值假设或费用决定时，展示冻结结果并等用户确认，拒绝用新证据替代已确认内容。
- AC3：两端可从原入口提交并找回原结果，失败与等待可区分，旧的显式准备及回测记录可读。
- AC4：受控验证准备、阻塞、重复、停止和恢复，不调用真实模型、付费行情或改变开关。
