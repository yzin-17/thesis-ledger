# 策略收益研究的价格输入

日期：2026-11-11。任务：[实施与验收](../archive/tasks/2026-11-11-backtest-return-research.md)。来源核验：[现有数据可行性](../evidence/2026-11-11-backtest-return-research-feasibility.md)。首次实现与运行边界见[验收记录](../archive/evidence/2026-11-11-backtest-return-research.md)，原任务完整窗口的追加验收见[价格对切换记录](../archive/evidence/2026-11-11-backtest-price-pair-recovery.md)。

2026-11-21 当前源码合同按[实际依赖整改规格](2026-11-20-backtest-practical-design.md)补充；部署状态与真实模型证据分别见其Task，不由本说明推定。

## 目标与适用范围

普通新建回测以策略收益研究为主：后复权序列用于指标、模拟操作与持仓估值，不复权序列用于具体价格条件。输出所选供应商冻结序列及明确研究假设下的模拟盈亏、收益率、回撤和资金曲线。

首轮覆盖同一股票或 ETF、同币种、日线研究。默认后复权；已有历史任务继续按原协议读取和重放。这里的模型收益不认证为真实账户收益、完整总收益或真实可用现金，不因来源标为后复权就假定其采用特定分红再投资算法。

普通研究不读取完整权益事件表，不模拟分红应收及到账，不恢复真实持仓的拆合股数量变化。公司行动策略信号、通用跨坐标数值换算、跨币种和多标的研究不属于本轮。

## 已确认选择

- 用户已确认：以策略收益研究为主，默认后复权，具体价格条件用不复权，不追求真实现金到账还原。
- 固定金额、按权益比例和目标权重继续表达研究资金投入。
- 用户已确认固定份数的含义：以模拟操作当时的不复权价格计算投入金额，再换成研究单位；输入份数作为投入参考份数，不表示后续真实持仓数量。

## 策略表达

每个价格来源的含义随策略版本保存，不由运行时单一复权选项改变整条策略。

| 表达 | 价格语义 |
| --- | --- |
| 收盘价低于 4 元 | 当日不复权收盘价与实际价格常量比较 |
| MA5 上穿 MA20 | 默认使用同一后复权收盘价序列计算 |
| 收盘价高于 MA20 | 两侧使用同一后复权坐标，并显示该口径 |
| MA5 高于 4 元 | 使用不复权序列计算价格型指标，与实际价格阈值比较，预览中明确口径 |
| MACD 高于零轴 | 指标默认使用后复权；零轴不依赖价格整体缩放 |
| 持仓成本、数量与百分比风控 | 使用研究账本的成本、研究单位和现有研究风控语义 |

编辑器与自然语言生成器复用同一规则，直接显示“实际收盘价”“后复权 MA20”“研究单位”等标签。复合策略可组合不同坐标的独立布尔条件，例如“后复权均线交叉，且实际收盘价低于 4 元”。

任意两个价格数值直接比较时必须属于同一坐标；实际价格与后复权指标直接比较，在保存或准备时指出具体条件，并提示选择同坐标输入或拆成独立条件。不得根据一对原价与后复权价格的比值推断通用转换关系，不静默改写指标或阈值。

## 两套输入与最小依赖

- 后复权行情是研究操作、估值和基准的共同价格输入。
- 仅当具体价格条件或固定份数投入需要时，读取不复权参考行情；纯指标、固定金额策略只需后复权行情。
- 原价参考与后复权行情按[独立来源合同](2026-11-12-independent-research-price-sources.md)各自选择已配置并准入的主备路由，可使用不同提供方和上游；校验标的、市场、币种、周期、时间与字段，分别冻结版本、来源和主备索引。每条路由自行处理来源暂不可用和备用选择，已取得的另一套行情保持原样；冻结后和历史重放继续使用各自的冻结身份。路由失配、单套证据冲突、预热不足等合同错误继续拒绝，失败保留窗口和底层稳定原因，不保存新路由或引入未配置提供方。
- 两套行情按会话时点关联，不按数组位置拼接。复用共同 Reader、来源选择及覆盖检查；冻结两套行情及研究参数后，Worker 可离线重放。
- 原价参考采用显式价格研究读取语义。未知上市日期和未证明的可交易状态保留未知，可在既有固定快照研究假设下处理；不将参考行情读取认证为真实成交能力。不能仅因原价参考缺少真实份额执行证明而要求完整权益事件。
- 仍需精确证券身份、可用交易日历、有效价格及指标预热。缺 Bar 不补价、不生成成交；具体条件的参考时点缺失时记为不可评估，固定份数所需的模拟操作时点原价缺失时记为未执行，均给出原因和统计。整个范围无法形成研究窗口时准备失败。
- 后复权价格必须有效且为正。显式dailyObservationVersion=2的价格研究可消费observed-price-only，成交量未知保持null，不授予真实份额执行资格；缺省及版本1继续原正量合同与原摘要。缺量只限制实际依赖量的VWAP、过滤、参与率等；字段全空及实际预热不足不能声明能力可用，不引入统一覆盖率门槛。真实整手和价位、官方历史费用表、完整权益覆盖及复权因子表不作为普通研究的共同前置。

## 研究资金与数量

复用现有归一化序列记账。设模拟操作时点后复权价为 H，不复权价为 R，投入金额为 B，持有研究单位为 n，研究资金余额为 C：

- 买入研究单位：n = B / H；资金余额扣除 B 和研究费用。
- 固定份数 Q 的投入金额：B = Q × R；随后仍按 n = B / H 记账。
- 持仓研究价值：n × 当期后复权价；模拟权益为 C 与各项研究价值之和。
- 卖出时按研究单位与当期后复权价计算模型收入并扣除研究费用。

固定份数的投入换算是本模型定义，不声称由 H / R 推导出供应商通用复权因子。研究期间不再追加序列之外的权益现金流。

沿用下一可交易日开盘的模拟操作时序和显式研究结算假设；使用操作时点的开盘价，不能偷用当日收盘价。费用继承已有研究模型中可执行的策略配置；依赖实际股数或尚未实现的收费方式时，在准备阶段具体拒绝，不假定收费为零。所有运算复用 Decimal，原始精度和存储值不因显示格式而改变。

该模型的收益取决于来源的后复权方法与冻结版本。后复权序列整体乘以正的常量时，固定投入金额得到的研究权益与收益必须保持不变。

## 准备、结果与兼容

准备顺序为：静态规则与坐标检查 → 联合提取入场、退出、保护、委托、仓位、估值与撮合依赖 → 按需读取、对齐并冻结Market窗口 → 正式创建先保存queued → Worker物化快照、模拟与分析。必需原价缺失具体阻断；可选额外能力缺失仍可prepared，保存本次dataScope。幂等同键同内容先找回原Run，不被后来的路由变化遮住。Worker只组装已确定的研究输入，不重新选源或裁短日期。

结果直接展示“模拟盈亏”“研究权益”“研究资金余额”和“研究单位”。模拟操作明细同时列出使用的后复权价、存在时的实际参考价、投入金额及研究单位；固定份数只标为投入参考份数。页面简要说明采用供应商后复权序列，资金余额属于研究模型。指标、图表、导出及基准使用一致语义和相同研究费用假设。

接口以显式价格研究子协议 `price-research-v1` 表达上述模型，扩展现有 V3 运行配置、快照与结果；策略 Schema V3 保存来源坐标。子协议由准备、冻结、重放和执行共同校验；未携带子协议的历史输入按原路径解码，不填默认字段来改写旧摘要。现有 JSON、字符串模式字段与 Artifact 存储承载新增内容，不新增业务表、队列或提供方转换端点。

旧策略发起新研究时先展示口径投影并确认，保存新的不可变策略版本；旧版本、任务、快照和结果保持原语义。原失败任务保留，不能将新准备结果回写成旧任务成功。当前普通默认规则文档继续描述已部署行为；本规格仅约束后续新模式，实施上线时同步当前设计和指南。

## 所有权与验证

Schemas 维护坐标和研究协议；Domain 维护规则求值、投入换算及研究账本；Server Backtest 维护规划、准备、冻结与任务执行；Market 及 DSA 维护明确的研究行情读取。客户端消费统一结果，不能自行换算收益或解释后复权来源。跨模块调整同步维护边界门禁。

验收按定向测试、受影响包检查、仓库门禁、目标运行态逐级执行。实现通过后使用受控样本验收真实 Server／Worker 闭环，真实来源仅做只读行情及准备检查；业务创建或路由保存需另有明确执行授权。

## 验收标准

- AC1：新策略默认后复权；实际价格常量条件、同坐标指标条件及独立混合条件的显示与求值一致，错误跨坐标比较在创建前具体拒绝。
- AC2：纯指标策略不读取原价参考，普通研究不读取权益事件或因子；两套行情按时点匹配，单套来源证据错配、缺价格及未使用字段的处理符合本规格。
- AC3：固定金额、比例及目标权重投入产生可复算的研究权益；固定份数以操作时点的原价计算投入金额，再换成研究单位。后复权整体缩放不改变投入和权益，费用、开盘时序及缺参考价未执行行为正确。
- AC4：准备检查、创建和 Worker 共用冻结协议；两套行情、参数与缺口可追溯，断开 Provider 后离线重放一致。
- AC5：结果、基准、图表和导出显示研究资金与单位，历史记录保持不变；Desktop 与 Mobile 使用同一合同。
- AC6：定向与包级检查、边界门禁、四种代表宽度浏览器、受控运行闭环和代表窗口真实只读准备分别留有证据。当前文档工作不代表这些实现验收已通过。
