# 覆盖诊断按大类隔离更新

状态：已实现并完成本范围验收。任务见[实施清单](../archive/tasks/2026-11-10-routing-category-coverage.md)，验证见[验收记录](../evidence/2026-11-10-routing-category-coverage.md)。承接[可用来源推荐](2026-11-10-routing-available-recommendation.md)的草稿诊断展示合同。

## 问题与行为

当前任何大类草稿发生变化，面板都会清空全部大类的诊断，导致未编辑大类的徽标和异常说明同时消失。推荐规则本身只替换目标大类；展示状态必须遵循相同范围。

- AC1：按每个大类的规则和精确能力范围判断草稿变化；修改某类只让该类显示“待保存”，其他类保持已有诊断、主备与单独配置数量。
- AC2：连续修改多个大类时，仅这些类显示“待保存”；恢复某类原配置后，该类恢复已保存诊断。保存前检查成功时消费当前草稿诊断，返回继续修改时仍按大类隔离。细分面板复用相同投影。
- AC3：采用建议的实际规则及请求继续只修改目标大类，不新增业务保存。定向测试验证多类、范围变化、恢复及预览；四宽浏览器对比未编辑类的选择、徽标和计数，检查布局并拦截保存。

## 所有权与范围

Desktop 路由编辑功能持有纯诊断投影，沿用当前共享草稿和预览 API；不改变推荐算法、服务端编译、数据目录或保存协议。
