# 基金净值成本参考与区间测量

日期：2026-11-08；任务标识：fund-nav-reference-measurement。
对应[实施任务](../archive/tasks/2026-11-08-fund-nav-reference-measurement.md)。

## 目标与边界

为场外基金历史单位净值图增加当前持仓成本参考线和双点区间测量。保留净值右轴、累计盈亏左轴、成交买卖点、日期区间、来源状态及原始精度。今日盘中估值继续使用已有图表，本轮不增加其参考工具。只修改 Desktop 图表与本地展示合同，不新增 API 请求、交易操作、数据库或 Provider 配置。

## 行为合同

- AC1：工具置于默认收起的“参考与测量”区域。成本参考默认关闭，数值由图中成本线标签显示；持仓代码与基金一致、账户及实际/模拟模式明确、存在有效持仓成本与数量、币种可比时才能打开。现有 Server 将 `.OF` 净值按 CNY 语义记录，客户端只允许 CNY 持仓比较；缺少信息或币种不符时通过成本旁的共享图标说明展示具体原因，不换汇或猜测成本。
- AC2：成本线使用右轴，标明当前持仓成本，开启时保证成本值在右轴显示范围内，关闭后恢复正常自动刻度；不影响左轴累计盈亏。只使用当前持仓成本，不推断历史成本。
- AC3：测量在有实际净值记录时可用，依次点击起点和终点，显示两点日期、净值、差值、涨跌幅和包含首尾的净值记录数；反向及同一点均可测量，零起点不产生无穷值。工具在选点及持有结果时保持选中；再次点击关闭后隐藏选点提示、错误提示和结果，不重新启动选点。蒙层复用现有完整图高的时间区间图层，保留连线及端点；缩放和窗口变化时跟随坐标。
- AC4：测量时优先消费图表点击，点击成交标记不弹出成交详情；完成或取消后成交详情仍可用。Esc 优先取消正在进行或已完成的测量，不关闭行情详情；日期、区间、成交详情等上层弹窗先自行处理 Esc。账户、模式或基金变化后不保留旧参考，切换日期区间不改写净值与持仓事实。关闭成本或重新测量时释放旧参考资源。
- AC5：定向测试验证计算、成本条件、坐标资源和隔离；实际浏览器覆盖 1440、1024、768、390、成本显示与关闭、完整高度蒙层、测量结果、取消及原成交入口；真实持仓页面只读核对。

## 实施原则与验证边界

纯测量概念由行情图共同模块持有，基金直接消费单位净值记录，不构造虚拟 OHLC。通过原有图层资源和共享控件组合呈现；成本不可见时不能仅创建价格线而不调整右轴。真实数据只读，边界输入与故障通过受控样本验证。来源可比性以当前合同为限，不扩大到未确认币种。
