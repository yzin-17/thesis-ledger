# 基金披露日期证据与保守可用边界

承接[组合走势原 Spec](2026-09-07-portfolio-valuation-series.md)及 [R3/T4.I2](../archive/tasks/2026-08-28-portfolio-snapshot-system.md)，只补齐当前基金披露输入的真实缺口。实施及验收已完成，见[本仓归档 Task](../archive/tasks/2026-10-21-fund-disclosure-date-evidence.md)、[DSA 归档 Task](../../../daily-stock-analysis/docs/archive/tasks/2026-10-21-fund-disclosure-date-evidence.md)与[真实来源/分钟记录](../tasks/evidence/2026-10-21-fund-disclosure-acceptance.md)。用户于 2026-10-21 明确允许本次及后续全部验收、不再逐项确认；本合同不新增 Provider、永久路由、产品入口或模型调用。

## 当前问题

Eastmoney SDK 投影只有季度与持仓观察，`disclosure_date=None` 是正确降级。当前已经核对 `161725.OF` 的 2026 中期报告及管理人披露公告，能证明报告期、逐项证券及比例、实际披露日，但不能证明该日的精确时分。不能把抓取时刻、报告期末或人为指定的午夜填作精确披露时间。

## 来源和资格

- 初始受控参考仅覆盖 `161725.OF/2026-Q2`。正式报告正文与管理人披露公告分别保存 URL、字节摘要、实际报告页及本次核对时刻。参考数据是版本化来源输入，不是缓存、生成产物或样本替代。
- 报告第 7.3 节的 17 个指数投资及 57 个积极投资证券保留原披露比例，总计 94.77%；不能混入第 7.4 节的期内买卖表，也不把 0.00% 补成正数或归一到 100%。
- 只有 SDK 返回的规范 symbol 和原比例逐项匹配参考，且基金/报告期一致，才附加匹配证据。允许 SDK 只返回真实披露子集，不替 SDK 增加持仓；证券名称保留审计，不以名称推断身份。每项误差只允许十进制转浮点造成的 `1e-12` 范围，不接受另一个百分比刻度或归一权重。
- 未登记基金或季度保持原未知语义；已有参考但持仓不匹配时返回明确的证据不匹配状态，保留观察数据，不冒充已知披露。受控参考损坏或合同无效必须暴露错误，不能静默当作无参考。

## 兼容数据合同

V3 现有 `disclosureDate` 保持不变；没有精确时分时仍为 `null`。新增可选 `disclosureEvidence`，未提供时按旧合同处理，旧消费者会继续安全降级。

匹配证据携带 `status=matched`、`fundSymbol`、`reportPeriod`、`precision=DATE_ONLY`、原始 `publishedOn`、`timezone=Asia/Shanghai`、`referenceObservedAt`、`availableAt`、`referenceVersion`、`holdingsDigest`、匹配/参考项数、匹配算法及两类来源引用。`holdingsDigest` 必须绑定当前观察摘要，项数必须等于本次观察数组；来源至少覆盖报告正文和披露公告。参考版本覆盖全部参考事实、来源与核对时刻，不与持仓观察摘要混称。

本阶段只实现中国基金的已知日期证据。日期结束边界是下一上海自然日零点：

```text
publicationUpperBound = 次日 00:00 Asia/Shanghai
availableAt = max(publicationUpperBound, referenceObservedAt)
```

`availableAt` 是推导的保守使用边界，不是实际披露时间；不能写回 `disclosureDate`。新增时刻采用毫秒精度、显式时区。核对时刻不得晚于本次来源观察；报告期末、披露日及核对时钟不得自相矛盾。

不匹配证据使用 `status=unavailable`、`reasonCode=holdings_mismatch` 和精确参考身份/版本，不携带可用时刻。它与“没有登记参考”分开，不强迫行情读取失败，也不升级为合格披露。

## 消费规则

1. 有真实精确 `disclosureDate` 时继续使用原时刻；日期证据只能在其为空时使用，不能覆盖矛盾的精确时间。
2. 匹配证据只有在 `availableAt <= 估值时点` 时可用。晚于发布日期结束或晚于本次核对的历史点均拒绝；不据今天的核对回填过去分钟线。
3. 未匹配、未来、未知或格式矛盾的证据维持原低覆盖，不请求底层证券。原披露权重不变；权重为零的证券不请求报价和锚价，不影响估值或可定价覆盖。
4. 分钟证据同时保留原 `disclosureDate`、日期证据和实际采用的可用边界；只表明保守估算，不冒称正式 NAV 或完整历史 PIT 原件链。

## 独立验收

- AC1：来源身份、报告范围、74 项及两类字节摘要由当前公开原文与可视表格核对；只用准确匹配子集，篡改/归一/错期不附加可用证明。
- AC2：Python 标准结果、实际 API 转换和 TypeScript Schema 一致；未知旧响应兼容，冲突不被可用状态掩盖。
- AC3：日期边界与核对时刻取更晚值，整日内未知时分不提前放行；未来证据不查询底层行情，零权重不产生外部请求，比例不放大。
- AC4：定向、包级和物理独立进程合同通过后，经正式脚本同步目标并核对保护数据和实际加载代码；来源启停和凭据不变。
- AC5：按已获验收授权完成有限真实持仓读取及基金分钟/Web 独立证据，本次参考和确定性测试不代替目标实源或真实点位。
