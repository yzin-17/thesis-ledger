# 标的搜索选择公共组件

日期：2026-11-06

## 目标与范围

全部可编辑标的代码入口支持按代码或名称搜索真实目录并选择，Desktop 和 Mobile 分别复用各自运行时公共组件。覆盖创建、编辑、导入修订、研究、策略、复盘、行情查询与代码筛选。目录管理及公告全文检索已经提供结果列表，保留原有检索；只读、冻结代码与高级 JSON 不强行改成选择器。

## 行为合同

- 搜索使用既有 market.searchInstruments 与 TanStack Query，传递取消信号；防抖使用已安装 es-toolkit 1.51.0 的 debounce，清理时 cancel。
- 显示名称、规范代码、市场，使用目录 ID 区分同代码不同市场。失败、空结果、加载分开显示；旧查询结果不可被选择。
- 目录选择只更新调用方字段，不自动 confirm、创建持仓、保存或扩大来源权限。既有持仓确认和业务校验仍归调用方。
- 支持市场、资产类型及业务 predicate 限制。手工代码原有合法入口继续可用；目录身份必需场景只接受所选目录对象。
- Desktop 使用现有 Base UI/shadcn Combobox，保留键盘导航、Escape、清除、可访问名称与 portal；Mobile 使用公共 Field、Action、QueryList。
- 真实业务数据只读，提交与故障恢复用受控样本。共享工作区其他任务改动不得覆盖。

## 验收

- AC1：盘点记录每个代码入口的接入或保留理由。
- AC2：搜索、选择、清除、外部回填、禁用与取消不改变原业务语义。
- AC3：限制、空结果、请求失败、竞态及键盘行为有测试。
- AC4：关键页面 1440/1024/768/390 实际浏览器验收，检查滚动、浮层、焦点环与导航。

## 衍生品补充范围（2026-11-07）

普通 Instrument 目录的股票/基金同步所有权与合约资料分开。补充 Market Reference 专用合约选择器：复用既有五所期货日行情与四只 ETF 的近月期权清单，由用户明确选择来源、交易日或 ETF 并点击读取，单次最多 20 行，翻页仍须显式操作。搜索仅过滤本次真实来源页；来源、日期、近月及非完整覆盖语义直接显示。失败、变更条件或新请求在途时，旧候选不得选入。

合约代码按既有资料输入合同消费，不创建 Instrument/Asset、不拼接股票市场后缀、不把成交/持仓可交易性扩大到衍生品。不扫描所有月份/交易所、不根据数字猜测郑商所世纪或生成主连代码。无对应真实候选时保留手工输入并明确来源覆盖。

稳定的资料页→合约候选投影由 api-client 的 Market Reference 消费契约拥有，Desktop/Mobile UI 分别组合现有公共搜索组件；不向 schemas/domain 添加 UI 编排或 Provider 调用。原服务端路由、权限、预算及响应关联检查保持。

AC5：两端可从真实来源页搜索与选择合约，覆盖来源错误、空页、分页、条件切换、迟到响应、代码格式与禁用旧候选；受控样本与实源验证分别记录。
