# 自选与共享标的详情规格

标识：watchlist-foundation。首次建立：2026-11-05。[实施任务](../tasks/2026-11-05-watchlist-foundation.md) · [方案来源](../reviews/2026-11-05-thesis-ledger-feature-proposals.md#10-codex-本地复核)

## 目标与页面

用户无投资账户也可以跟踪一个标的，打开走势、资讯、公告和已有研究。Desktop 的「自选」及 Mobile 的「市场 → 自选」负责名单；目录、持仓和自选打开同一标的详情。详情给出近期分析摘要及生成时间，「查看报告」或「发起研究」进入研究助手并携带规范标的身份。返回恢复原分组、筛选、排序与滚动位置。模拟成交叠加由[模型竞技场](2026-11-05-model-arena.md)在有成交后接入；本阶段独立验收。

## 关系与写入

Watchlist 拥有服务端身份与 Instrument.id 的唯一关注关系。服务端从 CurrentIdentity 取 owner；分组、批量移动与排序同样校验 owner。添加时须为有效目录标的，同代码不同市场分开；重复添加返回原记录。同一条目至多一个单层分组，“全部”是筛选，“未分组”是缺省。删组保留成员。组内按置顶、人工顺序、稳定 ID 排列；移动和排序原子更新，修订冲突让调用方重读。目录停用后可移动或移除旧关注。移除关注保留历史研究、比赛与账本。客户端缓存按服务地址和身份隔离。

关注操作和研究选择均不确认 Asset，不改持仓、账本、账户修订或历史快照。Market 按完整代码与市场批量投影名称，未知回退代码。有账本读取权限才返回相应 actual／shadow 持仓提示；无权限或读取失败保留未知。名称投影、无持仓详情和基金币种资格遵循现有 Market 合同。[只读标的解析](../../apps/server/src/market/instrument.service.ts)、[移动选择器](../../apps/mobile/src/features/market/InstrumentPicker.tsx)

## 行情与资料

范围为目录中有效的股票、ETF 与境内 OF 场外基金；支持关系按 SH／SZ／BJ／HK／US／OF 实际身份判断，数据覆盖逐市场记录。列表默认每页 50 项，进入、切页和手动刷新只读可见集合；股票／ETF 每批最多 100、并发上限 8，基金当前正式净值同样有界（最多 8）。列表不拉历史；切页取消或丢弃旧响应。股票标 marketTime，基金标 navDate；无前值则留空。无值、已有陈旧值和局部来源失败分别呈现。详情净值历史走 persistIdentity=false；无币种证明的基金沿用研究资格错误。列表故障不阻断管理。[报价读取](../../apps/server/src/market/market-quote-batch.ts)、[详情路径](../../apps/server/src/market/market-detail.service.ts)

详情按规范标的与时间窗口分页读新闻／公告，按发布时间展示、去重、标明来源及可用原文；将零条、部分结果、不可用分开。市场快讯独立展示。报告按当前身份、标的和已保存范围查询；浏览不触发模型。股票／ETF 走势、基金净值优先复用现有详情。自加入以来涨跌、候选对比、事件日历和提醒属后续增强，本合同验收基础列表与详情。

W06 基金公告从 DSA 已核验披露参考读取正式报告、披露提示、发布日期和原文，按完整场外基金身份与查询窗口筛选后分页。该列表表示已收录资料；其他公告可由用户打开对应基金的公开公告目录。新闻按基金身份独立核验，管理人动态、股票同码结果及历史报道不能计入当前标的新闻。


## 验收

| 标准 | 可验证结果 |
| --- | --- |
| W-AC1 | 无账户添加后重启仍能查到，移除后再次重启查不到该条目；重复添加保留分组，跨市场同代码各有独立身份。 |
| W-AC2 | 两身份间读写、分组和持仓提示隔离；两端共享本人变更。删组、目录停用、并发排序均可恢复，无条目遗失。 |
| W-AC3 | 以满页 50 项含重复请求、缺价、旧价和基金的场景核对上游请求数、并发、日期及取消；进入列表无逐行历史请求，刷新失败仍能分组。 |
| W-AC4 | 从目录、持仓和自选打开同一标的；资讯可溯源，查无与失败可辨；在研究助手查看同身份报告或由用户主动提交，返回保留原筛选。 |
| W-AC5 | PostgreSQL 与真实 HTTP 前后核对 Account、Asset、关联、Position、LedgerEvent、Trade、账户修订及已有冻结记录；Mobile 关注／研究选择不引入确认写，原持仓确认路径仍可用。 |
| W-AC6 | 保留数据升级后结构 head、打包输入、服务和两端实际入口均验证；市场样本逐项注明缺失或可用范围。静态、受控、目标运行证据分别记录。 |
