# 风险中心 AB 组合交互规格

## 背景

现有风险中心将模式切换、规则创建、扫描、规则治理、历史事件和通知状态全部平铺在一个页面。用户进入页面后无法快速判断当前风险，也容易把规则配置误解为只作用于当前实际/模拟模式。规则创建表单还承载了“扫描当前组合”操作，删除操作实际是归档停用却使用了删除文案和浏览器确认框。

## 目标

- 默认进入“总览”监控视图，提供当前模式下的风险摘要、数据时点、扫描主操作和事件摘要。
- 提供“规则”工作台：左侧规则列表、右侧规则详情，集中承载测试、编辑、启停、审计和归档。
- 提供独立的“事件”“通知”页签，使用清晰中文标签、Badge 和 Empty 状态。
- 实际/模拟模式只影响组合数据、扫描和事件；规则配置和规则列表不随模式切换，模式由路由层 portfolioMode 与 portfolio 数据驱动。
- 使用右侧 Sheet 承载新建/编辑规则，共用同一编辑器；表单按类型和范围渐进显示字段，提供自然语言预览、内联校验和创建后立即启用。
- 保持现有 Risk API、规则版本、事件时间、通知状态和查询语义，不虚构后端没有提供的风险状态。

## 交互与数据边界

### 页面导航

页面使用顶层页签“总览 / 规则 / 事件 / 通知”。组合、收益和风险页面统一在页面标题栏右上角提供带页面口径标签的胶囊式“实际 / 模拟”模式 Switch；三者复用路由层的 `portfolioMode`，切换后保持相同的上下文。进入模拟模式后，在标题栏下方展示共享的“模拟模式”提示，加载、空组合和失败状态也不得丢失该提示。风险中心的模式会影响组合数据、扫描和事件，规则配置与规则列表不随模式切换。总览指标卡可切换到对应页签并带上筛选意图。

总览主操作为“扫描当前组合”，扫描按钮展示当前数据状态和最后更新时间；刷新操作重新读取规则、当前模式事件和通知。扫描、人工测试使用路由层传入的 `portfolio` 与 `portfolio.mode`，不在 RiskCenter 内维护另一份模式状态。组合请求完成但持仓为空时显示“空组合”空态，不当作加载中，也不允许发起无上下文扫描。

### 规则编辑

规则编辑器在右侧 Sheet 中新建或编辑。`security` 显示证券代码，`account` 显示账户，`portfolio` 不显示目标字段。由于现有更新 API 对 target 使用 merge 且不能显式清空 `symbol`/`accountId`，编辑已有 `security`/`account` 规则时禁止切换到 `portfolio`，尝试时在范围 Field 附近显示 FieldError，并提示新建组合规则。严重级别和范围的有限选项使用项目已有 shadcn 组件约定；若使用 2–7 个离散选项，使用 ToggleGroup。

阈值展示遵循规则类型：`cost-stop`、`take-profit`、`position-concentration` 使用百分比输入并在提交时转换为 decimal；`price-above`、`price-below` 使用数值输入。表单在缺失目标、非法阈值或范围不匹配时阻止提交并在字段附近说明原因。预览使用中文自然语言表达实际条件。支持“创建后立即启用”，默认开启。

### 规则治理、事件与通知

规则详情显示规则版本、作用域、目标、阈值、启用状态和最近测试结果。人工测试结果留在详情区域，不只依赖 Toast；结果按规则 ID 与版本保存在页面父级，切换页签后保留，规则版本变化后失效。审计使用现有 Dialog 查询完整记录，并展示操作人以及修改前/后的快照。DELETE API 的 UI 文案为“归档规则”，说明规则会停用但保留历史；已停用规则仍可归档，并使用可访问的 AlertDialog 确认，不使用 `window.confirm`。

事件始终展示规则版本、数据时间；仅当顶层 `event.mode` 或 `context.mode` 明确为 `actual`/`shadow` 时展示实际/模拟语义，否则显示“模式未知”，不得回退伪造模式。通知展示渠道、级别、状态、尝试次数和错误信息，`delivered`、`retrying` 使用中文标签和对应 Badge，未知值显示原值。空态、加载态、失败态复用现有共享原语。

## 实现边界

- 风险读取使用 TanStack Query，写操作使用现有 Mutation hooks；不新增手写 `fetch`。
- 风险 UI 拆分为 `RiskOverview`、`RiskRuleWorkbench`、`RiskRuleEditorSheet` 等职责清晰的模块，避免继续膨胀 `RiskCenter`。
- 模式入口使用共享的 `PortfolioModeSwitch`，统一页面头部右侧位置和 Switch 交互；不得在领域页面重复实现按钮组或 ToggleGroup。
- `PortfolioModeSwitch` 使用单层圆角胶囊容器承载页面口径、实际/模拟标签和紧凑轨道；模拟提示使用共享 `PortfolioModeNote`，不得只在某个数据成功状态渲染。
- 只允许修改风险 feature、为 portfolioMode 对齐所需的 `routes.tsx`、投资组合/收益页面的模式入口、共享模式组件、风险针对性测试和本 Spec/任务文档；已确认的 shadcn 交互如缺少本地 primitive，可在 `apps/desktop/src/components/ui/` 新增必要的 `toggle-group.tsx`、`field.tsx`、`alert-dialog.tsx` 等组件，或为交互指标/风险开关补充必要的共享语义 variant。共享默认 Switch 样式不得因风险中心改动而影响 theme-toggle。
- 不修改服务端 endpoint、schema、数据库或 API response shape，不新增传统 CSS 选择器。

## 验收标准

1. RiskCenter 默认总览；总览/规则/事件/通知页签可切换，模式只影响组合、扫描和事件。
2. 扫描操作位于总览，使用当前路由 portfolioMode 对应的 portfolio；规则页不出现模式切换。
3. 新建与编辑复用右侧 Sheet，字段渐进显示、阈值单位正确、预览和内联校验可用，并支持创建后立即启用。
4. 规则详情保留人工测试结果，支持编辑、启停、审计和可访问归档确认；不再调用 `window.confirm`。
5. 事件和通知有中文 label、Badge、Empty 状态，并保留规则版本/数据时间等现有事实字段。
6. Desktop typecheck 与风险相关 Vitest 通过；不宣称浏览器、运行时或在线 Provider 验收。
7. 编辑已有证券/账户规则切换组合范围时，范围 FieldError 阻止提交并提示新建组合规则；不向现有 API 发送无法清理旧 target 的 payload。
8. 组合请求完成但持仓为空时显示空组合状态，扫描按钮保持禁用；实际 loading/ready/stale 状态按请求状态表达。
9. 投资组合、收益分析和风险中心的模式入口均位于页面标题栏右上角，使用相同的“实际 / 模拟” Switch，并共享路由层模式状态。
10. 模式控件显示页面口径标签和清晰的当前态；模拟模式在三页所有加载、空态、失败和成功状态下均显示“模拟模式”提示，且不重复渲染风险说明。
