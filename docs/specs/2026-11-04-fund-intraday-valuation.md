# 单只基金盘中估值接入规格

> 任务标识：fund-intraday-valuation
> 日期：2026-11-04
> 对应任务：[实施任务](../tasks/2026-11-04-fund-intraday-valuation.md)

## 范围与原则

复用已有披露持仓加权估算，补齐单只基金当前估值和今日分钟走势。正式净值、估算净值、个人累计盈亏分开表达，不覆盖历史事实，不根据当前数量反推历史收益。初始覆盖现有 CNY 场外基金及已有来源支持的底层证券，不新开来源、放宽控制或启用付费能力。保留原工作区与业务数据，不提交或发布。

## 计算与所有权

Market 拥有与个人账户无关的基金估值、披露证据和价格读取；Performance 单向消费同一估算能力，Market 不依赖 Performance。复用现有读者与控制围栏，计算只使用估值时点之前已披露持仓，以及同一复权口径的锚点和当前价格。未披露及无法定价部分按零贡献处理，不归一放大，分别返回披露和定价覆盖率。复用原有零价、复权、身份及时间约束。当前估值必须有已确认的 CNY 基金币种证据，读取期间元数据不得变化；第一版境外持仓缺少汇率回报证据时不计入当前定价覆盖，不能把外币价格涨跌直接当作人民币回报。原账户采样已允许的历史读取语义保持。

当前估值额外检查盘中时效：有效报价不得晚于估值分钟，且距计算时刻不超过五分钟；基金正式净值锚点不得无效或晚于当前时点。来源无当日可用更新、全部缺价或无披露证据时返回不可用，不把沿用锚点呈现为成功。定价覆盖率大于零但不足 50% 标低覆盖，其他缺失标部分覆盖。时间字段区分计算时间、净值日期及实际价格时间，过期缓存不得伪装成实时值。

## 接口与采样

`GET /api/market/:symbol/fund-valuation` 与 `GET /api/market/:symbol/fund-valuation/today` 使用完整代码，响应包含基金身份、正式净值锚点、估算净值、估算涨跌幅、估值时点、实际价格时间、覆盖率、质量及稳定原因码。单基金公共估值不按个人账户重复采样；已有账户采样消费同一结果。同一分钟并发合并，复用底层受控缓存；再次读取仍复核来源，失败返回明确状态。

分钟记录由 Market 所有，使用 PostgreSQL 保存真实采样，不以客户端内存或 Redis 代替历史事实。新增结构使用新 migration，并同步结构清单和部署门禁；不得清库。当前查询及既有账户采样可记录实际取得的当分钟公开估值观察，不改账本或正式净值。只记录接入后实际产生的点，不补造上线前数据。同分钟保留最新观察和最后有效观察，晚到旧结果不能覆盖新观察，失败不能抹去最后有效值。闭市保留最后有效估值时间，没有记录时显示未提供；不将休市后的请求时间标成价格时间。

## 界面

正式净值旁简洁展示盘中估值、涨跌幅、时间及必要质量状态。详情通过 TanStack Query 消费公共强类型契约，缓存包含基金与日期，支持取消、失败重试，切换标的不得串数据。保留原有净值、盈亏、区间涨跌幅与稳定悬停布局，不增加说明折叠区。

今日图以带净值日期的正式净值水平基准线，对照实际分钟估值，支持返回历史视图；历史净值和累计盈亏口径保持。缺价、漏采分钟和净值锚点变化均断开；真实缺价分钟保留时间位置，未采样不生成数据；个人累计盈亏不因公共估值曲线而被重建。

## 验收

- AC1：共享计算保持披露权重与复权、时间约束；当前估值拒绝陈旧、未来、全缺价与无披露输入，覆盖率和原因明确。
- AC2：单基金契约、完整代码身份、缓存控制和并发去重正确，账户采样复用同一估算实现，无反向依赖。
- AC3：当前估值界面区分正式与估算，账户/标的切换、错误和重试正确，加载及悬停布局稳定。
- AC4：分钟记录持久化、幂等与今日读取正确；全部结构门禁、隔离数据库及目标开发运行时升级保留数据。
- AC5：今日曲线与实际记录对应，无伪造历史、跨日串数据或缺口连线。
- AC6：本地服务和 Web 真实联通；独立记录交易时段的价格更新时间与估值变化，并在正式净值公布后对比误差。夜间只读和受控输入不能代替完整交易日验证。
