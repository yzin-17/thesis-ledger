# 规则监测同文档轻量正文

## 目标与范围

真实检查中的 govinfo 文档 `04-15081` PDF 读取超时，且响应声明大小超过单件上限。监测目录改用同一官方文档的 HTML 正文，三个引用来源统一生效；保留原收费资料包中的历史 URL、摘要、观察日期及收费规则。

FINRA `SR-FINRA-2020-032` 提交 PDF 的读取耗时也接近单件时限。其两个引用来源改为监测同一提案的联邦公报官方公告正文 `2020-23141`（SEC发布号`34-90176`），其中包含2024年TAF规划表。原提交包含附件，新地址是该提案的公告正文，双方按各自URL建立独立版本，原提交包证据继续保留。

港交所`LSD/086/2022`改用同日交易费操作程序修订的官方正文摘要及附件入口，覆盖三个港股来源；该页面包含2022-11-14修订记录、原费率与新费率、适用范围、2023-01-01生效日和修订附件，不等同于含签署及附件的原通告全文。监测标题明确替代范围，原通告证据继续保留。SEC`34-106409`改为同一发布通知的联邦公报HTML正文`2026-19392`，保留原PDF和`ex5`附件。

港股印花税`CT/158/23`通告与FINRA交易活动费FAQ保留原官方地址：前者约207 KiB，未找到同一通告更轻的独立正文；后者已经是包含`Q100.22`的官方HTML正文。针对原3秒附近的连接失败与成功复核耗时，连接时限校准为5秒；不通过更换成其他政策文档或重复请求掩盖连接问题。

SFC征费提醒通告`CT/053/14`的两个港股来源改为读取港交所官方标准`CT05314B.pdf`地址。未找到同通告更轻的HTML全文，所选PDF为完整中英文通告，与原资料包已核验版本字节及正文一致；此次属于同文档地址修复，不宣称文件缩小或监测范围缩减。原无后缀入口、指纹与失败历史保留。

## 行为

- 只对已核验的官方文档完整地址登记精确的正文地址映射，不推断任意文档的替代地址。
- 新地址仍通过既有 HTTPS、域名白名单和 URL 安全校验。
- 本文编号 `04-15081`、发布时间 2004-07-07、发布编号 `34-49928` 与收费日期定义必须在官方正文中核验。
- FINRA正文须核验提案编号`SR-FINRA-2020-032`、发布号`34-90176`、公报编号`2020-23141`及2024年TAF每股`0.000166`美元、每笔上限`8.30`美元的规划表，不以提案目录页或其他年份规则代替。
- 港交所替代页面须包含同日修订正文摘要、`0.005%`到`0.00565%`、移除每笔`$0.5`费用、适用范围、生效日及对应`086_22`附件链接；摘要及附件入口的监测不认证原PDF全部内容未变。
- SEC正文须核验发布号`34-106409`、提案号`SR-FINRA-2026-021`、发布日期2026-09-18及2026-10-01至2026-12-31暂停TAF、2027-01-01恢复征收的正文。美国现行规则按需核验须消费新监测地址及人工核验的正文摘要；其他版本变化继续拒绝通过，不依赖原PDF的旧成功观察。
- SFC通告标准PDF须核验编号`CT/053/14`、日期2014-10-20、前引`CT/031/14`、2014-11-01生效及征费从`0.003%`降至`0.0027%`，保留参与者系统与后勤准备指示；不得以其他通告或现行费率目录代替全文。
- 多个来源引用同一监测地址时，每轮只请求一次。新地址建立自身版本基准，不直接沿用旧地址的版本记录。
- 保留旧 URL 的原始失败历史与观察，不把新 URL 成功改写为旧 URL 历史成功；按本轮执行标识判断本轮结果。
- 连接超时设为5秒，分别约束TCP建立与TLS握手，读取、写入及连接池等待各阶段仍最多10秒；外层单件总时限15秒、整轮总读取300秒优先，不把分阶段时限相加为新的总时限。保留2 MiB正文上限、不自动重试、不跟随重定向及逐件释放结果。

## 验收

- AC1：五个精确映射分别覆盖其三个、两个、三个、一个和两个引用来源，采用已核验的官方正文或明确标注范围的同修订摘要及附件入口；原收费资料包字节与身份、历史失败保持不变。
- AC2：受控回归覆盖 URL 精确映射、未登记地址拒绝、跨来源去重、原始失败保留及新地址读取成功；大小、超时、认证隔离与重定向保护继续通过。
- AC3：使用 infra 正式最小目标入口同步本地，独立核对容器文件与正式 API。
- AC4：同步后通过正式 API 实际执行一轮全部已登记来源，记录本轮终态、逐来源归属与全部失败；保存配置和原执行计划保持不变。
- AC5：两个原地址的受控TCP及TLS连接在3秒至5秒间能够成功，超过5秒仍失败；读取及单件剩余预算能取消请求，HTTP错误、大小、地址、认证、串行和总预算保护继续通过。真实检查单独记录两份目标结果，旧失败不改写。
