# Drawer 内容与焦点可见性

## 目标与范围

检查 Desktop 全部 SheetContent 调用、嵌套滚动区及页签，修复基金定投输入焦点环被滚动区裁切及同类问题。保留 DOM 业务结构、提交精度、取消行为与已有未提交修改。

## 展示合同

- 独立滚动正文复用 SheetBody，或保留等效四周 4px 安全留白，容纳当前实际计算出的 3–4px 焦点外环；不能仅凭没有横向溢出判定通过。
- 滚动区设置 8px 的 scroll-padding，引导键盘焦点滚入时预留外环距离；高于可视区的编辑框允许滚动查看，但左右外环及上下边缘必须分别可达。
- 长错误信息置于滚动正文内，不能在固定区占满高度并挤没编辑区。
- 正文独立滚动时标题、正文与底部操作区不相交；长内容、错误提示、末项与操作按钮均可到达。
- 整体滚动侧栏保留该模式，短窗口时不得把底部内容留在不可达的视口外。
- 在 1440、1024、768、390 宽度及短窗口中检查实际计算边界与焦点环；真实数据只读，提交失败用隔离请求验证。

## 非目标

不改业务字段、请求、校验与标的搜索，不更新 Docker 运行态。

共享横向页签的滚动视口须容纳 4px 按钮外环；增加留白时补偿外侧间距，保持原控件高度与栏到面板的有效分组间距。
