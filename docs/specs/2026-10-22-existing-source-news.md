## 来源选择与边界

当前运行态已有并启用 AKShare，宿主已安装 `1.18.94`。官方 `stock_news_em` 文档声明个股新闻；实际 SDK 请求搜索第一页、每页十条。现有版本读取 `600519` 已返回真实近期标题、时间、媒体及链接，因此选择复用 AKShare，不需要新增账号、依赖或独立新闻服务。此前七家专用搜索来源缺少配置的盘点仅覆盖专用搜索，不代表全部行情来源没有新闻能力。

- 为 `akshare / eastmoney` 新增 `CN / STOCK / NEWS_SEARCH` 精确绑定。保留其他绑定、配置、凭据、原十七条政策及 NVIDIA 来源。
- SDK 执行放在现有有总预算、并发上限和强制回收的独立进程内；使用 SDK 的参数和字段解析，传输固定为官方公开搜索 HTTPS 地址，移除 SDK 内置 Cookie，限制字节数，禁止重定向和隐式重试，记录实际尝试及 HTTP 状态。
- 只提供标题、媒体、转载页链接、条目标识和发布时间；正文及图片不持久化，不生成摘要。搜索关联不能解释为发行方直接公告；`originalUrl` 与 `sourceAvailableAt` 保持未知。中国本地发布时间按 `Asia/Shanghai` 解释，缺失或非法时间保持未知。
- 搜索第一页并不完整覆盖日期区间，始终返回 partial 与有限搜索原因；不宣称完整历史或 PIT。仅已核验公开身份、精确修订、标的/日期准入和显式新闻政策共同满足时请求上游。
- 首次真实验收限定 `600519.SH` 与当前近期窗口；准入有效期最多七天，既有准入不覆盖或续期。Tushare 新闻需单独权限，当前 120 分记录没有开通项，继续跳过。

## 消费与数据保护

沿用现有 Market API 与 `news-search-v1`，不改变共享协议。新闻侧栏允许规范 A 股或美股代码，根据代码确定市场；默认使用已验收的 `600519.SH`，说明当前范围并区分搜索结果与 NVIDIA 官方订阅。输入变化与关闭继续取消请求，读取仍须显式操作。

先完成定向验证，再通过 infra 正式备份、首次准入维护入口及 `sync-code.sh` 更新代码。新来源绑定不等于自动获得使用权限；应用新闻政策前必须登记并核验首次准入。保留所有原数据和来源配置，比较前后控制与业务差集。无模型调用，不开启研究写入。

## 验收标准

1. E-AC1：现有来源公共配置、官方接口依据与当前 SDK 的真实读取可核验，来源选择顺序有记录。
2. E-AC2：精确绑定、公开身份、政策、准入及修订守卫有效，未准入或不支持的请求零尝试。
3. E-AC3：元数据、时区、转载关系、有限覆盖、传输预算及 HTTP 失败通过定向验证。
4. E-AC4：目标 Docker 的 V3、Market 与实际 Web 读取同一来源的非空真实新闻，旧 US 新闻行为保持。
5. E-AC5：正式更新、代码一致性、数据保护及总表核对完成，模型调用保持零。
