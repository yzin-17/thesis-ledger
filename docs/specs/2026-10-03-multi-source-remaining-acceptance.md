## 目标与基线

用户要求完成交接中的剩余任务，并明确停止 RQData 注册及试用申请。当前共同价格范围和 Canonical 已完成，继续以其实际验收为基线；本次启动原[扩展清单](../tasks/evidence/2026-10-03-multi-source-remaining-tasks.md)中的可执行工作。既有领域合同和原任务编号继续有效，不因来源缺失降低真实性要求。

本次范围包括严格历史 PIT、真实公司行动与份额、HiThink ETF 分红、可靠因子与派生序列、专业行情与辅助来源、不可变镜像和状态保真恢复，以及浏览器交互验收。AKShare/EastMoney、Tushare、RQData 和 TdxAiData 的既有来源跳过决定保留；不购买权限、不继续注册。

## 实施原则

先确认实际可用输入，复用已经完成的合同、仓储和消费者，不重写已通过部分。缺少真实历史版本、官方事件语义或可靠因子时，记录准确阻塞，不由当前抓取、价格比值或空响应生成历史资格。

按用户最新要求，客户端只使用浏览器连接当前构建产物与目标 API，验证页面、行情和冻结 Run 消费。Electron 窗口交互验收本轮跳过；浏览器结果只证明 Web 消费面。

Docker 清理先于后续构建：只清理确认可回收的构建缓存，保留数据卷、运行容器和回退镜像；daemon 无响应或存储只读时停止构建。需要重启 Docker Desktop 恢复时先确认容器短暂中断，再检查数据与服务健康。

镜像从当前源码通过官方 infra 更新入口形成，记录内容寻址身份、构建输入和运行结果。更新前保留候选；恢复演练使用隔离网络、数据库、DSA 状态和快照副本，保持目录 generation 与策略修订关联，不改目标数据或业务任务。不同版本候选是否相容须单独确认；同版本恢复不能冒称旧版本回退。

验收实施阶段未提交或远程发布；用户于 2026-10-03 后续授权提交推送项目改动，按三个仓库现有分支分别提交并推送源代码及文档。镜像 registry 发布与版本 tag 不属于本次提交任务。完整更新应在源码稳定后执行一次；恢复及故障场景复用镜像。备份中的凭据和业务数据不进入日志或仓库。

## 组件回退相容性续验

旧 Server 与旧 DSA 的组合已因目录身份改变而拒绝回退。下一步以相同当前状态副本分别验证“旧 Server/Worker + 当前 DSA”和“当前 Server/Worker + 旧 DSA”，定位组件相容性。仅完整目录、策略修订、业务读取及四条冻结重放均通过的组合获得当前状态下的隔离演练资格。演练不切换目标容器，也不等同于长期制品发布或旧状态备份完成。

## 本地可取回恢复包

将当前两份内容寻址应用镜像、PostgreSQL 一致性 dump、DSA SQLite 在线备份与数据目录、冻结制品封装到仓库忽略的 `.recovery-artifacts/`。目录权限为 0700，文件为 0600；不另行导出运行环境凭据，业务备份按敏感数据保护，不进入 Git，不上传远程服务。记录镜像身份、文件 SHA-256、结构 head、目录与策略身份、冻结结果摘要及恢复结果。空间预算在操作前复核，完成后应保留至少 18 GiB 主机空间。

验证压缩镜像包可导入，并使用该批状态与镜像进行独立恢复。通过后才标记包可用于本地恢复；本机磁盘副本不等同于异地灾备，也不赋予不相容旧镜像回退资格。

## 验收标准

- AC01：浏览器连接当前构建产物与目标 API，当前行情、图表口径及已完成 Run/冻结数据消费通过，保留浏览器证据。
- AC02：当前源码有可取回的内容寻址镜像，官方更新、版本/结构门禁、健康和实际业务检查通过；远程发布单独报告。
- AC03：候选镜像在隔离状态副本上完成 Server/Worker/DSA、目录/策略及冻结业务读取的恢复验证，原目标数据与配置保持一致；旧版本相容性单独判定。
- AC04：严格历史 PIT 使用真实历史版本、日历及决策可见性输入，预检/冻结/离线重验闭环通过；缺输入保留原 S05 未完成状态。
- AC05：公司行动、因子派生及 Quote/辅助能力逐来源验证实际权限和语义，完成其对应消费者和目标门禁；缺输入分别保留未完成状态。
- AC06：全部已完成和未完成范围、证据与启动条件对账，已跳过来源不再作为当前执行队列，其他待验收不隐藏到 TODO。

## 证据与停止条件

验证由定向检查到构建、仓库门禁、真实运行态递进。已通过且输入未变的高成本检查不重复运行；验证环境、输入和结果记入 Task。

某能力依赖的真实输入缺失时停止该能力的外部请求，继续其他可执行叶。只有实际必要门禁通过才能完成其验收项；任务状态保留真实阻塞。
