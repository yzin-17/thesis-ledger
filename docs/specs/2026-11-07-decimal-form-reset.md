# 数值输入的原生表单重置与归属

## 问题与目标

DecimalInput 以内部原值与独立展示值保护金融精度，但非受控草稿未监听 form.reset()。持仓和现金保存流程已经调用原生重置，组件应遵循其公开 defaultValue 合同。命名原值由隐藏输入承载，外置 form 属性也必须指向同一张表单。

补齐共享输入的原生表单行为，保留原始十进制文本、紧凑展示、正常输入事件、受控值和可访问命名。

## 验收标准

- AC1：非受控输入编辑后，原生重置恢复当前 defaultValue 的完整原值；聚焦状态保持，失焦仍按原展示规则格式化。重置自身不触发 onChange 或新脏状态，普通及 InputGroup 消费一致。
- AC2：被 preventDefault 取消的重置保留草稿；受控输入由父组件继续拥有值；重置期间父组件更新默认值时使用最新提交的默认值，组件卸载后不执行旧同步。
- AC3：外置 form 归属同时作用于显示控件和命名原值；FormData 保留长小数、大整数、极小非零值、零和空值，disabled 继续不提交，重复编辑和重置无残留值。
- AC4：核对全部 5 个当前消费者并验证真实 PositionFields。新增反例在旧实现失败；定向、Desktop 完整包、构建、lint、边界和尺寸通过；1440/1024/768/390 受控真实浏览器验证焦点、原值、重置取消、表单归属和布局，业务请求与写入为 0。

## 所有权与边界

表单同步属于共享 UI 数值输入，不进入 Portfolio、账本或提交编排。复用已安装 Input 与 InputGroupInput 及现有原子样式，不新增业务分支或重复组件。沿用已核对的 shadcn 项目和 Input/InputGroup 文档，不安装或覆盖组件。

仅修改 Desktop 数值输入、对应回归与受控浏览器入口。保持数据库、业务请求、金融计算、原始数据和所有受控编辑协议；不执行 Docker、外部服务、模型或真实业务写入。原生工程不变。
