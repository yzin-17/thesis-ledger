# 空交易计划执行等价修复

## 目标与边界

修复空交易计划因对象存在而启用计划执行分支的问题。仅含 `version=1`、`evaluation=barClose`、`stages=[]` 的配置应与未设置 tradePlan 在仓位参考价、信号选择、成交、结果和中文说明上等价；不通过删除已保存字段或改写历史版本实现。

包含阶段或其他已配置功能的计划继续使用其现有行为。功能开关由 Domain 的同一业务判断提供，Server 的仓位计算与计划输入、Domain 的执行和说明均消费该判断。仅省略可选功能或值为 undefined 才视为未配置，不将明确的功能配置静默移除。

使用现有 v3 `893ddc7e-1e8e-4f4d-a4a5-6668d340b097` 原样定义，新建回测复用运行 `9c7efea9-9242-494b-8bec-cef825ed4b1d` 的完整 RunConfig 与冻结行情。不得重新取价、重新冻结、调用 AI、删除或覆盖原版本和回测。正式准备与路由门禁保持生效。

## 验收标准

- AC1：共享判断区分缺失／空计划和真正配置功能的计划；空阶段但有止损、追踪、冷却、风险预算、亏损暂停或目标波动率的计划仍启用。
- AC2：存在开盘跳空时，空计划与无计划的数量、日期、方向、价格及权益一致；真实计划原有行为保持通过。
- AC3：实际 Server／Worker 运行修复代码，正式新增回测成功，完整 RunConfig、冻结行情和可比数据指纹与上述 v3 原回测一致。
- AC4：独立核对新回测的交叉方向及风险退出；首笔按原无计划参考价计算数量，旧版本／回测／AI 记录执行前后摘要一致。
