# Desktop 列表表头统一

日期：2026-11-07。对应[实施任务](../archive/tasks/2026-11-07-desktop-table-headers.md)。

## 问题与范围

当前持仓、账户持仓快照等列表混用原生表头和共享组件，并分别指定背景、字号、字色及内边距；固定操作列表头又拥有独立背景，造成同页和跨页差异。

检查 Desktop 全部带列标题的表格，包括账户、组合、收益、自选、风险、策略、研究、复盘、资料、Provider 和模型竞技场，以及详情和弹窗内表格。无列标题的键值资料表、卡片列表、页签及分区标题保留各自语义。Mobile 未使用 HTML 列表表头，本次不改原生界面。

## 展示合同

- AC1：所有列标题复用 `TableHeader` 与 `TableHead`；普通表头统一使用 `bg-muted` 背景、`text-xs` 字号、次级文字色、适中字重、40px 标准高度及横向 12px／纵向 8px 内边距。较长内容按既有换行策略自然增高。
- AC2：固定操作列复用相同表头单元格，并保留不透底背景、右侧固定、左分隔线及层级。数字列右对齐、文字列左对齐；列宽、隐藏断点和窄屏滚动保留。
- AC3：排序表头保持按钮、排序循环及 `aria-sort`；当前排序可用正文色表达，普通列与未排序列使用统一辅助层级。数据、请求、历史精度、加载及操作行为保留。
- AC4：建立全量源码清单与自动回归约束，防止 feature 内重新出现独立原生列标题及重复样式。实际浏览器覆盖四种代表宽度、浅色／深色、排序、操作列滚动及详情表格；真实业务数据只读，受控样本与真实页面证据分别记录。

## 实施与验证边界

沿用现有组件和 Tailwind 原子类，不新增页面级 CSS 或依赖。先验证共享组件与定向测试，再执行 Desktop 类型检查／构建、现有边界门禁及浏览器检查。测试或共享工作区失败按实际归属记录。无数据库、Server、原生工程或 Docker 更新要求，不创建提交。

## 未决问题

无。统一基线采用当前持仓快照使用的浅色表头，与固定操作列表头保持一致。
