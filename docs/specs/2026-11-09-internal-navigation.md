# 内部导航整页刷新排查与修复

> 日期：2026-11-09
> 状态：已验收
> 对应任务：[实施任务](../archive/tasks/2026-11-09-internal-navigation.md)
> 验证记录：[排查与验证](../archive/evidence/2026-11-09-internal-navigation.md)

## 目标与范围

排查 Desktop 及共享前端代码中，内部页面链接是否误用原生文档导航，修复同类问题；核对 Mobile 的外部链接入口。普通应用内导航使用现有 React Router 的 Link/NavLink 或 navigate，保持目的页、查询参数、浏览器前进后退及已有草稿保护。

## 已核对的边界

初始清单覆盖1005个 Desktop/共享生产源码文件，其中 Desktop643个。22处链接属性包括1处遗漏的应用内普通锚点：复盘“配置 AI 模型”。它由对象复盘、周期复盘及任务历史共用组件提供，须一次修复所有消费者。其他原生资料链接在新窗口打开；两个 Blob 导出入口、OAuth 新窗口及错误页显式重新加载分别保留。28个原生表单均有提交处理，未发现原生 action/target 导航。Mobile 的 `openExternalLink` 用于经校验的外部资料。

## 行为与验证合同

- 所有已发现的普通内部链接使用现有应用路由，保留原URL、中文名称、样式与可访问链接语义。
- 外部资料、新窗口授权、下载与错误恢复保留既有用途，不将它们误改为应用页面。
- 自动化检查覆盖静态/模板内部 href、常见 location 路径写入及显式整页导航开关；明确允许外部链接、下载及既有错误恢复。动态资料地址通过清单核对，不以静态扫描代替实际目的与运行语义。
- 定向测试和 Desktop 类型/构建通过；实际浏览器覆盖1440、1024、768、390，证明修复入口及已有“前往自动化”跳转不产生新文档请求、内存标识保留，后退和再次打开正常。
- 浏览器只读及受控响应分别记录；不触发 AI、资料检查、Provider探测、通知或真实业务写入。保存全部无关工作区改动，不提交代码。

## 验收标准

- AC1：候选入口及保留理由有完整清单，遗漏内部链接全部修复，全部共用消费者保持可用。
- AC2：回归检查能识别普通内部文档导航，保留外部/下载/恢复行为，定向验证及受影响构建通过。
- AC3：四宽实际页面或明确的受控页面验证应用内导航与后退，未触发真实业务写入；静态扫描与运行态证据分列。
