## 问题与目标

## 验收标准

- AC1：只将成交均价/止损线比较表述为已知偏差，不从中推断期间是否触及或触发止损；收益达标结论必须有明确阈值和已知比较依据。
- AC2：周期与减仓统计分别解释，不相加；不能从缺少行情、分红、税费或行为来源推断相应事件已发生/未发生。未知与假设明确标记，反事实不是实际成交。
- AC3：新提示拥有独立版本，冻结保存；旧 Run 按旧冻结版本读取，历史结果不重算或覆盖。结构、引用、算法和经济账本不变。
