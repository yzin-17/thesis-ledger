# 同花顺新闻准入的显式七日窗口滚动

日期：2026-10-30。对应[已完成任务](../archive/tasks/2026-10-30-news-admission-recent-window.md)，承接[研究工作台实施记录](../archive/tasks/2026-08-25-ai-research-workbench.md)及[原一小时续验](2026-10-29-news-admission-renewal.md)。

## 需求与授权

用户已明确授权：仅原同花顺 `hithink-news-stock-timeline`、`600519.SH`、2026-10-23～10-30 最近七日新闻元数据，先实读最多一页十条，再将该条准入续为一小时。其他准入、来源启停、路由、凭据、默认及业务数据保持。

原维护入口的续验只允许原审阅日期范围内。当前记录为版本 3、2026-10-22～10-29，已过期；直接使用新日期应继续被默认入口拒绝。本增量为用户本次明确同意的向前一天滚动提供独立显式选项。

## 范围与设计

1. DSA 的 `scripts/local-runtime/news-admission.mjs --source=hithink-timeline --renew-existing` 保持原续验行为。`--roll-recent-window` 仅能与原同花顺配置档、`--renew-existing`、一小时及旧版本/摘要确认同时使用。
2. Python 校验仍要求目标准入已过期、未撤销、同一来源/凭据修订、同一证券及完整旧证据链。新实读证据须在十五分钟内，日期仍须为执行 UTC 当日及此前七日。
3. 显式滚动只接受原范围恰为七日，开始与结束同时向前一天；不接受任意扩展、跨两天跳跃或更宽窗口。没有该选项时继续要求新范围落在原范围内。
4. 仍在 SQLite 写锁内按旧版本和摘要执行单条 CAS，只改原允许的日期、有效期、证据、记录人、版本与记录时间字段。新证据明确记录滚动选择，并嵌入旧记录和摘要；旧证据保留。
5. 正式操作只通过维护入口执行；不改 DSA 服务、镜像、数据库结构或任何来源启停，不部署应用。实读仅使用容器内原认证，不将凭据输出或写入宿主文件。

## 验证与验收

- AC1：CLI 拒绝缺少续验、错误来源、错误有效期、重复选项及缺少旧记录确认；默认计划不写入。
- AC2：隔离 SQLite 中默认仍拒绝越过原范围；显式向前一天成功，非法窗口、修订、撤销、过期及旧证据条件继续拒绝。
- AC3：独立只读验证成功，旧证据、其他记录及受保护表保持；应用失败不自动重试。
- AC4：本次目标仅实读一页十条以内；通过后由维护入口更新指定版本 3 的这一条准入并反读，其他准入/政策/凭据保持。实际研究调用与业务结果由研究工作台独立验收。

## 停止条件

任何来源实读、摘要/CAS、范围或保护校验失败即停该叶。日期与本次授权不符时不自动扩大授权窗口。真实模型调用为零，模型预算仍由本轮前四项的独立授权持有。
