## 目标与授权

用户要求所有股票不再设置日期窗口。范围为当前已支持的全部沪深股票目录身份，沿用本地个人研究、最小元数据和原文链接用途。取消本次验收使用的固定标的、固定日期窗口和 24 小时有效期；一次请求仍只读一个股票的一页，不自动采集。

## 状态与控制合同

研报业务就绪由现有显式政策路由、来源启停、来源配置代次、当前能力绑定及协议版本共同决定。研报绑定采用普通配置就绪的 QueryBinding，不再将短期实读验收记录作为业务访问许可证。旧准入记录及其证据继续保留为历史，不续期、不覆盖、不改成无限期记录。移除研报路由或停用来源即可撤销后续读取，执行期间控制变化时丢弃返回结果。

本次不修改已有 20 条路由、来源启停或凭据；不启用其他能力。协议和适配修订必须与当前绑定匹配，不能采纳旧版来源结果。其他能力的准入规则保持。

## 执行与消费合同

- 请求 `start`、`end` 均可省略或为 null，分别只作为可选筛选；同时提供时校验顺序。省略时不替用户填入隐藏日期；来源要求字段存在时，以空字符串表示无筛选，不发送日期值。东方财富缺少 beginTime/endTime 会返回 400，保留空字段已实读核实。
- 当前结果使用 `research-report-metadata-v2`，明确回显可选日期。保存发布日期及 date 精度，分页和 `historyComplete=false` 保持；来源可用历史仍受其实际返回范围限制。
- 单次最多 20 条、一页，500～5000 ms 预算及 256 KiB 响应上限保持；不重试、换源、翻页或下载正文附件。
- 共享 schema 继续接受完整旧版 v1 快照，保持旧日期字段、规范字段顺序和内容摘要；新读取客户端只接受当前版本及适配修订。本地历史不受旧验收记录过期影响，也不访问来源。
- 复用 JSON 快照存储，不修改数据库结构。不得将无日期筛选描述为全历史覆盖。

## 验收与停止条件

目标验收暴露的错误封装问题按用户确认继续修复：研报入口复用既有 `market_data_error_v3` 与运行时错误投影，确保输入错误和来源失败均返回标准 Data V3 信封及相同请求标识，不放宽 Server 的严格校验。来源传输诊断仅记录请求标识、稳定错误码和 HTTP 状态或异常类型，不记录 URL、原始响应、异常文本或凭据；用于同一次有界验收的失败定位。

先验证日期省略和单边筛选、旧快照摘要兼容、沪深不同股票、失效验收记录不再阻断、来源停用/路由撤销及执行中版本变化仍阻断。通过定向测试、类型/build 与相关门禁后，使用正式完整更新入口部署。

目标验收读取旧快照并核对原摘要，执行一次无日期的标准 Server 单页采集，核对当前来源目录及原路由/启停/受保护数据；已有且输入未变的数据库、重启和其他来源证据继续复用。遇到新的来源、部署或数据卡点先停止向用户确认，不扩搜其他方案。
