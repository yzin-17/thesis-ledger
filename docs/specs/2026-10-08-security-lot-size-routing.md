# 每手股数独立路由与富途只读数据源

任务标识：LOT。关联：[实施任务](../archive/tasks/2026-10-08-security-lot-size-routing.md)。

当前选择富途的开发目标验收已完成，真实00147/00700股数、默认/覆盖模型冻结、重放及页面下载见[验收证据](../tasks/evidence/2026-10-08-security-lot-size-live-acceptance.md)。长桥未配置，不记真实读取；Task归档，本Spec保留当前接口与行为合同。当前代码为开发同步，镜像交付不在本次验收声明内。

## 目标与范围

把港股股票每手股数作为 `SECURITY_LOT_SIZE` 独立能力接入现有主备路由。用户自行选择长桥或富途，不固定优先级，不因东方财富不可用而在未授权时改选其他来源。当前值只作为研究预设，保留手动覆盖、冻结和历史变更未核验提示。

富途本轮只登记证券静态资料读取，不登记尚未实施的价格、持仓或交易能力。连接参数为用户配置的 OpenD 主机和端口，复用 Provider 配置存储；不采集券商账号密码或交易密码，不查询账户或持仓。长桥复用现有授权及静态资料读取。

## 接口与职责

DSA 持有适配器、连接配置、主备执行和来源观察；Server 持有产品查询入口和响应校验；Desktop 复用路由配置、Provider 配置和回测参数编辑。能力键为香港／股票／每手股数，与日线及实时报价路由独立，不携带历史日期或复权口径。

响应保存标的、正整数每手股数、实际采用来源、观察时间和历史未核验标记。缓存按实际来源与标的隔离，不把查询时刻伪写成来源历史生效时间。回测确认时保存采用值，后续重放不重新查询。

## 行为边界

- 主源失败时只尝试用户配置的备用源；两个来源都不可用时明确提示，可手动保留或覆盖研究参数，不编造默认数值。
- 来源返回空值、非法股数或错误标的不能当作成功；不建设历史整手原件库，不做多源投票。
- 富途只使用行情上下文查询静态资料，确保连接关闭；连接失败、权限不足等收敛为可解释错误。
- 已有每手快照与结果不回填；原价与股数单位的现有约束不因独立查询而放宽。本轮不宣称任意标的历史原价已支持。
- 保留当前并行工作区改动；不提交、不推送、不调整用户已有选源。

## 验收

LOT-AC1：Provider 列表可见富途连接配置；长桥和富途均出现在每手股数独立主备路由。
LOT-AC2：静态资料读取、标的归一化、正整数校验、失败关闭连接及主备选择有确定性测试。
LOT-AC3：产品查询与回测参数消费可见实际来源，手动覆盖和旧冻结结果保持。
LOT-AC4：定向测试及受影响构建通过；真实券商联调与目标部署独立记录，缺少 OpenD 或授权不能标记实测成功。

## 官方接口依据

富途：`OpenQuoteContext.get_stock_basicinfo` 的 `lot_size`，见 https://openapi.futunn.com/futu-api-doc/quote/get-static-info.html 。
长桥：`QuoteContext.static_info` 的 `lot_size`，见 https://open.longbridge.com/docs/quote/pull/static 。
本轮核对日期为 2026-10-08；上述字段是当前静态资料，不是历史整手变更记录。
