# 市场查询入口与抽屉一致性

## 目标与边界

整理市场数据页的资料、新闻查询入口，修正标的选择回显，提供新闻时间范围，并统一抽屉布局。仅修改 Desktop 展示与查询参数组织，复用现有接口、TanStack Query 和共享组件；保留工作区已有修改，不修改业务数据、来源路由和历史记录。

## 行为与验收标准

- AC1：标题区只保留刷新；「查询资料」「查看新闻」作为次级入口位于功能页签行右侧，与四个页签分组；窄屏入口换行，页签可在自身容器内滚动。
- AC2：共享标的字段选中后在框内显示名称和完整代码，提交仍使用原代码；编辑时恢复搜索文字。已有目录结果可复用，未知名称回退代码，不新增自动补名请求。不预填示例标的；移除资料代码示例说明与这两个查询入口中的搜索占位提示，保留错误、空结果及来源覆盖限制。
- AC3：个股新闻和市场快讯共用时间范围控件，提供最近 24 小时、3 天、7 天、30 天和自定义日期，默认 3 天。预设以点击读取的时刻倒推；自定义按浏览器本地时区包含起止日全天，缺失、无效或倒置日期阻止请求并显示中文错误。选择条件不自动读取；改变条件或关闭抽屉取消旧请求；结果显示已提交范围，不能沿用旧范围的数据。
- AC4：两个查询抽屉统一使用共享 `SheetContent size="detail"`（960px，窄屏上限为视口减 16px），复用相同标题、内边距和内部滚动。
- AC5：定向测试验证回显与原始提交值、手工输入、请求取消、预设/自定义范围和错误恢复；实际浏览器在 1440、1024、768、390 宽度验收两个入口、抽屉、选择器、日期控件及关闭/原导航。

## 接口与限制

复用 `publishedStart`、`publishedEnd`、每页 5 条及现有请求预算。范围可选择不代表来源能提供完整历史，继续显示服务端覆盖缺口。当前名称仅来自已有目录选择结果，合约仅消费已读取的来源清单，不猜测名称或创建目录记录。
