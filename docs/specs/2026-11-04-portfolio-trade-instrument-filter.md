# 交易标的选择规格

> 任务标识：portfolio-trade-instrument-filter
> 日期：2026-11-04
> 对应任务：[实施任务](../archive/tasks/2026-11-04-portfolio-trade-instrument-filter.md)

## 目标与范围

交易列表接口按完整代码精确匹配。标的筛选改为下拉选择，显示“全部标的”及名称、完整代码，选择完成后查询交易。加载期间保留统计区和筛选区的位置。沿用现有原子类、Select、账户筛选、生命周期、详情与分页。

## 数据与交互

- 新增只读 `/portfolio/trades/instruments`，参数为 `mode` 和可选 `accountId`。按与交易列表相同的账户、模式范围，批量分组读取完整历史的唯一标的，不受交易分页、当前标的或生命周期筛选限制。
- Ledger 拥有交易标的查询，通过 Market `InstrumentDisplayService` 一次批量解析完整代码，返回当前名称；目录未知或故障时回退代码。不得向远程 Provider 查名称，不修改交易或历史事实。
- 公共响应回显模式、账户和标的列表；API 客户端验证范围并传递取消信号。查询缓存按模式和账户隔离。
- 下拉触发器与选项复用同一标签映射。首次读取时显示加载状态；失败可通过刷新交易重试。交易列表仍可独立显示。
- 账户或实际/模拟模式切换后，标的恢复全部；生命周期选择保留。旧标的不得先发送给新范围，也不得在返回旧模式时自动恢复。
- 切换标的、生命周期或加载下一页时保持筛选区和统计区布局稳定，统计未就绪显示占位，不将旧范围统计充作新结果。
- 刷新交易同步刷新标的选项；清除筛选恢复全部标的和现有其他默认筛选。

## 验收标准

- AC1：选项覆盖当前范围完整交易历史，包括仅出现在后续分页中的标的；去重并按代码稳定排序，名称本地批量解析，未知与故障回退代码。
- AC2：公共契约校验参数与响应范围；错误模式或账户请求不暴露其他范围数据。
- AC3：下拉显示名称与代码，选择发送精确代码，全部时省略 `symbol`；没有按输入字符发起交易查询的路径。
- AC4：加载时布局稳定；账户/模式切换清理标的且不先查询旧代码，生命周期与分页行为保持。
- AC5：定向测试、相关包构建、边界检查和本地 API/Web 验证通过，保留现有业务数据及未提交工作。

不修改数据库结构或 Provider 配置。Docker 更新遵循维护入口；本次本地 Web 验收不代表镜像或安装包更新。无未决设计问题。
