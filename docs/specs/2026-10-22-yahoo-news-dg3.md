# Yahoo Finance 新闻接入与 DG3 扩展

## 目标与边界

按用户授权，将已验证的 `yfinance.Search.news` 接入现有新闻 V3、Market 和 Web，补充 DG3 的真实消费证据。复用 [HiThink 与 Yahoo 验证](../reviews/2026-10-22-hithink-yahoo-news-final-review.md)及原 DG3 证据；当前执行状态由[配套任务](../tasks/2026-10-22-yahoo-news-dg3.md)持有。

仅增加既有 `yfinance` 来源的 US/STOCK/NEWS_SEARCH 绑定 `yahoo-search-news`。本次首次准入限定已经核验的 `NVDA.US` 和近期日期窗口，最多七天，不自动扩大或续期。US 新闻路线以 Yahoo 为首源，保留原 NVIDIA 官方订阅备用；其余路线及 HiThink、AKShare、Tushare 配置不变。AAPL 的既有 SDK 验证继续有效，但不据此自动登记其他标的准入。

不调用 `Ticker.get_news`，不获取文章正文，不调用模型或开启研究写入；研究 G3 仍由原任务和预算授权控制。依赖、数据库结构、凭据及镜像输入不变，使用正式代码同步入口，保留全部现有数据。

## 数据与执行合同

- 使用当前已核验的 yfinance 1.7.0 `Search`，禁用模糊搜索、推荐、列表和无关扩展；股票引用必须与请求代码及公开身份一致，每条新闻必须包含对应 `relatedTickers`。
- 搜索与 Cookie 引导仅允许固定 HTTPS 目标和只读 GET，关闭重定向、持久 Cookie/时区缓存和 SDK 网络重试；在隔离取数进程中约束总预算、HTTP 次数和响应大小。所有实际网络尝试计数，搜索错误状态不能被 SDK 空数组掩盖。
- 只投影标题、原始链接、发布者、来源条目标识和 Unix 秒发布时间。正文、摘要、原文归属和来源首次可用时间未知时保持未知。复用共享转载归组与日期过滤，近期搜索列表始终保留 `search_first_page_not_exhaustive`，不声明完整历史或严格 PIT。
- 继续执行来源启用、精确绑定、当前政策、准入修订、标的/日期和公开身份检查。未准入、旧日期和不支持游标必须零网络尝试；使用原有总预算及失败分类。
- 首次准入使用现有维护脚本的显式白名单 profile，审阅有摘要的元数据证据；拒绝覆盖或续期已有准入，事务内保留首次写保护。无 Key 来源的凭据修订为 `not-required`。

## 回退与证据复用

通过现有政策编辑移除 Yahoo 新闻目标即可停止选择该来源；源码回退仍使用正式入口，不删除准入审计或业务数据。原 HiThink/AKShare/NVIDIA 实源、共享合同及未改 Server 的验收按实际输入复用，本次补 Yahoo 适配、受影响门禁、目标联通和保全差集；不以健康状态替代部署或业务验收。
