# 港美股后复权回测准备修复

## 目标与边界

修复富途港美股股票后复权研究回测在数据准备阶段被拒绝的问题。当前来源路由保持不变；只消费已有核验身份、日历与完整窗口证据，不推测上市日或放宽价格、身份、权限及覆盖校验。历史失败记录保持原样，不自动重跑用户任务。

## 行为与验收

- AC1：富途港美股股票的 `qfq`、`hfq` 绑定复用同一研究日历及证券身份策略；未知身份、错误市场、未复权和未覆盖资产继续按既有门禁处理。DSA 拥有绑定和测试。
- AC2：来源诊断脚本按生产解析器确定市场，港美股请求可到达真实覆盖检查；真实控制库只读，临时副本清理。DSA 拥有脚本与隔离测试。
- AC3：服务端保留 DSA 的 `insufficient_coverage` 语义，回测提示窗口或覆盖证明不足，不误报为未配置来源。ThesisLedger 拥有错误投影和消费测试。
- AC4：经定向测试、相关契约测试及门禁后，使用 infra 正式最小更新入口；独立核对部署代码与健康状态，并诊断苹果、腾讯后复权窗口。实际外部读取若被权限或连接阻塞，记录准确错误，不认证为已成功回测。

## 实际验证边界

先验证不含外部调用的契约，再对两个标的各执行一个最多 93 天的隔离窗口诊断，单来源、沿用脚本超时与分页预算。小窗口通过后，每个标的各复核一次原任务的完整窗口；脚本通过显式 `--max-window-days 400` 放行含预热的一年窗口，默认仍为 93 天，不提高单次请求、分页及超时预算。不修改、覆盖或自动重跑原任务。
