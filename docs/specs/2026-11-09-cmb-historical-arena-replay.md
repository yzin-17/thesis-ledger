# 招商银行真实历史模拟成交回放

## 目标与边界

复用 2026-11-06 封存的招商银行双模型决策，为下一交易日 2026-11-09 补齐有来源的开盘状态和执行规则，生成可审计的模拟成交，并在真实行情图核对买卖点。关联[模型比赛规格](2026-11-05-model-arena.md)与[归档任务](../archive/tasks/2026-11-09-cmb-historical-arena-replay.md)。

不新增模型调用，不改写既有决策、失败回执、真实或影子账本；11 月 10 日前向比赛继续运行。新回放必须明确标识为历史回放，不计为前向验收。不得用测试样本、一般规则或日终成交量假冒开盘状态，不回填虚假的来源可用时间。

## 行为与验收

- AC1：决策严格复用原始封存材料及两模型有效回执，核对哈希、标的、模型身份、材料截点及下一交易时段；后取执行事实不进入原决策输入。
- AC2：开盘价格、是否可交易、报价步长、手数、价格边界及结算要求均有与标的和执行日期匹配的来源。规则须保留发布、生效时间及适用范围；来源不可得或覆盖不足时保留具体原因，不放宽门禁。
- AC3：历史执行重建与实时开盘读取分开，消费已冻结且验证的证据，复用生产撮合计算。核对价格、数量、费用、现金与目标权重，重复执行不得生成重复成交。
- AC4：将获准且证据齐备的回放作为独立比赛记录发布，保留原决策和执行来源引用；不覆盖旧比赛及其失败历史。主 API 的报告和点位必须来自同一组模拟成交。
- AC5：实际浏览器中核对日线买卖点、模型筛选、日期、方向、价格、报告跳转及周期切换，覆盖代表性桌面与窄屏宽度。受控测试和真实数据结果分别报告。

## 外部读取约束

仅招商银行 `600036.SH`、2026-11-06 决策及 2026-11-09 开盘范围。复用本地材料优先；真实读取使用已选行情来源（同花顺、BaoStock 等）与交易所官方规则。单类事实初次最多两次来源请求，累计最多十二次数据请求；不申请新增付费额度，不做模型探测、不切换或启用新来源。现有行情配额消耗按实际回执保留，来源费用未经核实则标记未知，不宣称免费。若需要购买额度、新权限或扩大日期范围，先记录具体缺口。公开官方文档检索用于核实规则与来源，不认证未经核实的证券状态。

本次只重建初始现金账户的单轮买入：无需出售既有持仓，故不认证历史可卖数量、卖出回款或完整客户账单。费用严格复用原赛制 `fixed-v1`，不把其佣金、最低额和滑点配置解释为法定收费事实。后取的执行证据只用于后验执行重建，保留真实取得与核验时间，不进入原模型输入，也不认证当时已经持有这些事实。
