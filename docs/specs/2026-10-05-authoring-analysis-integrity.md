# 编写分析结果的引用与确认边界

本叶归属自然语言策略 T03，只处理分析输出的可信转换前置，不关闭生成、目录确认或正式保存。

模型输出的问题必须绑定输入修订；需求引用必须实际出现在冻结描述或用户已确认答案中。问题依赖只能引用已知问题，不能自引用或形成环。模型不能确认用户答案、移除需求或覆盖已生成定义。

后续应用分析时应保留原需求、运行意图、用户移除记录、手动定义和编辑记录。问题语义及依赖完全相同时可保留已确认答案；问题变化或依赖答案失效时，相关答案回到待审核。新内容超过集合或字节上限时拒绝，不截断。分析检查由编写领域的纯函数持有，AI 审计仍记录实际收到响应与用量。

执行器在收到并保存调用事实后检查分析引用；失败为 `AUTHORING_ANALYSIS_INVALID`，不重新调用模型。原子应用由 V3 拥有：当前用户和输入修订锁决定是否追加新修订；操作、草稿修订在同一事务内更新，重复应用返回相同修订引用，之后的编辑保持原状。扩展 migration 允许 succeeded 操作的 applied disposition，不改历史 SQL。完整生成校验仍为独立叶，不能用本叶替代。
