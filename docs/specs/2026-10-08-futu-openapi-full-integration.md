# 富途研究所需能力接入

关联任务：[实施与验收](../tasks/2026-10-08-futu-openapi-full-integration.md)。当前按 2026-10-09 用户“暂时接入我目前用得到的功能”收窄范围，并纳入用户明确需要的分钟线；既有[每手股数合同](2026-10-08-security-lot-size-routing.md)与已通过证据继续有效。

## 目标与边界

富途成为当前价格研究与港美回测所需的可配置数据来源，保留港股股票每手股数、港美股票/ETF 当前证券资料、实时报价、历史日线，并增加历史分钟线。复用主备路由、来源元数据和消费者；SDK 已安装或目录出现名称不代表功能完成。日线回测保留来源冻结与离线重放，分钟线首期用于行情图表查看。

2026-10-08 基线：富途已接入港股股票每手股数。OpenD 已启动，产品连接为 `host.docker.internal:11111`；DSA 使用 `futu-api 10.8.6808`，官方文档显示 v10.11。逐接口核对 SDK 与 OpenD 的最低版本；版本缺口必须记录，不能声称新接口已可调用。

当前能力按具体市场、资产、权限和样本声明，不把单标验收扩大为全市场通过。其他资产/全市场证券列表、IPO、相关证券、独立日历/状态/复权资料、板块、逐笔、分时、订单簿、经纪队列、订阅推送、衍生品、资金流、基本面、持有人、公司行动、宏观、榜单、自选与提醒暂不纳入本轮交付，不保留为关闭前置或活动 TODO；出现明确需求时再立项。分钟线读取所需的权限/历史额度检查属于该能力内部责任，不要求先建设独立查询产品。

账户及交易接口继续按用户确认排除；当前实现只创建 `OpenQuoteContext`。本次仅缩小交付范围，已有实现、测试、历史记录和业务校验保留。

## 统一适配约束（2026-10-09 增量）

复用[统一数据能力适配层](2026-10-09-unified-data-capability-adapter.md)的能力合同和来源绑定边界。富途代码格式、SDK 对象、复权枚举、分页游标及查询上下文属于 DSA 来源适配器；上层只消费标准报价、证券资料和 K 线模型，不因来源是富途复制页面或增加业务执行分支。已有实现优先薄适配复用，迁移通用注册机制由独立 Task 拥有，不作为本轮分钟线及消费验收的新增前置。

历史分钟线是查询能力，应保持分钟时间戳、时区、交易时段和窗口语义；不为统一接口送入日线规范化或冒充实时订阅。以后首次增加盘口能力时再定义其标准契约与订阅生命周期，后续来源复用该契约；本次框架测试不重新打开已排除的订单簿、订阅或账户/交易接口。

## 稳定行为

1. 延用当前 OpenD 配置；不自动修改既有价格主备路由。用户可将已接入的富途能力选为主源或备用源，失败只按已配置目标切换。
2. 查询绑定精确证券代码、市场、资产类型和复权/周期/交易时段。不同参数不能共用响应或分页游标。SDK 数据中身份不符、重复/无效数据应明确失败。
   报价 API 支持可选 `assetType=STOCK|ETF|INDEX`，Server 向 DSA 同名参数传递；已知身份的行情详情显式传入股票/ETF 类型。显式类型的缓存与并发锁按类型隔离；未传参旧请求保持兼容，不从美股代码猜测 ETF 身份。
   行情模块接受港美规范代码 `00700.HK`、`AAPL.US`，港股前导零规范为五位；沿用中国内地旧代码格式。该解析属于行情读取边界，不扩大账本录入的市场合同；详情没有资产或目录身份时仍显示未知。
3. 港股时间按香港时区、美股时间按纽约时区转换为带时区的来源时间；抓取时间单独记录。来源缺失的量额与时间保持未知，真实零值保留。
4. 历史日线明确传递 `AuType.NONE/QFQ/HFQ`，按 SDK 的 `page_req_key` 获取全部页；中途失败、循环游标、超出分页上限时失败，不返回伪装完整的前几页。不将供应商不复权字段直接等同于已经验收的历史按股执行资格。
   港美日线通过现有 `interactive` 图表读取入口消费，能力选项、窗口证明和实际读取均按标的市场构造路由；内地路由不能授予港美资格。该入口继续拒绝 `complete`、`point-in-time` 和 `asOf`；冻结回测仍走独立入口。
   港美股票/ETF 的普通价格允许富途、长桥与 Yahoo 直接来源按现行精确目录、同一复权类型整窗主备替换；不混合单根数据，不声明供应商价格坐标或算法等价。未配置、未启用、目录未接入或窗口不足的目标仍不可调用。
5. 一次性查询有可终止的进程期限并关闭上下文。分钟线首期使用历史查询，按用户操作刷新，不新增推送订阅会话。
6. SDK 方法限定在已登记接口内，不向客户端开放任意对象/方法执行。
7. 用户看到的“已接入”指真实适配器与消费者可用；“已验证”标明样本、参数与权限范围。权限不足、额度不足和版本缺失不以空数据或零值掩盖。
8. 冻结快照继续离线重放，富途新接入不能改变旧模型、结果或已有来源资格。

### 当前证券静态资料

`SECURITY_STATIC_INFO` 首期精确覆盖港美股票/ETF，由用户独立配置主备路由，使用 `get_stock_basicinfo` 单标查询。请求携带规范证券代码及明确资产类型；SDK 忽略 market/stock_type 的场景仍须校验返回代码和类型。返回名称、证券 ID、每手股数、上市日期、退市标志、交易所及观察时间，缺失值保持未知。证券 ID 使用字符串保存，避免超出 JavaScript 安全整数范围。该接口是当前资料，不证明历史状态；不接受历史窗口、复权或时间点参数，也不自动创建资产、持仓或目录关联。

`listing_date` 已被官方标为废弃；保留上游原值，并在页面显示“供应商上市日期（未核验）”及字段来源说明。实际 SPY 样本返回 `1970-01-01`，不作为已经验证的上市日，不通过替换成自行推断的日期来掩盖上游问题。

Data Contract 使用 `/market/security-static-info`，Server 提供 `/api/market-data/security-static-info?symbol=00700.HK&assetType=STOCK`。响应绑定请求 ID、符号、资产类型、实际 RouteTarget 与策略修订；资料查询和价格页面分别验收。

### 历史分钟线

首期覆盖港美股票/ETF、`1m`、不复权和正常交易时段。显式调用 `KLType.K_1M`、`AuType.NONE`、`extended_time=False`，仍完整读取分页，失败不返回前缀。保留 SDK 当地时间并按香港/纽约时区转换为带时区的分钟时间戳，不能复用日线规范化把同日各分钟压成一个日期。返回 OHLC、成交股数、成交额与真实缺失状态；不合成缺失分钟。

分钟线需要独立的周期、窗口、来源和缓存身份。共享图表合同须按完整时间戳排序去重，日线仍按交易日校验；完成状态按单根分钟结束及观察时间表达，不宣称整日交易日历证明。页面显示“1 分钟”，来源与正常时段约束明确；保留日线和已有派生周期行为。用户当前请求不要求分钟策略回测或盘前盘后数据，这些不作为本轮前置。
