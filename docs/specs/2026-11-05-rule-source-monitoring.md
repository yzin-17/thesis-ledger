# 历史收费来源更新监测

对应[任务](../archive/tasks/2026-11-05-rule-source-monitoring.md)与[父规格AC15](2026-11-04-todo-4-15-delivery.md)。监测现有CN／HK／US官方收费资料及本轮ETF切片的版本、资料包摘要和已引用公开文件变化；不扩展到全网规则发现、每日证券公告或历史停牌事实重建。

## 状态与执行边界

DSA拥有独立SQLite监测库，置于现有DATABASE_PATH同目录，不写凭据库、业务PostgreSQL、原资料包或冻结快照。保存监测配置、queued／running／succeeded／partial／failed／interrupted任务、资料包版本及公开文件摘要观察。队列只是唤醒信号，SQLite是任务事实源。领取／终态按任务状态、attempt=1及owner条件原子更新；单次失败不补投，租约过期收敛interrupted，晚到执行不能覆盖终态。

新功能默认关闭定期检查，页面明确选择已有来源并开启后每24小时检查一次。手动检查返回持久任务ID；查询失败不能视为任务不存在。关闭只停止后续调度，当前读取在有限边界内结束；关闭定期功能不改变Provider与路由。

来源选择以当前登记目录为边界，请求必须去重且全部属于目录。一次执行快照包含所选来源的全部去重公开URL，文档总数随目录扩展。详见[来源选择规格](2026-11-15-rule-monitor-source-selection.md)与[执行规格](2026-11-15-rule-monitor-execution.md)。每个URL只请求一次、顺序处理、不跟随重定向、不自动重试，单件2MiB、单请求连接／读取有界、整轮300秒、0 USD。后台逐件持久化并释放结果；超时后的文档记录预算耗尽且不再访问。URL只能来自仓库登记的官方资料，API不接受自定义URL或凭据；不携带DSA认证到外网。来源不可达、验证码、非预期文档、超限保留稳定错误和最后成功摘要，不将其当作规则变更或清零。

## 变化含义与消费

资料包保存datasetId、SHA256和首次／最后观察；文档保存原始摘要与规范内容摘要、观察时间及错误。每个市场同时登记对应官方现行收费页面：CN为已核对收费规则的有效状态与附件，HK为现行交易收费页，US为FINRA现行监管收费条文。除旧历史原件修订外，正文及附件链接的变化也能形成复核线索；不自动跟随或采纳新附件。

首次成功建立观察基线；此后摘要变化产生独立版本记录，相同内容仅更新检查状态，不产生外部通知。HTML去除脚本与导航噪声后取正文文本及正文链接，PDF保留原始摘要，DOCX取正文；变化只代表候选材料变化，不推断费率、法律生效或适用市场。这不是全网新规发现保证。

Server仅代理已认证Control接口并验证共享合同；Desktop使用TanStack Query显示配置、最近任务及变化记录，手动检查或定期启用均为明确操作。监测不自动批准、覆盖规则、修改Provider路由、使缓存失效、重新执行回测或发送飞书等消息。已冻结执行模型继续使用自己的来源副本。

## 验收

分层证明持久化／恢复与并发领取、受控HTTP正文／错误／大小限制、同内容安静及变化留存、Scheduler开启／关闭、Control认证与严格输入、客户端竞态和状态展示；再包／门禁、正式目标同步、真实已有公开文件有限读取与页面验收。目标真实读取单轮最多选择一个现有来源，最多6个公开文件，失败不自动重发。
