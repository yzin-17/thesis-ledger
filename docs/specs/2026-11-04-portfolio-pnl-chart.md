# 投资组合累计盈亏走势图规格

> 任务标识：portfolio-pnl-chart
> 日期：2026-11-04
> 对应任务：[已归档实施任务](../archive/tasks/2026-11-04-portfolio-pnl-chart.md)

## 目标与现状

用户确认需要按时间查看累计盈亏。完整走势图位于[统一收益工作区](2026-11-05-performance-workspace.md)的收益分析页签，组合概览保留当前盈亏指标；图表继承页面账户、实际/模拟模式和估值响应本位币。现有资产走势接口不能直接用作累计盈亏；当前实际组合的八个收盘快照缺行情，必须保留历史未知。

## 数据口径

累计盈亏与当前组合卡片一致：当时证券市值减当时持仓成本，加经济时间不晚于该点的已卖出交易净盈亏。现金充值、提现和资产总值变化不直接当作收益。历史行情与持仓成本取冻结快照，已实现部分由 Ledger 的当前有效交易投影按成交时间读取；事实更正可改变此计算视图，但不修改历史快照。

Ledger 拥有批量历史已实现盈亏查询，Performance 单向消费；不能反向依赖。单次按账户集合与模式读取平仓事实，禁止逐时点数据库查询。缺成交时间、估算成本或未知成本时不假定已实现收益为零。

历史组合账户范围以冻结账户编号集合为准，新快照冻结该集合。旧组合快照缺少可证明范围时保留未知；单账户快照使用其账户编号。账户模式必须在服务端校验。仅使用快照内的历史汇率证据换算，缺汇率留空；读取图表不触发远程行情、历史回填或快照写入。

## 页面行为

- 累计盈亏按[同图契约](2026-11-05-combined-performance-trend.md)与资产总值同时展示，标题“资产总值与累计盈亏”，共用区间默认近 1 年；原盈亏接口的近 1 月、近 3 月、近 1 年、年初至今、全部及取值口径保持，短区间／近 5 年由客户端在适用返回点中筛选。控件使用中文回显。
- 历史点包含时间、累计/已实现/未实现盈亏、快照编号和稳定的不可用原因码。缺数保留空点，曲线在缺口断开，不补零或平滑填充。
- 最新当前点直接使用当前估值响应的 `cumulativePnl` 与 `valuedAt`，与卡片一致，标注为当前估值；仅一个可用点时展示单点并解释历史不足。
- 提供金额刻度、零基线、日期、悬停/触屏取点和左右键查看；不使用装饰渐变。收益配色沿用项目设置，零值保持中性。
- 历史错误在图表内提示并可重试，不影响持仓和当前汇总；切换账户或模式不得短暂显示旧范围曲线。刷新组合同时刷新图表，交易页不触发图表查询。
- 历史最多读取最近 2000 个有效收盘快照，截断时明确提示；全部表示服务端可提供的该范围历史，不伪造启用前数据。

## 范围与验收

仅涉及只读历史契约、Ledger/Performance 服务、API 客户端和桌面 Web；新增 JSON 冻结字段不改数据库结构，不追写旧快照。保留所有现有账户、交易和行情配置。

- AC1：批量已实现盈亏按模式、账户和成交时点隔离，后发生卖出不提前计入，未知时间/成本保持未知。
- AC2：服务端按冻结快照与 Ledger 证据计算累计盈亏，使用历史汇率、稳定原因码和明确账户范围；读取无写入和远程 Provider 调用。
- AC3：公共契约验证参数、空值与响应范围；客户端查询按账户、模式、币种和时间区间分缓存。
- AC4：曲线、缺口、零值、单点、空历史、失败恢复和鼠标/触屏/键盘操作正确，与当前卡片金额一致。
- AC5：账户、模式、区间和刷新联动正确；定向测试、包构建、边界门禁与本地真实 API/Web 验收通过。

真实历史不足时验证单点和缺口诚实展示，确定性多点与买卖时点由测试验证；不得把 fixture 多点曲线称作真实历史。Docker 快更若执行，必须使用维护入口，不能据此宣称镜像或安装包已更新。无未决设计问题。
