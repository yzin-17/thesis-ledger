# HiThink 默认路由与页面凭证配置

> 任务标识：MARKET-HITHINK-DEFAULTS
> 日期：2026-10-07
> 状态：本地、目标 API 与真实 Web 客户端验收完成；选择与普通能力执行规则现由[市场数据精确接入与用户自主选择](2026-10-07-market-route-user-choice.md)定义。
> 对应任务：[已归档实施任务](../archive/tasks/2026-10-07-market-hithink-defaults-credentials.md)；[客户端验收](../archive/reviews/2026-10-08-market-provider-client-acceptance.md)。

## 背景与目标

用户要求路由页面直接使用 HiThink 默认主源，并通过前端管理 HiThink 凭证；同时核对其他来源“尚未准入”的实际原因。

页面依赖精确能力目录；来源已启用并不表示每项能力已就绪。实施前 HiThink 凭证定义为空，前端没有配置入口，只能使用环境 API Key。默认路由与凭证属于同一市场数据设置流程，但分别验证客户端和 DSA 执行边界。

## 设计与可观察行为

- 路由页面初始化时，对尚未选择来源、且完整目录中只有一个精确 HiThink 目标的能力，自动填写 HiThink 主源。用户已保存的主备选择保持原值；不支持的复权口径保留其他可选来源。页面不提供预览预设的额外步骤。
- 默认值进入可编辑草稿，通过现有“保存路由策略”统一提交；不在页面读取过程中隐式保存。用户清空或编辑草稿后，目录刷新不得覆盖这次操作。
- HiThink 复用现有凭证侧栏，字段为必填、保密的 `API Key`，认证方式为 `api_key`。页面凭证由 DSA 加密保存，不返回明文；页面优先、环境备用，留空只保留已有页面字段。
- 保存、草稿测试、运行时读取使用同一凭证解析链路。凭证缺失时保留 HiThink 默认配置意图并禁用下拉项，配置凭证后恢复可选；执行前必须完成凭证配置；保存凭证本身不证明接口权限或高级证据能力。
- 对当前目标运行态只读核对 Provider 配置、精确目录和准入记录；报告未建立、过期、撤销与缺凭证的实际区别。不会根据旧验收记录自动签发新的准入。

## 边界与兼容

不新增数据源适配器，不更改高级事件或历史事实的准入规则，不购买服务或申请账号。不改数据库结构、不迁移已有凭证、不覆盖已保存路由。原凭证配置规格仍定义通用安全约束，见[页面凭证配置](2026-09-14-market-provider-credentials.md)。本规格补充 HiThink 并更新[多源规格](2026-09-25-multi-source-adjustment-aware-backtest.md)中的默认路由行为。

## 验证策略与风险

客户端定向测试覆盖自动默认值、未就绪/缺凭证、已有主备、异步目录到达及编辑后刷新。DSA 使用隔离 SQLite 和合成 API Key，通过真实 Control HTTP 保存、加密重开、轮换、环境恢复及运行时取值验证；合成测试不证明真实账号权限。

目标部署只使用 infra 的正式同步入口，验证实际 API 返回 HiThink 凭证表单与既有就绪能力；浏览器验证移除预设入口并展示凭证配置。用户真实页面 API Key 的写入与连接权限需要用户提供输入，不用环境密钥替用户写入。

默认值仅补充空路由可能使草稿变为待保存状态；保留已保存选择及不隐式提交的提示由现有修订/保存状态表达。

## 未决问题

无阻塞设计问题。真实页面凭证输入未提供，使用合成凭证验证安全和执行链路，真实账号页面写入单独记录未执行。

## 验收标准

- AC1：路由页面自动补充可用 HiThink 默认主源，且无预设预览步骤；已有主备、其他口径和用户本次编辑不受覆盖。
- AC2：HiThink 在前端具有 API Key 配置入口，凭证安全保存、留空保留、轮换与环境恢复均成立。
- AC3：运行时读取页面 HiThink API Key，页面失效不静默回退；缺凭证不开放默认路由，其他独立准入规则保持有效。
- AC4：当前“尚未准入”有来源级只读诊断证据，区分配置状态和具体能力状态。
- AC5：正式同步后目标 API 与浏览器展示新行为；真实账号页面保存、权限测试的证据范围明确。
