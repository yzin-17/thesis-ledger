# 研究V2来源故障与准备截止验收规格

> 日期：2026-10-31。父合同：[研究工作台](2026-08-25-ai-research-workbench.md)、[研究V2冻结与引用](2026-10-18-research-evidence-evolution.md)。[已完成实施任务](../archive/tasks/2026-10-31-research-source-fault-acceptance.md)。

## 目标与运行面

补齐研究V2实际来源准备失败、完整准备截止及最终引用的运行证据。V2生成只消费冻结可用材料；不制造失败Tool记录，不重生成已验报告。

保持目标默认、Provider配置及两个空对象，使用现有Server容器的实际编译模块，在所属临时目录启动专属HTTP实例和独立PostgreSQL。使用真实控制器、身份、范围权限、准备服务、SDK、持久化及报告查询；缓存端口只返回未命中。真实样本连接实际DSA和Cloudflare；独立实例不冒充主实例任务，隔离库不冒充目标业务数据库。

## 授权及保护边界

用户本次明确授权仅同花顺`hithink-news-stock-timeline`、`600519.SH`、2026-10-24～10-31元数据：先实读最多1页10条，再从维护入口生效起续验1小时，其他准入、路由、凭据和默认保持。先准备入口及保护基线，再消耗当次实读和有效期。

新模型仅现有Cloudflare/Qwen，次数不限、费用上限0；具体本叶最多1次业务请求、无自动重试或回退。复用用户确认的Workers Free及已验D58请求参数，仅隔离内存描述使用0 USD预算费率，不改目标标准价格或计费。费用估算与上游实报分列；配额拒绝立即停止，不升级、充值或调用第三方付费模型。

真实凭据仅在原Server进程环境内读取/解密，不输出、导出到宿主或写入隔离数据库。目标库只读事务仅读取现有Cloudflare与该公开标的。隔离库不复制账户、账本、持仓、成交或其他私有资料。临时数据库明确固定前缀、随机所属容器名、精确身份；迁移使用当前全部SQL，不改结构/依赖/镜像。只清理所属临时资源，失败证据导出失败时保留资源供恢复。

## 受控故障与真实事实

中继先实际读取同一单页新闻，核对原响应为获准同花顺、最多10条、元数据日期落在授权窗口。只记录状态、数量、摘要和时钟，不改写新闻内容或伪造源站错误。

样本B先执行：实际新闻响应到达中继后保持交付，沿用DSA请求120000ms和准备共享30000ms；原控制器应以RESEARCH_PREPARATION_TIMEOUT退出。尚未提交时隔离库AiRun/Tool/模型请求均0，连接断开可观察，完整墙钟不加速。

样本A随后执行：实际新闻响应到达后断开该交付连接，价格正常。primary-risks允许新闻缺失；准备结果应冻结新闻不可用及原因、价格可用。人工核对冻结包后只执行1次Cloudflare，请求通过原V2合同；报告质量明示缺口，引用仅绑定可用材料的真实Tool，缺失新闻不参与引用。中继交付故障不称为源站自然故障。

两个样本各最多1页10条、合计最多2次新闻消费请求；前置准入验证的单页实读单独记账。模型中继最多放行1次且只允许指定Qwen端点，超额拒绝发生在外部派发前。

## 入口与验收

入口默认只输出计划，不创建Docker资源、读取凭据或调用外部来源。显式controlled模式只用本机假来源/模型；live模式必须提供本次授权和未到期的精确准入回执。先本机定向，再隔离HTTP/SDK/PostgreSQL，最后真实样本。

| 断言 | 验收事实 |
| --- | --- |
| RF-AC1 | 默认只读计划、精确隔离身份、外部次数与来源范围拒绝、凭据不外泄、所属清理 |
| RF-AC2 | 实际编译服务在独立HTTP/数据库完成来源故障→冻结→SDK→报告读取，受控结果明确标识 |
| RF-AC3 | 实读1页/10条后精确准入4→新版本及1小时窗口，其他准入/政策/凭据保持 |
| RF-AC4 | 真实来源交付保持至完整30秒准备截止，未提交时模型和任务均0 |
| RF-AC5 | 实际来源交付失败、真实Cloudflare、合法V2结果/质量/数字/引用及真实Tool绑定 |
| RF-AC6 | 旧业务/审计、全部目标配置/默认/空字段保持，原Source授权差异仅获准一条，证据和清理完整 |
