# 账户数据的单账户范围

> 任务标识：account-data-single-account
> 日期：2026-11-05
> 对应任务：[实施任务](../archive/tasks/2026-11-05-account-data-single-account.md)

## 目标与职责

Desktop 的账户数据用于查看和维护具体账户的持仓快照、成交、现金与适用的定投计划。跨账户估值、收益和持仓汇总由投资组合页面承担。账户数据的选择器仅列出当前实际/模拟模式下的具体账户，继续提供管理账户入口。

移除重复的账户数据组合汇总视图及其聚合请求，不新增账户总览或替代仪表盘。不修改投资组合页面的账户范围、API、账本事实、原生客户端或数据库。

## 选择与地址兼容

1. 有效的具体账户地址优先；默认恢复当前模式下仍有效的最近账户，没有记录时使用该范围的第一个账户。
2. 历史 `accountId=all`、失效地址或失效的最近账户按相同规则选择具体账户；旧地址使用 replace 规范化。旧 all 记忆更新为具体账户，不作为合法账户继续保存。
3. 账户目录尚未就绪或读取失败时，保留深链，等待成功读取后再判断账户是否缺失；当前范围确认为空时保留创建账户入口，不请求其他模式数据。
4. 账户不匹配时清除绑定该账户的录入入口、定投来源定位与旧编辑上下文，防止旧链接自动打开另一个账户的录入表单。适用的页签继续按具体账户类型处理。
5. 账户切换继续经过原有草稿/忙碌保护；管理账户、定投来源定位、前后导航与模式隔离保持。

## 实现边界

`account-data.selection` 拥有具体账户解析规则；`useAccountDataNavigation` 负责当前模式记忆、地址规范化和切换保护；页面与选择器组合具体账户内容。删除无消费者的 `AccountDataAllAccountsView`，不把账户列表或汇总放回页面其他区域。

## 验收

- AC1：选择器只出现当前模式具体账户，账户数据不显示组合汇总/持仓总览；投资组合继续提供跨账户汇总。
- AC2：默认、最近账户、旧 all、失效账户、空范围、目录加载/错误与实际/模拟模式隔离有回归；旧 all 不触发聚合估值或跨模式账本读取。
- AC3：旧入口/来源不打开错误账户表单；账户切换、管理账户、页签和定投来源导航的保护继续通过。
- AC4：定向测试、Desktop 类型/构建、相关门禁和最终生产预览通过；在 1440、768、390px 验证账户选择、旧链接、具体账户内容及投资组合入口。

真实业务数据只读，不提交表单、不更新 Docker 或安装包，不提交或推送代码。受控写入行为沿用测试样本验证。
