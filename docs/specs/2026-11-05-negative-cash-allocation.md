# 配置分析支持负现金余额

## 问题与范围

本机收益分析配置页稳定失败。真实只读估值返回证券 176.76 元、现金 −82 元、净资产 94.76 元且估值完整；前端按原值提交配置计算，接口以“资产市值不能为负数”返回 400。目标读取正常且当前未设置目标。

修复配置校验对现金的错误限制，保留账本事实、净资产分母与既有权重／再平衡公式。不补写余额、不改持仓／目标／交易，不扩大负证券市值支持，也不改变数据库或接口字段。

## 稳定契约与验收

- AC1：现金类别允许有限负余额；别名按现有类别规范化处理，非现金负市值仍拒绝。
- AC2：完整且净资产为正时，权重按证券与带符号现金总和计算，允许证券权重高于 100%、现金权重为负；金额与权重不截断或补零。
- AC3：再平衡继续使用同一净资产与目标权重公式，现金缺口包含原负余额；差额按原规则取分并合计为零。非正净资产和不完整估值仍不提供完整权重／建议。
- AC4：Desktop 真实查询／API 投影能接收带符号金额和权重，展示当前配置并保留目标设置；前端不通过忽略 400、伪造成功或改写现金掩盖问题。
- AC5：领域及 Server 定向回归、构建／边界通过；使用复现的真实输入检查真实计算路径。目标运行态是否已更新必须独立说明。

## 实现归属

领域拥有再平衡输入约束及原公式；Performance 适配层按规范类别验证市值。API 契约已有有限带符号金额和权重，字段不变；当前未设置目标时只计算配置，设置目标时复用原再平衡。
