# 统一市场开闭市状态与日历消费

## 目标与所有权

统一报价、基金估值、自动任务、后台报价、风险最近完整收盘日、盘中估值采样和客户端休市展示的日历判定。Domain 负责只依赖已验证日历事实的状态投影，Market 负责读取与缓存本地展示日历；其他 feature 单向消费，不维护另一套周末、节假日或交易时钟规则。项目 `AGENTS.md` 固化这一所有权和复用要求。

## 状态与兼容合同

- 共享状态明确区分 `open`、`closed`、`unknown`，另提供当日是否交易日、最近已结束时段、最近完整收盘日、下一边界及相关真实会话。使用日历时区、完整覆盖、版本与可用时点；未知、未来、覆盖不足不能转成休市。
- 报价快照判定复用共享状态，仍要求覆盖最近有效时段；休市不覆盖来源失败，也不放宽严格实时行情门禁。
- 基金估值增加未知市场状态和稳定原因；未知时不计算或记录新分钟事实，不把旧值冒充当日新估值。正常休市沿用原始有效事实及其时点。
- 自动任务区分“交易日”门禁与“交易时段”门禁，沿用手动执行和自定义门禁语义。日历未知保守跳过并返回明确原因，不能作为普通休市。
- 盘中采样只处理已确认开市且有实际持仓的市场。历史价格交易日归属和基金收盘误差读取对应时点的日历，不改写冻结记录。
- 客户端只消费服务端的共享状态或会话事实。自选分时的休市间隔从实际会话计算，日历缺失时保留真实时间缺口；证券资料弹窗与双端估值文案复用共享展示契约。
- 原响应新增字段保持可选；新增状态与原因在 Schema、API 客户端、Desktop/Mobile 消费者同步兼容。无需数据库结构变更，不启用新来源或扩大准入。

## 验收

- AC1：纯状态与读取接口验证交易中、盘前/盘后、午休、周末、节假日、提前收市、时区/夏令时、未知/未来/覆盖不足，以及同市场日历请求复用。
- AC2：报价、基金估值/价格归属/收盘误差、后台报价、风险、调度与采样实际消费者接入，失败与严格门禁保持，未知日历不产生虚假休市或新事实。
- AC3：Desktop/Mobile 与派生行情入口正确展示未知和休市；分时图基于事实画休市间隔。四种宽度浏览器检查通过。
- AC4：项目 AGENTS 记录复用要求，边界门禁限制新增旁路；定向测试、包级构建和门禁通过，再通过 infra 最小正式入口同步并核验真实只读运行态。
