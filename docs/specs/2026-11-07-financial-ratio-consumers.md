# 收益、组合与风险比例读数统一

## 问题与目标

首批双端比例展示已建立共享合同，后续搜索确认 Desktop 的收益摘要、带符号收益、配置差额、目标编辑当前权重、走势覆盖、组合持仓及风险触发指标仍独立使用浮点乘法与固定小数，导致同一比例在不同入口呈现不同结果。

将这七处消费者接入现有 Domain formatRatioPercent。保留各自正负号、零值、可用性、错误原因与历史消息语义；不改变输入、计算或业务请求。

## 验收标准

- AC1：普通两位、临界舍入、极小正负值与超大有限值在七处消费者一致；带符号收益保持原正号和零值规则，非法数值不显示 NaN/Infinity 或加号加破折号。
- AC2：实际收益指标、配置差额、目标编辑当前权重、走势焦点详情、组合摘要与表格、风险事件行有真实回归。原快照不足、partial、汇率阻断、读取失败、进度条边界、原事件 message 均保持。
- AC3：四宽浏览器使用实际组件，检查读取、展开编辑、关闭、图表聚焦与 Escape、表格容器、文本及溢出；业务请求和写入为 0。
- AC4：定向回归先记录旧代码失败，再完成 Desktop 完整包、构建、lint、边界和尺寸约束；共享和 Mobile 未变输入复用前轮证据。

业务写集限于 performance-display、performance-return-display、PerformanceSections、PerformanceTargetEditor、PerformanceTrendChart、PortfolioOverview、risk.format。格式化仍由 Domain 拥有，不新增跨特性 helper 或共享杂物层，不调整计算、排序、颜色和 DOM。

回测、行情、模型竞赛的两位小数入口及一位小数摘要、文本型高精度比例属于后续独立核对范围；已发现的问题继续作为全线程 Goal 的执行项，不据本任务完成宣称整个项目收口。
