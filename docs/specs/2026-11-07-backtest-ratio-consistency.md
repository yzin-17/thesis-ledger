# 统一回测列表、详情与图表的比例展示

## 问题与目标

统一回测详情和列表先把文本指标转换为 Number，再乘 100；长小数、极小非零和巨大值仍会丢失。图表回撤轴和焦点读数各自保留旧的乘法格式化，可能与指标语义不一致。

复用现行 Domain 文本与 number 比例合同，在策略特性内统一指标状态解包和百分比投影。百分比以外的夏普、利润因子、金额及图形计算保持原合同；最大回撤指标沿用绝对幅度，图表保留原始回撤正负。

## 验收标准

- AC1：列表与详情对 number、十进制文本、available 包装及旧 amount 包装一致；普通两位、临界长小数、极小正负、最大有限与超大文本正确，零和未知值分开。
- AC2：列表任务终态说明、指标名称、缺失/不可用原因、基准兼容限制和冻结原文保持；不修改结果对象、回测计算或存储。
- AC3：图表回撤轴和焦点使用共享 number 展示，原始序列、时间、缩放、范围与键盘锁定/解除保持。真实浏览器覆盖 1440、1024、768、390，检查溢出、控件、读数和取消焦点。
- AC4：先建立失败回归，定向、Desktop 完整包和构建、lint 与仓库门禁通过；最终输入稳定，证据和剩余边界明确，关闭 Task 后继续全线程 Goal。

## 所有权与写集

指标状态与历史形状读取仍归 strategy-backtest-detail.model，增加明确的百分比展示入口；strategy-list-presentation 与 StrategyBacktestDetailSections 单向消费。strategy-backtest-result-availability.model 的比例有效性也使用同一合同，兼容性和费用门禁仍优先，避免有效超大文本被误判缺失；非比例有效性继续原 number 规则。StrategyBacktestEquityChart 和 useStrategyBacktestChart 只改显示函数。维持现有模块方向和共享包所有权，不新增通用 utils。

已有 Domain 共享文本合同和 614 项验收保持，除非发现其新缺陷，否则不改共享包或重复其完整验证。策略版本摘要目前使用最多三位，与本轮两位合同分开；非百分比原始文本保持各自语义。

## 执行边界

浏览器使用受控读取样本和真实业务组件/图表；不触发业务 API、来源或模型，不修改真实数据，不部署、不操作 Docker，不改变 Native 工程。复用现有 5173 开发服务，测试不得重启它。
