# 免费官方新闻与 DG3 接入规格

本规格承接 [DSA 新闻合同](../../../daily-stock-analysis/docs/specs/2026-10-18-data-only-service.md)，实施见[已完成任务](../archive/tasks/2026-10-22-free-news-dg3.md)与[最终复核](../reviews/2026-10-22-free-news-dg3-final-review.md)。DG3 的完成记录由 DSA 原 Task 持有，研究 G3 的模型与发布门禁保持独立。

## 来源与范围

用户授权查找免费来源，可用时接入并推进 DG3。首源使用 NVIDIA 官方 Newsroom RSS：`https://nvidianews.nvidia.com/releases.xml`。[官方说明](https://www.nvidia.com/en-us/about-nvidia/rss/)允许个人非商业信息用途。已有公开索引含 `NVDA.US / US / STOCK`；来源只覆盖该发行方，不宣称全市场、完整历史或商用授权。

- 来源为 `nvidia-news / nvidia-newsroom-rss`，只绑定 `US / STOCK / NEWS_SEARCH`，其他标的在请求上游前返回未覆盖。
- 无 Key、无注册，默认关闭；显式启用、精确政策、当前修订及标的/日期准入仍须满足，保留控制变更与缓存撤销保护。
- 来源模块拥有 RSS、URL 与日期解析；公共执行器只管理预算、进程回收、实际尝试及通用记录。固定 HTTPS 订阅地址，不接收任意 URL 或自动重定向；限制字节/条目，拒绝 DTD/实体与非法外链。
- 复用 `news-search-v1`。只取标题、发布方、原文链接、条目标识和明确 `pubDate`，不抓正文或生成摘要。非法/缺失日期保持未知，可用时间未独立证明则为空，有限订阅覆盖保持 partial 并说明缺失原因。
- 最多一次上游请求，保留 429、超时、HTTP/XML 失败和零尝试拒绝，不换源或无限重试。

## 消费与保护

沿用 `/api/market-data/news` 的 Market 读模型；只读侧栏使用共享合同、TanStack Query 和现有组件，显式检索并展示原文链接、来源、发布/抓取时间及覆盖质量，失败明确提示，关闭/切换不混入旧请求。无需报告、账户或成交写入，不改变模型开关。

通过 infra 正式入口更新最小目标。仅新增本来源、精确准入与新闻路线；保留原十六条路线、来源、凭据和全部业务数据，登记前后差集。可写层与镜像证据分别说明。

首次准入通过 infra 的 `scripts/nvidia-news-admission.mjs` 计划、显式应用与只读核验入口执行：锁定开发目标、固定发行方、已审阅 RSS 摘要、标的和日期，只安装元数据证据；不调用会初始化结构或轮换凭据的普通构造器。有效期明确指定且不超过七天，已有准入不覆盖或续期，写事务内再次检查并发记录。普通来源配置与准入记录继续分开，其他来源不因此开放。

## 验收标准

1. F-AC1：官方免费访问及个人非商业边界有依据，实际读取成功，无新账号或秘密。
2. F-AC2：注册默认关闭，身份/范围/政策/准入/修订与缓存撤销有证据，错误标的零上游尝试。
3. F-AC3：XML、URL、日期、大小、进程与失败边界通过，已有新闻来源行为保持。
4. F-AC4：正式 V3 有真实非空条目，原文与日期可核对，partial/未知状态如实表达。
5. F-AC5：主仓合同、Market 与实际 Web 的条目、质量和失败状态通过，模型调用为零。
6. F-AC6：正式更新、目标同源与原业务/来源/路线保护通过。
7. F-AC7：实现、证据、原 DG3 与总表一致，研究 G3 等其他门禁不由此关闭。
