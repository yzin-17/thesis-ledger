# 基金净值曲线的账户成交标记

> 任务标识：fund-nav-trade-markers
> 创建日期：2026-11-07
> 对应任务：[已完成实施任务](../archive/tasks/2026-11-07-fund-nav-trade-markers.md)

## 目标与范围

在基金历史单位净值曲线上，自动标出当前明确账户、模式和完整基金代码的有效账本买卖成交；点击标记查看该日对应方向的成交明细。保留净值、累计盈亏、缩放与日期锁定行为。只读消费现有成交投影，不写入账本、不访问远程来源补全成交。

## 契约与职责

`FundNavPnlChart` 提供账户上下文，独立查询 Hook 复用 `portfolio.getTradeChart` 的有效成交投影与原始十进制字符串，图表资源与明细各自独立。成交合同同时接受交易所证券及六位 `.OF` 基金代码，实时行情合同独立维护。Server 的 Ledger 只读查询按账户、模式、完整代码和窗口隔离，并保留投影代次、预算及未知日期检查。

## 行为与边界

- 查询范围为已加载净值历史的首尾日期，TanStack Query 管理缓存、取消、错误及竞态；没有明确账户或模式的目录入口不查询成交。实际与模拟账户分别读取各自账本，绝不混合。
- 买点使用向上箭头，卖点使用向下箭头，挂在同一净值序列的对应日期。只匹配来源净值日期，不把无净值日期的成交移到相邻日，不用成交价替换净值或补造净值。
- 同日同方向标记合并，点击打开该组全部成交；同一事实被拆成多个卖出分摊时，按事件、事实、方向、价格、币种和日期精确汇总数量，保持成交身份与原始精度。
- 明细显示名称、代码、账户、账户类型、成交日期或时刻、买卖方向、成交数量、成交价格与币种。日期精度成交不伪造具体时间；仅显示接口已有的成交字段。
- 提供与图表相同数据的可键盘操作成交入口；关闭明细保留行情详情与图表窗口。账户、模式、标的或历史范围切换后，旧范围的标记及已打开明细立即失效。
- 首载在图表结果区显示加载圈，同范围刷新保留曲线与已有标记；失败可重试并保留同范围可用结果。无成交、范围内无净值可匹配、未知日期、预算与投影不可用分别说明。

## 验证与兼容性

不改变数据库、队列、Provider、客户端原生工程或已有实时行情代码合同。先做合同与投影定向测试、标记归位及拆分汇总测试、图表事件与查询竞态测试，再做 Desktop 类型检查和构建、边界门禁。浏览器覆盖 1440、1024、768、390 宽度，验证标记实际绘制、点击/键盘明细、关闭、缩放、重试、账户隔离和无横向溢出；真实业务数据只读，额外场景用受控响应。运行态需要新合同校验时通过 infra 的维护入口更新并独立核对，不把快更当作镜像发布。

## 验收标准

- AC1：成交合同接受合法 `.OF`，保留证券校验及账户、模式、窗口隔离。
- AC2：有效买卖记录标在相同日期净值曲线；缺净值日期不错误平移，同日买卖与多笔成交可辨识。
- AC3：点击标记或键盘入口可查看精确成交明细，卖出拆分数量正确，关闭保留原图表。
- AC4：切换作用域不泄露旧数据；加载、失败重试、无成交和不可绘制原因正确；原净值与盈亏功能保留。
- AC5：定向检查、实际浏览器及只读真实接口验收完成，工作区其他改动与业务数据保留。
