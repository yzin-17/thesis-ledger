# 回测图表买卖点

日期：2026-11-11。对应[初版实施任务](../archive/tasks/2026-11-11-backtest-trade-markers.md)、[初版验收记录](../archive/evidence/2026-11-11-backtest-trade-markers.md)与[显示控制验收](../archive/evidence/2026-11-11-backtest-trade-visibility.md)。本文件保留为当前展示合同。

## 目标与范围

回测结果的权益图参照标的详情页展示买入、卖出标记，并在原有时点读数中展示成交信息。本次只修改 Desktop 的冻结结果展示；保留历史结果、原始十进制精度和现有导出内容，不新增请求、数据库字段、行情查询或真实交易操作。

## 现状与边界

实施前权益图只有权益、回撤序列和时点读数。标的详情使用 `createSeriesMarkers`，买入为向上箭头、卖出为向下箭头，颜色跟随系统涨跌配色。

只消费结果中的 `simulationFills`。实际样本中的成交在盘中，权益在收盘估值，时间戳不能直接等同。成交标记表示模拟成交事件，其纵向位置沿用权益曲线，不能解释为成交价格。

## 展示合同

1. 精确时间相同的成交直接映射到该权益点；否则使用成交之后、同一显示日期内的首个已有权益点。显示日期只按结果时区转换已有时间戳，不判定交易日、会话或行情有效性，不补造权益点。
2. 超出覆盖、缺少同日期后续权益点、时间或方向无效的记录不绘点，并显示未映射数量。没有成交明细时不从订单、拒单或已平仓交易反推出成交。
3. 同一权益时点、同一方向聚合为一个标记；多笔显示笔数，同一时点的买和卖分别保留。保留各笔原始成交时间、标的、数量和价格。
4. 箭头复用详情的方向及配色；回撤继续使用中性色。提供“显示买卖点”开关，默认开启，关闭时清除箭头并隐藏对应成交读数，重新开启恢复；不重置缩放、平移或锁定的权益时点。选择只保存在当前图表实例中；无可显示成交时禁用开关。切换主题或涨跌配色及时更新，替换任务、空成交及卸载时清理旧标记。
5. 悬停、点击锁定或键盘逐点查看时，原读数补充该权益点对应的成交。数量和价格复用共享十进制格式化，最多六位小数，极小非零值保留科学计数法。单点读数最多列三笔，其余显示数量并指向“交易与订单”查看。
6. 保留原缩放、平移、快捷区间、重置、锁定和导出行为；标记不向权益或回撤序列增加数据点。

## 验证与验收

- AC1：真实模拟成交生成正确方向、时间和数量的买卖标记；同点同方向聚合、不同方向分别展示。
- AC2：覆盖精确时点、盘中到收盘、日期边界、时区/夏令时、无覆盖、无效输入、空成交；原结果保持不变。
- AC3：开关、箭头和成交读数一致，开关切换保留图表窗口与权益读数；切换配色/主题及替换任务后无旧标记，数量精度满足展示合同。
- AC4：真实浏览器在 1440、1024、768、390 宽度显示买卖点、可用键盘查看对应成交，缩放平移和重置保留，页面与读数无横向溢出。

定向模型测试验证时间投影与原始数据保留；组件测试验证标记资源、主题更新及原交互；类型检查通过后，在当前源码的本地开发页面只读验收真实回测。受控边界输入与真实结果分别记录。无需 Docker 更新、外部 Provider 或原生编译。

## 风险与未决问题

密集成交按同点同方向聚合，读数限制三笔以保护窄屏空间。标记对齐只影响展示，真实成交时间始终保留。无阻塞问题。
