# 行情图日期区间

任务标识：chart-date-ranges；日期：2026-11-08；状态：现行合同，实施已验收。
对应[实施任务](../archive/tasks/2026-11-08-chart-date-ranges.md)。

## 目标与现状

基金净值图和股票、ETF 行情图统一提供今日、一周、一月、半年、一年、三年、自定义区间。按[常用选项合同](2026-11-08-common-chart-choices.md)显示常用项，其余放入“更多”菜单。实施前基线（2026-11-08）：分钟图按根数截窗，基金详情默认只取得约九十条净值，较长区间需要按需读取已有历史接口。

## 展示与日期语义

基金净值与股票、ETF 行情复用“区间”“视图”分组及视图操作控件；“回到最新”在前，“重置”在后，统一为小尺寸描边按钮和相同间距。分组在窄屏按可用宽度换行。

- 默认一月。快捷区间以最近可用行情日期为结束日；一周覆盖该日及之前六个自然日，一月、半年、一年、三年按日历减月，月末截到目标月最后一日。分钟图按标的市场时区归属日期，不再把日历区间解释为分钟根数。
- 基金持仓图继续将最新累计盈亏日期纳入共享时间轴，快捷范围以该图最后日期为锚点。基金的今日沿用现有盘中估值入口；股票、ETF 的今日展示最近可用交易日期，保持所选行情周期。实际日期和数据状态沿用图表读数展示。
- 自定义区间使用包含首尾的起止日期，校验真实日期、起始不晚于结束、不选未来日期；取消不改变已应用范围。日期和全部选项使用中文标签，键盘与 Esc 保持正确的弹窗层级。
- 历史不足时按需读取已开放接口，保留已有曲线；基金最多沿用现有三千六百五十条上限，K 线沿用三千根上限。请求失败、无数据和覆盖不足分别说明，不能把部分数据声明为完整区间。不得自动更换周期、来源或开通能力。
- 测量、买卖点、成本、盈亏、图表导航及账户隔离继续工作；旧本地快捷区间偏好迁移到可用选项，自定义日期保持可读校验。

## 边界与风险

范围为 Desktop 的行情详情与共享 API 客户端。复用已有历史查询协议，不修改服务端、数据库或 Provider 配置。真实业务数据只读，不提交或部署。自定义超出来源覆盖时提示实际覆盖；上游无数据不伪造成功。日期运算由行情领域的日历合同承担，使用原生日期和市场时区，不引入日期依赖。

## 验收标准

- AC1：两类图表提供七种选项，默认一月，分钟与日线均遵循日期语义，覆盖月末、闰年及美股跨 UTC 日期。
- AC2：自定义区间正确应用首尾日期，错误输入阻止应用，取消保留原范围，偏好恢复经过校验。
- AC3：基金和 K 线按需补充所选范围，保留原曲线并反馈加载、失败、无数据或部分覆盖，遵守既有请求与条数上限。
- AC4：桌面、平板和窄屏（1440、1024、768、390）无页面溢出，自定义弹窗边界、选择、取消、全屏、导航和成交详情交互通过实际浏览器验收。

## 验证方式与未决问题

日期和偏好定向测试、区间控件交互测试、行情历史读取合同测试、Desktop 类型检查，最后执行受控浏览器与真实页面只读核对。浏览器样本覆盖长历史与来源不足，分别记录证据。无阻止实施的未决问题。
