日期：2026-11-04。任务标识：`astock-source-coverage`。状态：首批核对已完成；本规格继续约束覆盖分类与资格证据。对应[任务](../archive/tasks/2026-11-04-astock-source-coverage.md)。

## 目标与范围

按用户确认的建议，核对 a-stock-data 固定提交 `bf447c1d05fa75eac907426601d602125c81a0cd` 所列 34 个主要来源，形成逐来源、逐已验能力的覆盖表；首批验证同花顺财报三表、沪深官方融资融券、沪深官方龙虎榜及新浪研报列表四组备用路径。现有 63 类资料的分层验收继续有效，已有实际证据按相同输入复用，不重新遍历已验来源。

本轮交付是完整覆盖表及四组备用源的可读取性、字段语义与可替代性结论。来源采证与离线投影不等于已接入产品；现有来源选择、策略、准入、业务库和客户端保持当前状态。前端选择备用源及自动切换属于需要另行确定的产品合同，本轮不启用这些行为，不据此增加资料类型。

## 事实与判定边界

参考仓库只作为接口和解析资料，不安装或执行其中的 Skill、Agent 指令、自动重试或关闭 TLS 校验代码。参考版本列出的稳定性是历史声明，必须与本项目实际回执分开。Provider 承载、上游发布机构、接口和资料类型分别统计；相同上游的多个 SDK 不算独立备源，一个接口成功不代表该来源全部能力已验。

覆盖表每行明确来源身份、已验接口／能力、证据种类、项目使用状态和未验能力。状态区分已实测通过、指定路径失败、未测与当前范围外；历史验收附原日期，不能作为今日健康探针。未测不是不可用。一个接口失败只归属该路径；不得将其推成所有替代来源失败或功能取消。

四组首批语义分别为：

| 组 | 来源与核对结果要求 |
| --- | --- |
| 财报三表 | 同花顺 F10 的资产负债表／利润表／现金流量表，核对证券、报告期、单位、科目、币种和披露日，逐字段与当前新浪三表合同比较；无法证明的字段保留缺口 |
| 融资融券 | 上交所及深交所官方来源分别核对交易日、证券、金额／数量单位、发布状态与完整性，比较融资余额／买入额及融券余额；未知金额不得由数量猜测 |
| 龙虎榜 | 沪深官方分别核对请求日期、证券、上榜原因、金额与营业部记录，区分全文与结构化表、证券汇总与席位行；不把不同统计范围相加或混合 |
| 研报列表 | 新浪单证券一页，核对证券过滤、标题、日期、机构、研究员与链接，分别比较现行元数据的条目合同和分页合同；评级／目标价是完整研报能力的差异，不冒称为当前最小元数据的必填字段，来源 ID 和引用不能冒用东财身份 |

可替代性分为字段兼容、部分兼容、不兼容、因读取失败尚未验证；“HTTP 200”不能代替有效数据和合同核对。原件的空值、零、未发布、无记录、传输失败、权限、限频及格式变化分别记录。

## 执行与所有权

主仓拥有覆盖表、当前产品合同的比较和结论。DSA 拥有来源语义、纯解析与离线核对入口，见[子规格](../../../daily-stock-analysis/docs/specs/2026-11-04-reference-backup-qualification.md)。infra 复用固定公开采证 CLI，维护精确端点和独占回执，见[子规格](../../../thesis-ledger-infra/docs/specs/2026-11-04-reference-backup-source-check.md)。不创建平行产品 API，不修改普通行情／回测或账户资产合同。

用户已授权四组公开来源读取。首批固定代表切片为三份财报、沪深两融各一份、沪深龙虎榜各一份、研报一页，共 8 次 HTTP；新增费用 0 USD，无模型或通知请求。后续只在实际响应、明确源码或已核对父链接支持时纠正参数、检查来源说明或补最小对照，并在执行前记录理由、对象和次数，不将首批次数当成用户设定的总上限。单项失败先诊断；没有新依据时不机械重试，继续独立组。

公开采证不以候选已注册为前提，不附带账号、SDK 或 netrc 凭据，不忽略前端配置后冒充正常产品调用。正常 TLS 校验、无自动重定向和无自动重试保持；所有原件与失败独占保存。目标运行态与路由不变，本轮没有 Docker 部署或设备验收义务，也不能声称这些层级通过。
