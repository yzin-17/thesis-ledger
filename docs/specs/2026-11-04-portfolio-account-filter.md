# 投资组合账户筛选规格

> 任务标识：portfolio-account-filter
> 日期：2026-11-04
> 对应任务：[已归档实施任务](../archive/tasks/2026-11-04-portfolio-account-filter.md)

## 背景与目标

同一标的在不同账户中分别持有。当前持仓已按独立账户列展示归属，投资组合页需要进一步支持按账户查看汇总、持仓和交易。

## 行为与边界

- 在[统一收益工作区](2026-11-05-performance-workspace.md)四个页签上方提供一个账户筛选，默认“全部账户”；选项仅包含当前实际或模拟模式下的启用账户。
- 账户触发器与选项复用 `accountDisplayLabel`，全部范围显示“全部账户”。沿用项目现有 Select 与原子类。
- 规范页面 `/performance` 用 `accountId` 查询参数保存账户选择，旧 `/portfolio` 地址保留参数跳转。切换页签、刷新和前进后退保持对应选择；全部范围省略该参数。
- 服务端现有按账户估值接口计算汇总、现金和持仓，客户端不得只过滤持仓后继续显示全量收益。
- 交易页消费同一账户范围；已有标的和生命周期筛选继续可用。清除交易筛选同时恢复全部账户。
- 查询缓存包含模式和账户。账户改变后不得把旧账户数据当成新账户结果；加载和失败时筛选仍可操作。
- 切换实际或模拟模式恢复全部账户。链接账户不存在、已停用或属于其他模式时回退当前模式的全部账户，不发起跨模式账户请求；账户列表尚未就绪时等待核对。
- 保留持仓独立账户列及去重标的、账户持仓数量语义。

## 实施范围

仅修改桌面 Web 的路由接线、组合查询和组件。复用既有 API 和 TanStack Query，不修改服务端、数据库、手机端既有筛选、部署配置或安装包。

## 验收标准

- AC1：账户选项和中文回显正确，包含全部账户，只包含当前模式启用账户。
- AC2：选择账户同时切换汇总与持仓，恢复全部时恢复全量；缓存和迟到结果按账户隔离，失败可恢复。
- AC3：交易页使用同一账户；切换页签与刷新保持范围，清除筛选恢复全部。
- AC4：无效、停用或跨模式账户安全回退，全局模式切换不复用旧账户范围。
- AC5：本地真实 API 与浏览器完成全部→单账户→另一账户→全部及页签联动检查；定向回归、桌面构建和边界检查通过。

## 验证与风险

定向组件和查询测试覆盖请求参数、中文标签、加载、失败、迟到响应与模式隔离；浏览器核对现有两个基金账户的独立持仓和页面操作。浏览器检查证明本地 Web，不代表 Docker 静态文件、Electron 或手机安装包已经更新。无未决设计问题。
