# 业务流程内选择证券与港美股票支持

## 目标

取消独立的标的目录管理页面，用户在自选、持仓和成交录入中选择证券。延续已授权的香港、美国股票支持，资产身份确认由持仓/成交表单自动完成；自选不要求确认。

## 范围与行为

- Desktop 市场数据保留路由策略、数据源、规则监测三个页签，不再提供目录搜索、手动确认和同步页面。Mobile 设置取消目录页面入口及导航注册。
- 保留后台目录、搜索、身份确认和维护 API，现有业务选择器及自动准备目录继续工作；已有受控验收样本保留作为组件/契约回归用途，不再作为生产导航入口。
- 按此前授权支持 HK、US 的 STOCK。保留原 A 股及场外基金类型范围；不同时扩展境外 ETF、指数或公募基金的持仓准入。搜索能力、确认写入及 requireConfirmed 使用同一市场/类型规则。
- 港股使用五位代码，美股保留完整规范代码；持仓新增、编辑和手工输入接受这些代码并保留原精度。现有成交载荷已接受完整代码，不改变其金额、数量、现金或交易规则准入。
- 新建目录关联或手工资产时，HK 使用 HKD，US 使用 USD，国内保持 CNY。新写持仓基线采用资产实际币种，不能继续固定人民币；账户本位币不覆盖证券成本币种。已有资产币种、名称、历史账本与冻结记录不因确认或此次升级被重写。
- 新增港美持仓的成本单位明确显示港元或美元；Mobile 港美股票持仓快照使用相应原生币种并明确提示，国内原有账户成本口径保持。成交币种继续由用户选择，不更改原有默认与校验。
- 自选只检查有效目录身份及自身类型范围，不调用资产确认；新增持仓、成交选择继续自动确认。确认失败保留输入并允许重试，不要求用户跳转目录页。
- 资料仍在标的详情自动读取，行情来源是否已配置与证券能否录入分开处理。

## 验收标准

- AC1：Desktop 目录页签及表单、Mobile 目录导航不可到达，其余市场配置及正常导航保持；旧 section=catalog 地址安全打开默认市场配置。
- AC2：HK/US 股票可搜索、自动确认并通过新增/编辑持仓校验；国内既有行为保持，境外非股票不误放行，无效规范代码不放行。
- AC3：新建港美股票资产的币种和市场正确，已有资产与历史数据不重写；账户资格、现金及成交准入保持。
- AC4：两端选择器不依赖独立目录页，自选添加不触发身份确认；受控请求验证股票选择、自动确认、失败恢复与提交载荷。真实业务只读。
- AC5：定向及相关包验证、边界/规模检查、Desktop 四宽真实浏览器与目标后端运行态通过。Mobile 仅 TypeScript 与导航改动，不修改原生工程或依赖；不将类型检查宣称为 Native compile。

## 所有权与替代关系

市场/类型资格和目录关联归 Server Market；规范持仓代码归 schemas，账本新资产市场/币种归 Ledger；两端导航及表单各自持有。Server 模块依赖不反向新增，检查边界脚本。

本规格替代此前独立目录页面的 UI 合同；原确认状态字段和后台关联事实仍保留。实施见[归档任务](../archive/tasks/2026-11-10-instrument-selection-workflow.md)与[验收记录](../archive/evidence/2026-11-10-instrument-selection-workflow.md)。详情证券资料合同继续适用，其中目录导航入口由本规格替代。
