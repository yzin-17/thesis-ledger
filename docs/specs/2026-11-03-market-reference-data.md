# 市场资料按需查询规格

日期：2026-11-03。状态：当前已实施合同。对应[任务](../archive/tasks/2026-11-03-market-reference-data.md)，父项为[现有来源条件交付](../archive/specs/2026-11-03-astock-existing-sources-delivery.md)。

## 产品目标

让用户在现有市场资料界面显式选择资料类型、证券／指数及日期或分页，查询本轮现有来源实际能够交付的事实，看到中文字段、原始单位、日期、出处及覆盖限制。查询不触发研究生成、交易、记账或自动扫描，不替代既有新闻和行情页面。

## 接口与领域边界

新增 `market-reference-v1` 只读表格合同及 Server `POST /api/market-data/reference`、DSA `POST /api/v3/thesis-ledger/market/reference`。每种资料拥有明确 capability、作用域、列定义和来源适配；统一表格仅为稳定的事实读取投影，不接受任意 URL、SQL、字段名或执行代码。

请求包含资料类型、规范证券或指数身份、可选日期筛选、分页与请求预算。市场级资料不伪造证券身份；指数参考与普通股票分开校验。来源选择遵循前端现有 Provider 配置及该能力的明确有效路由，不隐式切源。结果严格关联请求、资料类型、来源、政策代次和适配修订。

字段为受控列定义及字符串／空值；数字使用有限十进制字符串，单位按来源合同声明，缺失不补零。记录有稳定内容标识、来源引用；日期列明确是报告期、来源记录日、披露日还是交易日。抓取时间独立保留，不替代发布时间。字段或身份不合格时返回明确错误，不能包装为无记录。

当前登记 63 类资料，范围见[使用说明](../market-reference.md)及[当前来源复核](../reviews/2026-11-04-astock-derivative-reference.md)。2026-11-04 先按用户指出的具体参考代码补齐 18 类公开来源，再按[衍生品与可转债规格](2026-11-04-astock-derivative-reference.md)增加 16 类；原 47 类证据按实际输入复用。不能因尚未配置上游而直接判定来源无法满足。旧 EPS 试读中的 CNY 假设未恢复，新实现单独展示来源明确年度的 EPS 汇总和机构预测，保留“元／股”及未知 ISO 币种／统计方法说明，不充当标准化估值合同。申万分类变更及行业排名保留其具体失败与取消结论。

期货与期权仅在 Data Route 增加 `FUTURE`／`OPTION`，可转债沿用 `CONVERTIBLE_BOND`；普通 Bar Route 和账本资产范围保持原合同。代码标签、单日窗口、来源报价单位、近月期权及可转债状态由上述分规格与共享目录约束。

指数按已验切片固定为新浪／中证 `000300`、国证 `399001`。新资料采用独立精确来源及单目标路由；公开路径分别借用已启用的 Provider 承载，不向公开站点附加账号／SDK 或本机 netrc 凭据，不忽略不受支持的前端传输设置。保留原全部路由、来源配置、准入和业务记录。

## 消费与验证

Desktop 与 Mobile 复用现有表单、状态和资料展示组件，TanStack Query 管理显式查询，保留加载、真实空态、来源错误与取消范围的区别。所有类型与当前选项显示共用中文标签；数据源名、单位、日期语义和分页限制可见。

验证分为严格共享合同、DSA 适配与执行、Server／API client 关联、双端交互及真实目标运行态。来源样本不能代替实际 HTTP 或双端消费。原生依赖与工程配置不改变时复用已验原生输入，但须验证当前 JS 的实际运行。

## 验收标准

- R1：可查询类型均有合格源样本、严格字段／单位／时间定义及独立 capability，无猜测或未登记类型入口。
- R2：DSA 使用现有来源和有效配置，来源／政策在执行前后变化会拒绝晚到结果；失败与空态保真。
- R3：Server 与 API client 严格关联请求和响应，不能接受错误证券、类型、日期、来源或版本的数据。
- R4：Desktop 与 Mobile 实际按需查询并显示来源、中文字段、单位、日期、错误和覆盖边界。
- R5：目标实际 API、来源、双端消费及旧数据／配置保护通过；每种交付与取消归属可追溯。
