# 基金持仓行完整性校验

归属多源回测 M3 R04；任务见同名 Task。

- AC1：每条记录必须包含唯一可识别的四位年份与 1–4 季度，允许来源标题后缀；未知或歧义报告期拒绝整批。
- AC2：同报告期原始代码重复拒绝整批；同代码跨报告期允许。API 最新季度中的规范化代码重复不得累加权重。
- AC3：代码和名称必须是非空字符串；权重为有限的 0–100 原始百分比，拒绝布尔值；每季度总和不得超过既有 100.0001 容差。
- AC4：Provider 校验失败映射为 invalid_response，API 不得静默丢弃异常季度。披露时间保持未知，不据此宣称完整覆盖或历史可见性。

仅修改 DSA 持仓校验、转换及定向测试，不改变主仓持仓契约或来源准入。目标运行态须经官方同步与实际 HTTP 验证后另行验收。
