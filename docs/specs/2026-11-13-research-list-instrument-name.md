# 研究列表标的名称与来源展示

## 目标
研究助手列表应使用可信标的目录展示中文名称及规范代码，避免“标的研究”等类型同时出现在研究对象和研究来源中。

## 范围与合同
- 列表读取只使用研究报告已授权的冻结范围提取 `instrument` / `position` 标的代码；按页批量读取本地 Instrument 目录名称，不向上游报价服务发起额外请求。
- `researchReportPageSchema` 可选附带 `instrumentDirectory`，旧响应与历史报告继续兼容；若缺少目录或无法解析名称，保留规范代码，不编造名称。
- 研究对象列展示“名称 · 代码”（有值时），来源列展示“模拟/实际 · 标的研究/持仓研究/其他研究类别”。紧凑布局合并两列但不重复类别。
- 目录仅影响展示，不改写冻结范围、模型事实、权限、研究结果与历史快照；只解析已授权可见报告的标的。

## 验收
- 已授权报告目录命中、目录缺失或未知标的、未授权与历史兼容均有可解释回退。
- 浏览器 1440 / 1024 / 768 / 390px 核对溢出、名称和标签重复。
- 本地源码测试、Schema/Server/Desktop 类型检查通过；运行态更新单独验收。
