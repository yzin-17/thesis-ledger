# 历史快照显示标的名称

## 现状

历史快照列表只显示 `inputSnapshot.trade.symbol`，而单笔复盘的候选列表已通过 `instrumentDirectory` 提供标的名称。

## 目标与边界

- 历史快照列表按名称、代码、复盘粒度展示，与单笔复盘对象列表对齐。
- 历史分页响应由现有 InstrumentDirectoryService 批量解析当前页标的，字段沿用 `instrumentDirectory` 合同。
- 目录缺失或无法解析时保留原始代码，不修改历史快照持久化数据、证据状态或查询行为。
- 旧版无法解析的快照仍显示“标的未知”，不从未经验证的原始 JSON 猜测代码。

## 验收

- 有目录名称时显示名称与代码，无名称时显示代码；分页追加仍可正确解析。
- API、Schema、客户端类型检查通过，旧快照和无数据页面行为不变。
