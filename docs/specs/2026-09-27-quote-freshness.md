# 报价时间新鲜度边界

归属多源回测 M3 R02.5，沿用既有报价接口，不扩大回测执行价格来源。

## 问题与要求

DSA 报价网关直接使用 Provider 适配器，可能没有 Manager 补齐的过期标记；接口不能只因来源时间存在就返回 live。

以响应生成时刻核对有时区的来源时间：超过既有默认 600 秒期限则 stale；有效且不在未来、未超期可沿用 live。来源明确标记过期时不得降级为新鲜。来源时间缺失、格式无效、无时区或在未来时为 unknown，除非来源已经明确标记过期。marketTime 的兼容回退不构成真实市场时间证明，freshness 必须保持 unknown。保留字段名及枚举，不改数据库或报价权限。

## 验收

分别验证旧来源配新获取时间、近期来源、未来时间、未知时间及明确过期；实际 API 序列化保留正确状态。离线测试、目标部署与真实来源验收分别记录，不凭身份探针关闭时间门禁。
