# 桌面端日期选择统一

## 目标与范围

统一桌面端所有日期、月份、日期时间及由两个输入组成的范围选择入口。截图中的开始月份使用浏览器原生面板，修复前公共 DateInput 仅统一收起态；展开面板也纳入公共组件。

## 展示与交互合同

- DateInput 归属 Desktop UI，业务入口单向消费；日历和月份面板复用项目 Button、Input、Popover 与主题 token，不引入页面样式。
- 输入继续使用原来的 date、month、datetime-local 原始字符串与原生约束；不增加时区转换、不截断秒或毫秒、不改变范围校验。
- 保留原生输入的键盘编辑、ref、name、required、min/max、step、错误关联及事件。聚焦失焦和开关面板不产生值变更；只有实际选择或输入更新值。
- 展开面板使用中文、统一选中态、今天/本月与清除操作；禁用和只读不能打开面板或修改数据。Escape 仅关闭当前弹层并恢复焦点，点击标签不激活输入。
- 日期范围继续由各业务拥有其语义，公共组件不把起止日期重解释为整天或 UTC 时间。

## 验收

1. 记录所有消费者以及保留差异；不存在绕过公共组件的日期类输入。
2. 定向测试覆盖表单原值、精度、约束、禁用/只读、受控/非受控、选择/清除、取消和键盘输入。
3. 在 1440、1024、768、390 宽度及短窗口验证页面和 Drawer 内的面板、焦点、滚动与溢出。真实业务只读，提交验证使用受控样本。
4. 记录桌面包检查、仓库门禁、实际浏览器覆盖与未完成项；不把本地前端验收称为 Docker 发布。
