# 桌面端间距与字号

[实施任务](../archive/tasks/2026-11-06-desktop-style-tokens.md)

## 范围与设计

覆盖 Desktop 全部样式表、共享组件、页面与详情中的页签。检查页面布局、字体尺寸、表格与控件；数据状态、业务行为与金融数值精度沿用现有合同。

- AC1：横向页签栏到面板内容外缘统一为现有分组间距（16px），由一层负责；容器内的表格、卡片和图表保留自己的内边距。无内容的分组不占空间；错误、加载提示按实际内容占位。纵向控件保留紧凑间距。
- AC2：项目样式表与 Tailwind 共用间距、排版尺度。页标题在小屏为 28px、常规宽度为 32px；页头到正文沿用 24px，标准分区标题 20px，正文 14px，辅助文字 12px。图表标记、紧凑控件与响应式指标按用途保留专用尺寸。
- AC3：检查桌面端源码中所有字号和间距来源，区分内容布局、控件、图表几何。用浏览器在 1440、1024、768、390 宽度切换页签，核对截图对应标题、内容边缘、键盘切换、主题、页面溢出和弹层边界。
