# 行情周期切换与视口稳定性

日期：2026-11-08；对应[实施任务](../archive/tasks/2026-11-08-chart-period-viewport.md)。

## 行为合同

- AC1：同一标的切换周期时保留详情弹窗、资讯展开状态、滚动位置及已显示图表；移除按周期重建整个详情的身份键。新周期读取期间在图表数据区显示共享加载圈，其他详情不清空。
- AC2：周期、复权、历史窗口及请求代次继续隔离。新周期成功后仅替换对应图表数据；迟到响应不覆盖当前选择，历史页不跨周期合并。年度与普通周期的窗口上限正确，缓存切回可用；静态报价与其他详情保留。
- AC3：图表视口操作独立于数据重绘。放大、缩小、拖动、主题及指标更新保留精确逻辑视口，不因边界状态变化反复恢复旧日期范围；数据前插或追加按日期锚点迁移视口，只有处于最新端时跟随新增尾部。
- AC4：切换实际行情范围后初始化一次视口；重置、回到最新、日期区间、补历史和全屏保持可用。原生自动尺寸处理后不持续回写旧视口。
- AC5：定向测试验证状态和竞态，再执行类型、构建、边界门禁及四宽实际浏览器；核对弹窗 DOM 保留、局部加载、快速切换、缩放与拖动后视口稳定，以及 MACD 图层回归。

## 所有权与边界

详情会话拥有请求窗口和可见详情，行情渲染器通过独立视口控制器管理原生时间轴。保持已有领域数据、计算精度、账户隔离和来源预算，只调整 Desktop 生命周期与展示；不修改服务端、数据库或部署。浏览器使用受控读取或真实只读数据，分别记录输入边界。
