# 已保存策略直接配置回测

日期：2026-11-07。任务标识：saved-strategy-backtest。对应[归档任务](../archive/tasks/2026-11-07-saved-strategy-backtest.md)与[验收证据](../archive/evidence/2026-11-07-saved-strategy-backtest.md)。

## 目标与范围

已保存股票或 ETF 策略的普通回测入口不要求再次输入执行模型 JSON。保留策略版本、日期、初始资金和价格口径；系统复用策略佣金、最低佣金、滑点及成交时序。用户已确认默认采用[研究默认规则](2026-11-07-backtest-research-defaults.md)，按回测区间生成并披露简化执行假设；真实交易状态与行情继续由正式准备链核验。重新运行可继续使用原冻结模型。基金净值专用配置和 AI 实验的独立设置保持原有合同，本次处理截图对应的普通回测入口。

## 行为与边界

- Server 提供受策略所有权保护的执行配置解析入口。默认仅读取已保存策略并生成研究模型，不把研究假设缺失解释成历史事实缺失；严格历史规则分支读取现有 DSA 标的事实，按实际覆盖拒绝缺口、冲突、晚到来源及未知费项。
- 费用继承策略佣金及可选最低额；未配置税费的研究初值暂不计入，并直接披露。取得适用的已核验税费后按现有冻结设置处理。滑点及成交方式仍由策略执行器消费，不重复计费。没有声明的最低佣金保持未设置。生成配置以当前研究配置标记来源和假设。
- 复权研究显式生成连续价格与归一化数量模型；默认不模拟涨跌停，原始份额仍受真实市场单位准入约束，结算采用直接披露的研究假设。模型和来源在现有准备、冻结、预检及任务链中保留。
- Desktop 自动取得配置，通过 TanStack Query 隔离策略、日期、币种和口径请求；日期或策略变化后旧响应不能继续用于开始回测。缺失时显示具体原因及重试入口，不要求用户填写技术协议。
- 普通入口默认只展示必要运行参数与自动设置状态；严格历史时点、预热边界和公司行动研究放在“高级回测选项”中，当前历史数据口径与冻结时间语义保持直接可见。
- 使用现有正式准备和连续提交链，不改变后台任务终态、所有权、预算和确认边界。不启用新 Provider，不调用模型，不改写真实策略、交易及历史结果。
- “开始回测”提交被服务端接收后关闭弹窗并进入“回测任务”；后续准备及预检状态由任务入口展示。提交失败时保留弹窗、配置及错误提示，允许原地重试。
- 普通回测的后台准备、预检失败按[准备失败任务合同](2026-11-08-backtest-preparation-failure-jobs.md)创建失败任务，在任务列表和详情保留原请求及诊断；已关联任务的提交不在顶部重复展示。

## 验收

- AC1：解析请求与结果有共享契约；已保存策略的成本、研究假设和日期边界正确，严格历史模式的非法与未知资料具体阻断。
- AC2：普通回测入口无执行模型 JSON 输入；配置自动读取，取得后可直接提交现有后台准备和运行意图；失败、重试与迟到结果有正确反馈，旧冻结配置可复用。
- AC3：定向及包级检查、API 所有权与限流分类、模块边界通过；四宽真实浏览器验证默认、加载、失败、重试和提交，业务写入使用受控请求或隔离样本。
- AC4：正式快更通过并验证实际接口，区分研究模型准备与真实来源准入；研究假设不得作为真实历史状态证据。

未决问题：无。详细验证与当前状态由任务及证据维护。
