# 细分路由选择具体来源

状态：已实现并完成本范围验收。任务见[实施清单](../archive/tasks/2026-11-10-routing-explicit-source.md)，验证见[验收记录](../evidence/2026-11-10-routing-explicit-source.md)。

- AC1：细分项仅提供具体接口及未配置或不设备用入口；大类仍按提供方设置默认偏好。主备去重、凭证权限过滤与来源不可用回显保持。
- AC2：已有具体绑定正常回显；旧配置未绑定且只有一个接口时显示唯一来源，多个接口时以“请选择具体来源”提示，不猜测第一个接口或触发草稿修改。该提示只作为触发器占位，不作为可选来源。
- AC3：选择具体接口只修改当前细分项，恢复继承继续通过原入口完成；其他类、其他子项及真实业务配置保持。定向测试、Desktop 构建和四宽浏览器验证具体候选、占位、选择和保存前检查；真实保存拦截。
- AC4：保存前检查及保存请求只发送编辑内容，`preserved` 字段提交空数组；本地草稿和基线仍保留完整记录。服务端继续从当前数据库快照恢复可信记录并校验修订及目录，不依赖客户端回传或扩大请求正文预算。

范围为 Desktop 来源选择投影、现有选择器占位支持及请求精简，沿用服务端及保存协议。请求精简用于解除当前配置回传保留记录导致的正文大小阻塞。
