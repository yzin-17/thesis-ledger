# 行情视图工具与模型点位

日期：2026-11-08；对应[实施任务](../archive/tasks/2026-11-08-chart-view-tools-parity.md)。

## 行为合同

- AC1：股票、ETF、基金历史净值与基金今日估值使用同一组视图控件，顺序为回到最新、重置、全屏、放大、缩小、向前、向后；按钮名称、样式和响应式换行一致，适用动作实际可用。
- AC2：基金历史净值全屏及退出后保留可见范围、成本参考、测量和成交交互；Esc 依次处理内部日期弹层、测量或锁定、全屏。全屏入口恢复焦点，无横向溢出；数据刷新不覆盖手动缩放。
- AC3：股票与 ETF 在日、5 日、周、月、年周期保持模型模拟买卖点入口。日级模拟事实按聚合行情的日期桶映射到对应 K 线，读取覆盖完整桶范围，点击聚合 K 线能查看桶内事实；保留模拟事实原始日期及明细。分钟周期保留入口并通过图标说明日级点位的适用范围，不伪造分钟坐标。
- AC4：关闭模型图层后不读取模型来源；账户与身份边界保持，切换周期不把旧范围点位附到新图。定向测试、构建、门禁与四宽浏览器验证真实控件、画布导航、全屏、成本/测量和聚合点位。

## 所有权

视图控件、原生时间轴控制和全屏容器归属行情详情；基金图表资源按画布生命周期管理。模型点位映射归属模型比赛消费层，只附加绘图坐标，不更改模拟事实、账户账本或服务端协议。复用已安装的 shadcn 组件和主题原子类。
