# 个股新闻按所选范围分页读取

## 目标与边界

让用户通过「加载更多」读完所选时间范围内来源可提供的个股新闻。先打通当前已启用的 HiThink 个股时间线；继续复用既有 `cursor` / `nextCursor` 合同，其他未声明分页能力的来源保留真实限制，不生成猜测游标。每页五条，不自动扫完整历史，不改变准入标的、日期、有效期或凭据。

## 行为与验收

- AC1：HiThink 首屏传 `offset=first`，后续原样回传来源 offset；取数与实际返回页大小一致，不能读取六条仅返回五条后跳过第六条。来源游标不前进时失败并保留已加载页。
- AC2：DSA 返回不可猜测的有界、30 分钟有效的不透明游标，绑定标的、精确时间窗口、条数、来源、数据库、策略和凭据/配置代次。游标不能跨来源使用；无效、过期或控制变化在上游调用前拒绝，重试相同游标可用。内存最多 512 个继续点，服务重启后提示重新查询。
- AC3：逐页按请求闭区间过滤并保留来源时间；对时间线逐页验证页内和跨页倒序。全部已读取时间已知、无时序异常且末条早于所选起点时结束本次窗口，或以来源 `has_more=false` 判定源结束。官方分页文档没有声明全历史完备性，本次完成语义限于该来源的倒序时间线窗口。空页仍有后续 offset 时允许继续；发布时间未知、页内或跨页逆序、重复 offset 等异常不得触发窗口提前结束或认证完整覆盖。
- AC4：Desktop 用 TanStack Query 管理分页，冻结首次查询参数，追加、去重并保留已加载条目；加载失败可原游标重试。切换标的/日期或关闭取消请求并丢弃旧作用域；同一列表加载圈保留原内容，所有相关请求结束后再收起。
- AC5：「加载更多」仅在服务端有 `nextCursor` 时可用；全链条正常耗尽且没有时间未知、来源失败等缺口时显示「所选时间范围内的来源新闻已加载完毕」。其他状态保留具体限制，不能仅因没有游标就声称全部读完。合并统计基于去重后的已加载结果，按同一来源分组，不突破单页 API 上限冒充响应。

正常分页尚有后续页时，使用「已加载 N 条」及「加载更多」，不把单纯的 `pagination_truncated` 显示为覆盖缺口或「部分覆盖」。其他覆盖缺失、未知时间、实际错误继续显示；没有后续游标的真实截断不能隐藏。该区别仅应用于提供加载操作的分页列表，详情与研究的单页展示保留其覆盖语义。

新闻列表的每条记录仅展示标题、来源和发布时间；移除独立证据计数、来源首次可用时间及抓取时间的界面回显，保留已加载条数、所选查询范围与分页操作。原始来源、时间与证据字段继续保存在数据合同和历史记录中。
- AC6：HiThink 分页适配修订升级。通过 infra 维护脚本重新核验同一招行准入，只更新适配修订和证据链，严格保留现有标的、日期、有效期、凭据和路由。先定向测试、包级与门禁，再按 `sync-code.sh dsa` 或必要的正式更新入口同步。
- AC7：真实招商银行最近 3 天，在实际抽屉从首页加载后续页直到真实耗尽，展示数超过五条；核对重复、时间窗口、最后状态、失败恢复及 1440/1024/768/390 布局，真实业务数据只读。

实测收敛：来源会连续返回数月前的历史；结束条件按本次所选窗口和逐页倒序验证收敛，避免让用户为三天查询连续请求大量空页。界面所称加载完毕仅指该来源时间线范围，不认证全网新闻或来源未提供的历史。

## 实现所有权

DSA 拥有来源分页和不透明继续点；Server 继续校验现有合同；Desktop 拥有已加载页的展示投影；infra 拥有兼容更新与同范围准入修订。游标缓存仅保存分页位置与范围摘要，不存凭据值或正文；过期及容量淘汰保留明确失败。

跨页去重使用项目已安装 `es-toolkit@1.51.0` 的 `uniqBy`，保留首次条目，不改写原新闻身份；代码和官方声明已核对。来源协议见 [HiThink 个股分时新闻](https://fuyao.aicubes.cn/docs/api-reference/news-stock-timeline/)。

实现与实际验收已完成，见[归档任务](../archive/tasks/2026-11-09-market-news-pagination.md)与[验收证据](../evidence/2026-11-09-market-news-pagination.md)。本规格继续作为当前分页合同。
