# 策略标的名称展示

日期：2026-11-10。对应[已完成任务](../archive/tasks/2026-11-10-strategy-instrument-display.md)与[验收记录](../archive/evidence/2026-11-10-strategy-instrument-display.md)。本规格继续维护当前展示合同。

## 目标与范围

策略编辑、列表、详情和回测配置以当前标的名称为主、代码为辅。编辑器执行标的标签只保留“执行标的”，移除紧邻的市场与资产类型小字。Desktop 与 Mobile 共同消费服务端名称投影。

## 展示合同

- 服务端经 Market 的 `InstrumentDisplayService`，按完整代码批量读取本地目录；同一列表去重后查询一次。
- 策略版本响应增加可选 `instrumentDirectory`，覆盖执行标的与信号来源；写入与高级 JSON 中的策略定义保持原样。
- 已保存策略首次打开即可显示名称，无需展开搜索；选择新标的后立即显示名称。聚焦、取消与回显不得修改业务代码或产生未保存状态。
- 缺目录、歧义或目录故障时保留业务结果并回退完整代码；不同市场分别匹配。当前名称投影不改写历史策略、回测结果或冻结记录。

## 验收

- AC1：初次打开及重新打开编辑器均显示目录名称，标签无市场/类型小字；信号来源同步显示名称。
- AC2：列表、当前定义、回测配置和 Mobile 编辑复用版本响应的名称；无额外补名请求。
- AC3：目录批量查询、重复代码、跨市场、缺失与故障回退可验证，原始定义保持不变。
- AC4：定向测试、类型检查、仓库门禁通过；目标运行态与 1440、1024、768、390 宽度浏览器检查通过。

## 边界与风险

只增加读取投影与展示输入，不迁移数据、不保存真实业务记录。搜索仍使用已有目录搜索接口。未决问题：无。
