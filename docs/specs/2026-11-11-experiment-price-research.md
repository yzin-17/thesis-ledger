# AI 实验统一策略收益研究

实施与验收：[已完成任务](../archive/tasks/2026-11-11-experiment-price-research.md)、[验证记录](../archive/evidence/2026-11-11-experiment-price-research.md)。本规格维护当前新建实验合同。

## 目标与所有权

新建 AI 实验复用[普通回测的双价格研究规则](2026-11-11-backtest-return-research.md)：后复权计算指标和模拟收益，具体金额价格条件使用不复权参考。页面不再选择前复权或后复权。Backtest 继续拥有研究策略投影、行情规划、冻结与重放；StrategyOptimization 只编排实验和候选，不反向修改核心领域规则。

## 行为合同

1. 新实验使用策略 Schema V3 与 `price-research-v1`，固定后复权、归一化研究单位和固定来源快照。已有研究版本直接使用；旧正式策略先复用现有预览并确认保存新版本，再选择新版本作为基线。不得静默改写旧策略或阈值。
2. 从零探索创建研究种子。AI 仍只提交可变策略表达，Server 使用普通回测投影规则确定实际价格与研究价格来源，保存 V3 候选和采纳版本。指标零轴、同坐标比较及具体价格常量沿用共享规则。
3. 新实验准备时显式冻结后复权执行窗口和不复权参考窗口，二者按[独立来源合同](2026-11-12-independent-research-price-sources.md)各自选择来源，覆盖候选预热预算；基线、候选和三段切分都复用各自已冻结窗口。候选不得临时补取新参考价或扩大冻结范围。普通回测仍只按自身依赖读取行情。
4. 为冻结额外参考窗口，Backtest 准备意图增加显式 `priceResearchReference: 'freeze'`；仅在价格研究协议下有效。输出沿用 `priceResearch.actualPriceWindow`，回放读取存在的窗口并验证其证据，不猜测或重算历史行情。
5. 历史实验的研究版本、价格协议、生成行为、已冻结提示与快照保持原语义；新的探索空间使用独立版本标识。克隆保留原实验协议，旧幂等创建重试仍读取原实验。正常新建入口由 Server 检查完整研究协议，客户端不能绕过。
6. Desktop 新建页、旧实验面板和 Mobile 使用相同准备合同；旧版本转换和研究说明使用现有组件。Mobile 不重设计模型和预算输入，不改变原生工程。

## 验收

- 合同与准备：新模式拒绝前复权、旧策略直接运行、缺少参考窗口等不完整输入；历史读取、克隆和幂等恢复保持原样。
- 执行：实际价格阈值与后复权指标正确分流，基线和候选复用同一批冻结事实；包括从纯指标种子新增实际价格条件、固定投入参考份数、不同预热需求和来源失败。
- 消费：已有 V3 可选，旧版本确认后采用新 ID；新建页无价格口径切换，展示后复权与原价用途，四宽无溢出，失败保留输入。
- 验证按定向测试、包级构建与门禁、隔离数据库执行、受控运行和真实页面进行。已有同输入的普通研究验收可复用；新增额外参考冻结路径须单独验证。

## 执行边界

不改写历史业务记录，不调用付费 AI，不创建用户真实实验，不变更数据库结构或路由策略。受控样本使用隔离环境或维护入口；目标部署采用正式最小快更入口。未获授权不提交或推送。
