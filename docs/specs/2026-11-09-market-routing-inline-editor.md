## 目标与交互

- AC1：细分列表只平铺展示完整的精确路由，使用完整范围名称及常驻主备下拉框。行情行须同时指定市场、标的类型、用途、周期和复权，其他能力须指定市场、标的类型和用途；旧汇总配置按有效设置展开为精确项例外。顶部统一按市场、标的类型、用途、周期和复权筛选，初始均为全部；各筛选独立可选，只展示范围本身匹配全部已选条件的行，可一键清空筛选。筛选不改变配置。桌面统一表头，窄屏逐组显示控件标签。
- AC2：直接选择主备，实际选择才写入共享草稿。“使用上级配置”删除单项覆盖，直接恢复大类配置；主源“未配置”继续清空本项主备并阻止继承。
- AC3：返回主配置保留各层共享草稿，不提交；具体来源选择继续保留上级及未更换来源的精确绑定，统一预览取消后可继续调整草稿。
- AC6：精确项的主备选项及选中回显复用“数据源 · 具体来源”标签，在同一下拉框选择具体接口。大类只选择提供方；细分项已有精确绑定继续回显，未绑定且仅有一个接口时显示唯一来源，多个接口时提示“请选择具体来源”，不猜测接口或修改草稿。选择及验收详见[具体来源合同](2026-11-10-routing-explicit-source.md)。主备不能选择同一家数据源，恢复继承及明确清空语义不变。
- AC7：可选来源只来自当前行范围对应的实际能力目录，具体行匹配市场、类型、用途、周期和复权全部已指定维度；聚合范围允许来源部分覆盖，覆盖缺项仍由诊断说明。未支持当前能力或账户权限未确认可用的来源不作为新选项；缺凭据来源沿用原规则标注且禁选。既有不适用选择保留只读回显及原因，不自动替换或清空。
- AC8：采用建议主备、查看本地资料、查询资料、查看新闻及相关显式操作入口使用可识别的按钮边界，辅助操作保持次级层级，并保留悬停、键盘焦点及禁用反馈。清空筛选、恢复继承、重试和监测查看入口遵循相同表达，操作结果及确认流程保持。
- AC4：面板底部可直接“预览变更”，使用现有统一预览与保存流程。现有保存失败恢复、目录待确认、导航草稿保护及所有层级共享草稿保持。
- AC5：桌面右侧面板、窄屏全屏，正文和已选值使用正文色。标题、筛选及底部操作位于列表滚动区域外，仅列表滚动；滚动前后固定区域位置保持，筛选边缘不露出列表内容，外层不产生额外滚动条。覆盖 1440、1024、768、390 及窄屏较矮窗口，无横向溢出、弹出层越界或操作裁切。真实业务配置只读，保存和故障使用受控请求。

## 实现范围

本规格维护 Desktop 交互，Server 无损整理及兼容字段由 [旧继承整理规格](2026-11-10-routing-legacy-inheritance.md) 持有。列表按现有精确 key 构建，只编辑完整精确路由；大类主备由主页面配置，旧汇总设置无损展开为单项例外。标签复用现有中文映射。继承和单独设置属于当前规则状态，不新增启用开关。

纯投影验证所有层级、继承、显式空配置及精确绑定；编辑组件验证初始渲染无修改、直接选择、恢复上级和预览入口。随后执行 Desktop 构建、边界/严格复杂度与文件规模检查，实际浏览器覆盖全部代表宽度及受控失败恢复。原有路由读取和原样预览继续证明来源无损。
