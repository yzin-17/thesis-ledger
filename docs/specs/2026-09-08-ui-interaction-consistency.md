## 背景与目标

全站已有共享组件和主题变量，但页面标题、布局间距、容器边界及操作反馈存在不同实现。本主题统一视觉语言和操作习惯，保留内容类型需要的信息密度。用户已明确要求保留装饰性英文副标题。

桌面页面共享同一套视觉与交互契约，因此使用一个规划单元，分页面独立验收。移动端作为独立验收批次，复用语义及视觉层级，保留原生操作习惯。

## 约束与非目标

- 延续现有 shadcn/Base UI、主题变量和共享组件体系，优先原子类、组件变体及组合，不新增页面级覆盖规则作为常规方案。
- 保留既有业务、接口、金额口径、币种、真实与模拟模式、权限及功能开放状态；本主题不扩展业务功能。
- 保留工作区未提交改动，尤其共享 Sheet 和策略实验；每批开始前重新确认相关文件当前状态。
- 本主题不更新其他任务完成状态、不发布、不提交代码。
- 10-18 用户确认现行运行架构：Desktop/UI 在本机构建运行，连接 Docker 中的 API/Worker；现有 Dockerfile 和快更脚本不托管 UI。目标验收分别记录 UI 包和真实 API 的证据，后端已一致时不重复更新或重启，不将脚本成功误作 UI 已进入容器。
- 对超过尺寸或复杂度门限的文件，新增职责须收敛至明确组件；不得提高门限或机械拆分。

## 设计方案

### 标题与文案

一级页面采用“装饰性英文副标题 → 中文主标题 → 可选说明”。英文简短、全大写，统一字距、弱化颜色和位置。中文标题为主要层级。Tab、卡片和表单内部使用相应标题层级，不重复整套页头。

导航名称与页标题一致；投资组合中的总资产作为指标呈现，确保页面仍有清晰的名称。说明描述用户可以完成的任务，版本、Schema、引擎等细节放在相关配置或结果附近。策略中心按[后继列表合同](2026-09-18-strategy-center-list-usability.md#31-页面骨架)使用紧凑中文页头，不恢复英文眉题及常驻说明；研究助手同样按其后继合同处理。

以下为现行标题映射。共享页头与侧栏参数已按 `PageHeader`、`Sheet` 实现及代表页面证据核对定稿；策略中心和研究助手保留后继合同例外。

| 中文标题 | 英文副标题 |
| --- | --- |
| 投资组合 | PORTFOLIO |
| 账户数据 | ACCOUNT DATA |
| 风险中心 | RISK CENTER |
| 收益分析 | PERFORMANCE |
| 策略中心 | 按后继列表合同省略 |
| 投资复盘 | INVESTMENT JOURNAL |
| 研究助手 | 按后继列表合同省略 |
| 数据与自动化 | DATA & AUTOMATION |
| 市场数据 | MARKET DATA |

定稿共享排版：英文 12px、字重 600、字距 0.16em；页面标题在 `sm` 以下 28px、其余 32px，字重 600、行高 1.25；说明 14px、行高 1.625。英文至中文间距 8px，中文至说明 12px，页头至正文 24px，操作区允许自然换行。侧栏由 `SheetTitle` 使用 20px、字重 600，说明 14px、行高 1.625；标题与说明间隔 8px。模块内部标题继续复用对应共享组件层级，原初始 18px 提案不作为覆盖卡片、指标和表单不同语义层级的统一规则。本次只回写现行实现，不新增视觉迁移。

### 边框、分隔线与容器

| 场景 | 规则 |
| --- | --- |
| 页面与模块 | 优先留白；同组内容的明确分区可使用单条分隔线 |
| 独立卡片 | 独立操作或成组数据可使用一层外框；内部优先留白、浅背景或分隔线 |
| 表格与列表 | 表头和行分隔统一；不默认增加每个单元格的竖线；悬停与选中语义区分 |
| 表单控件 | 复用统一边框、圆角与高度；聚焦和错误不能仅靠轻微颜色差异 |
| 按钮 | 实心表示主要操作，描边表示次要操作，轻量按钮用于低强调操作；每个操作区明确主要动作 |
| 侧栏与弹窗 | 使用共享边界、遮罩和阴影；内部仅在固定操作区与滚动内容之间需要时分隔 |

边框默认 1px、使用语义化颜色；常规控件与容器初始圆角均采用现有 6px 级别；常规静态卡片不使用浮层阴影。每条线应能解释其分组、交互或层级用途。嵌套容器若保留多层外框，须在问题清单说明独立语义。浅色和深色采用相同语义，分别验证可辨识性。

### 交互契约

- 表单：统一字段说明和就近错误；提交中防重复提交；失败保留输入；成功等待相关数据刷新后关闭或返回。写入成功但刷新失败时，明确提示刷新失败，提供重新读取入口，避免诱导再次写入。
- 关闭：有未保存修改的编辑界面，关闭按钮、Esc、遮罩和页面离开遵循一致提醒规则；无修改时可直接关闭；关闭后焦点返回触发入口或其合理替代位置。
- 侧栏：共享 `SheetContent` 的 `compact`、`form`、`detail` 分别为 480px、640px、960px，默认 `form`；左右侧栏实际宽度不超过视口减 16px。保持一个清晰滚动区域，底部操作不遮挡最后一个字段。跨层选择器与确认框须验证焦点和遮挡。
- 搜索与筛选：清楚展示当前范围及重置动作；同页面打开再关闭详情保留筛选和位置；账户或模式变化时不能展示上一范围的数据为当前结果。跨页面保留范围沿用现有契约，有变化先记录于规格。
- 反馈：短暂成功使用 Toast；字段错误放在字段附近；持续的加载失败或过期状态放在对应区域并提供恢复动作。长任务必须能看见运行、完成和失败状态。
- 空状态：区分首次无数据、筛选无结果、依赖未配置和请求失败，不把错误或未知值渲染为零资产。
- 展示：同类金额、日期和比例统一格式，币种清晰，缺失值与零区分；颜色同时配合数值、文字或图标表达。
- 可访问性：可见焦点、图标按钮可访问名称、合理焦点顺序；标签仅作说明，遵守项目禁止默认标签激活控件的规则。
- 窄窗口外观入口：在主内容页头前使用普通流工具条承载主题与涨跌配色，随页面滚动；不得固定悬浮并遮挡分页或提交操作。800px 及以下使用该工具条，与侧栏底部的隐藏边界一致；更宽窗口继续使用侧栏入口，两处复用原控件及偏好状态。
- 账户范围：账户相关页面跟随应用共享的实际/模拟模式，页内下拉仅选择该模式的账户，“全部账户”也限于该模式；最近账户分别记忆，恢复及请求消费前检查归属。另一模式的旧 URL/记忆不得改变应用模式或继续读取旧账本。应用层先完成未保存/在途保护，再下发新模式；账户页的局部浮层和草稿状态按模式分界，不能把旧对象交给新账户查询或写入。此处承接[用户已确认范围](../reviews/2026-10-14-user-experience-optimization.md#r01实际--模拟账户使用唯一全局开关p1用户已确认)，外壳、记忆、转换保护及消费的现行合同见下方 R01，验收由配套 Task 维护。

## 对外行为、状态及兼容性

对外变化集中于标题、布局、边界与操作反馈。R01 为研究请求既有 JSON context 增加可选 mode，并让只读 Tool 消费冻结范围；不新增数据库字段或迁移，不改写历史 context。旧入口跳转、账户及模式隔离、行情详情与复盘链接须回归。原有禁用入口继续保留原因说明。共享能力仅承载稳定表现与通用交互，业务编排由各 feature 持有。

## 测试策略

### 全局账户模式（R01）

应用外壳拥有唯一可操作的实际/模拟开关；宽屏位于品牌与导航之间，折叠时仍可辨认，≤800px 使用主内容顶栏。业务页只显示必要范围说明。模式以 `thesis-ledger-portfolio-mode` 在本设备记忆，首次默认实际；首次查询前同步恢复，URL 和历史导航不改变模式。存储不可用时保留内存选择并反馈记忆失败。

应用级转换保护统一接收草稿与同步操作的在途状态；现有表单关闭保护继续保留。会被范围转换清理的草稿必须先经过一次可取消确认；取消不改模式、URL、账户、输入或持久记忆。确认后丢弃本地草稿，再更新模式；确认期间若开始写入，应阻止转换。共享配置和独立对象输入不依赖账户模式时可原样保留，不得粗粒度重建整个策略中心而静默丢弃改名等输入。写入及保存后确认读取尚未结束时不得切换或离开，不把已提交对象重新归入新模式。普通查询可取消并按各自模式/账户 Query key 隔离。

全局转换与路由离开复用同一保护事实源，避免多个 Router blocker 竞争。账户下拉、浏览器前进/后退与跨页返回仍须保护当前草稿；自动清理无效 URL 使用 replace，不制造返回循环。当前模式内无账户时展示该模式空态；新建账户继承模式且归属只读，既有账户属性与历史事实不因浏览切换改变。复盘只列当前模式账户，跨模式链接给出说明，不读取其对象；共享配置、独立策略/回测和已提交任务保留自身归属。

新建非策略研究在 `context.mode` 明确固定实际/模拟范围，账户和持仓选择只列该模式；提交、持久化和只读 Tool 消费同一模式，不能只改界面。旧研究未保存 mode 时保留原上下文语义，不迁移历史记录；策略研究不携带账户模式。跨模式重试提示原对象归属并阻止直接提交，不悄悄改写原 context。真实生成及目标执行验收仍服从 AI 停止决定。

本项验收按外壳/记忆、转换保护、账户与跨页消费、研究上下文四个可独立验证的部分执行；复用已过的页面查询隔离，只补全局控制和对应新请求边界。不得为验收写真实账本、执行真实 AI 或触发路由故障。

先形成全量入口与状态矩阵，再逐批验证实际页面。每个入口记录位置、检查状态、问题编号、视口、主题和证据；状态不适用时说明理由，环境阻塞时记录具体依赖，不标记通过。

桌面至少检查 1440×900、1024×768、390×844；全部一级页面覆盖浅深主题，全部侧栏与弹窗检查打开、滚动、关闭及焦点。状态通过受控测试数据或请求模拟验证，不为制造错误修改真实业务数据。移动端在可用设备或模拟器验证，浏览器窄窗口不替代原生验收。

复用现有 UI、路由、账户、风险、收益、研究与复盘测试入口；对异步保存、失败恢复和范围切换新增必要的行为回归。纯视觉数值以实际渲染核验，不新增仅匹配 className 字符串的测试。类型、构建和静态检查不替代运行验收。涉及原生依赖或构建配置时执行对应 Native compile。

## 风险与备选方案

共享样式可能影响所有调用方，使用兼容扩展、分批迁移、最终清理的顺序。样式局部统一即可满足时，不扩大组件改造。存量大文件只提取本主题新增或变化职责。运行环境缺少数据或外部服务时，模拟证据与真实环境证据分别记录。

## 验收标准

- AC1：全部一级页面、Tab、侧栏、弹窗和全局入口具有检查记录；正常及适用的异常状态均有证据或明确阻塞说明；有未解决阻塞时不得宣称全量验收通过。
- AC2：桌面一级页面采用定稿的标题与说明层级；导航与页标题含义一致，尺寸和间距符合试点定稿值。策略中心及研究助手按各自后继列表合同使用紧凑中文页头。
- AC3：各页面边框、分隔线、背景、圆角和阴影符合场景规则，例外有明确语义；浅深主题和三个目标视口无内容遮挡。
- AC4：所有编辑入口提交中防重复、失败保留输入、成功刷新后返回；刷新失败不会诱导重复写入；有修改的关闭行为一致。
- AC5：所有适用页面区分空、失败、过期和加载状态；反馈就近可恢复，账户与模式切换无错误范围内容，详情往返保留原范围。
- AC6：控件、数字格式、按钮优先级及焦点行为统一；标签交互符合项目约束，菜单和浮层不遮挡关键操作。
- AC7：策略实验、账户数据和投资组合的代表流程通过运行验收，最终规则已同步回规格，再推广其余页面。
- AC8：移动端两页完成同类文案、数据及状态语义统一，在设备或模拟器记录验证结果，保留原生交互及只读范围。
- AC9：业务接口、金额口径、旧入口与功能开放状态保持兼容；各批完成相应测试，最终覆盖表区分静态、浏览器、原生与外部依赖证据。
- AC10：适用横向滚动的桌面行操作列使用共享语义组件，表头与单元格固定在最右侧，背景不透底并保留左边界；纯只读表格不增加操作列。策略库、回测任务、实验列表按后继[列表可用性合同](2026-09-18-strategy-center-list-usability.md) AC-L08 使用静态窄操作列，不恢复固定列或强制最小宽度；该例外不扩展到其他表格。
- AC11：策略库不重复拼接已包含首个标的的描述，版本数据时点使用中文本地时间格式，已完成回测使用克制的非 primary Badge。
