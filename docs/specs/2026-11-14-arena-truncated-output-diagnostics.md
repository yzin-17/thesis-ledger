# Arena 截断响应诊断补全

## 目标与边界

配置已由用户确认，不再重复核对。补全单次完整响应以 `length` 等非正常原因结束时的输出诊断，支持区分正文缺失、正文为空及推理重复。保留原错误码、用量、费用、拒绝结果和重试行为，不从思考文本提取交易指令。

只使用离线合成响应验证；不调用真实模型、不重试或恢复比赛、不部署、不改变模型／限额／思考设置，不改写历史审计。此修改不宣称修复模型推理循环或完成历史回放。

## 验收标准

- AC01：单次非正常结束仍以原错误码和确定性收敛，保留原实际总用量，SDK 不增加调用次数；正常响应处理不变。
- AC02：截断诊断保留正文字符数、摘要、JSON 状态及脱敏结构预览；空正文与未取得正文区分。不得通过读取结构化结果而覆盖原长度失败。
- AC03：新增可选的推理字符数、摘要、有界重复统计及来源明确的正文／推理 token 分项；未知分项保持 `null`，不以总量差额猜算正文 token。不在新字段保存原始思考或重复段落。
- AC04：重复分析仅覆盖前 65536 字符，明确窗口及截断状态，不能将采样计数冒充全文计数；兼容已有缺少新字段的审计。
- AC05：纯函数测试和注入 HTTP 响应的真实 SDK 离线测试覆盖循环推理、有效 JSON 但 `length`、未知分项、凭据脱敏及正常成功；后续按依赖顺序完成类型／构建和工程门禁。

## 所有权

Schemas 拥有可选诊断契约；AI 模块拥有响应摘要和拒绝边界；Arena 沿用既有错误审计消费，不新增跨领域反向依赖。诊断可用于排障，不参与业务接受或费用计算。
