# Provider 模型目录通用配置规格

> 任务标识：`provider-model-catalog-configuration`
> 对应任务：[已完成任务](../archive/tasks/2026-10-26-provider-model-catalog-configuration.md)

## 目标与边界

用户通过 Provider 前端表单手动定义模型目录的请求地址、响应映射、筛选和分页。Server 只解释通用声明式配置，不按提供方名称、域名或模型前缀识别目录协议；前端也不提供品牌专属预设或自动识别。

本主题替代此前的目录专属实现。保留生成协议、模型选择、凭据、价格、用途、默认研究设置、业务数据和其他 WIP；不调用模型、不启用 Provider 或 V2、原余 2 次额度冻结，不 stage 或 commit。已有目录配置不自动推断、迁移或代用户保存，正式运行态更新继续使用 infra 入口。

## 配置与默认行为

Provider JSON 设置新增可选 `modelCatalog`，不修改 Prisma 结构。共享输入、查询、保存、返回和客户端草稿使用同一合同。

- `url`：用户填写的完整 HTTP(S) 目录地址；不含 URL 用户名、密码或片段。沿用当前认证方式，使用 API Key 时必须与生成地址同源。
- `itemsPath`：响应列表的 JSON Pointer；空字符串表示响应根节点。
- `idPath`：相对于列表项的模型 ID JSON Pointer；空字符串表示列表项本身。
- `reasoningPath`：可选推理元数据 JSON Pointer，仅消费现有白名单结构，不推断第三方元数据。
- `filter`：可选的路径及字符串等值筛选；不接受脚本、表达式或任意代码。
- `pagination`：可选页码分页，包含页码参数名、可选页容量参数名、页容量、起始页及空页／不足一页的结束规则。

未配置时保留现有标准协议的 `/models`、`data` 和 `id` 行为。输入省略 `modelCatalog` 时保留已存配置，显式 `null` 清除并恢复默认。临时目录查询可以覆盖已存规则；获取结果只更新候选，不自动保存或修改模型选择。旧客户端省略新字段不得擦除目录配置。

## 执行与权限

目录只发 GET，请求拒绝重定向、不自动重试，所有分页共享总超时。最多读取 2,000 个原始条目和 21 页；重复页、无效列表／ID、HTTP 错误、超量或超时均整体失败，不返回部分成功。数量和终止判断使用用户配置及实际响应，不根据提供方身份修正。

JSON Pointer 只读取对象自身字段，支持标准转义，不访问原型链。目录配置与模型生成、用途验证及其指纹相互独立，修改目录规则不得调用生成、扩大权限或使已验证的生成用途失效。

## 前端交互

在现有连接配置中增加“模型目录规则”，显示“默认规则”及“手动配置”。手动模式提供上述通用字段及中文说明，复用现有 Field、Input、ToggleGroup 和 TanStack Query 请求状态；无品牌分支，不改整体布局或主题。

编辑或切换规则必须使在途旧目录结果失效。失败保留原模型选择并反馈具体的安全错误；取消不保存，保存后可重新打开查看规则。规则仅由用户在前端手动设置，本轮不通过脚本写入目标 Provider 的目录配置。

## 验收断言

- AC1：共享合同覆盖默认、手动、清除、非法路径和分页；保存及返回往返不丢配置，旧客户端省略字段保留配置。
- AC2：Server 无提供方专属目录分支；相同输入配置解释任意名称的提供方，正确处理地址、映射、筛选、分页及执行边界，标准目录回归通过。
- AC3：前端可手动编辑、校验、提交和回显通用目录配置；草稿获取使用当前规则，竞态、失败、取消及模型选择保留通过验证。
- AC4：受影响包的测试、类型、构建与仓库门禁通过；通过正式 infra 最小入口更新后，Server／Worker 与共享合同一致，真实前端手填临时规则可读取目录。
- AC5：不代用户保存目标目录配置；目标现有配置、凭据、默认值和业务数据保持，模型调用 0、V2 关闭、余 2 次冻结，既有 WIP 和验收证据保留。

## 验证与未决问题

按共享合同／定向执行测试、客户端表单及竞态、受影响包与仓库门禁、正式入口和真实前端临时草稿逐级验证。保存往返由实际保存逻辑及固定数据集验证；目标配置最终保存属于用户手动操作，本轮不以自动写库替代。

无阻塞设计问题。本期声明式能力为 GET、JSON Pointer、字符串等值筛选和页码分页，不建设任意协议转换或脚本执行平台。
