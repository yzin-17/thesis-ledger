# 通用多选框内回显

## 范围与目标

将适合搜索、选择多个值的输入统一为同一边框内的标签与文字输入。Desktop 复用 shadcn `ComboboxChips`；Mobile 复用原生 `MultiSelectField`。不将记录操作、逐项授权或图表即时开关改造成表单下拉框。

本轮新增统一入口：Desktop 提供方能力、风险通知提供方、资料监测来源、两处竞技场参赛模型；Mobile AI 能力、模型列表、实验选模、两处竞技场参赛模型。Desktop AI 模型列表和实验选模已使用框内标签，本轮同步清空选中后的搜索并明确移除名称，保留其费用与推理配置。

## 稳定行为

- AC01：选中值在输入框内显示可移除标签，支持名称搜索、连续选择、换行、键盘或触屏操作。选择后清空搜索；已选值仍可搜索并取消选择，不能重复添加。
- AC02：保留值标识、顺序、保存触发时机、选择上限、禁用态、未知值回显与失败恢复。模型同时保留提供方身份、费用说明、推理配置及未知费用确认；手工配置模型的能力继续保留。
- AC03：异步读取、失败和忙碌状态继续由既有查询/业务组件维护。组件只管理输入和选择，不自行保存配置、验证来源或调用模型。
- AC04：参数授权、独立权限声明、逐行导入勾选、图表图例和指标开关保留其说明与即时操作；单选与已有标的多选契约不变。记录完整排查范围和保留理由。
- AC05：定向测试与类型检查通过；实际组件浏览器覆盖 1440、1024、768、390 四档代表宽度、长标签、搜索已选值、移除、限制及原保存内容。Mobile 浏览器证据与原生设备验证分开表述。

## 模块与执行边界

通用静态选项组件属于各端 UI 层，业务枚举、模型、来源和保存策略仍由领域消费者提供。不新增无业务所有权的工具集合，不跨端引入 DOM。新增内容分组使用标题、留白和对齐；保留输入、按钮、表格和图表的语义边界。

真实业务配置只读；保存和失败恢复使用受控请求验证。无依赖、数据库、原生工程、Docker 或真实模型调用变更，不创建提交。
