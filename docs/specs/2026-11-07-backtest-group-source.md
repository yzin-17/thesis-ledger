# 回测分组来源有效性

回测列表中未关联实验的内部种子版本（version=0）不得投影为正式 existing 策略来源，避免单条记录使整页响应不满足契约。只有正整数策略版本与 Schema 版本可投影为 existing；其他已知版本记录使用现有 unknown/missing_source 契约，保留来源引用、任务、计数和分页。未找到版本时保持原 null 行为。不修改历史数据，不猜测实验关联，不放宽正式版本校验。

验证正式版本、内部种子、缺失来源及已关联探索实验；真实接口各页契约、浏览器列表与详情只读验证。

实际验收发现该页筛选栏在 768px 因强制三列撑宽页面，局部改为较宽视口才并列，并限制策略选择列宽；保留组件、查询及表格内滚动。

长名称选中时，单列网格及弹出选项均保持在窄屏视口内，关闭动画完成后验证稳定布局。
