## 目标与范围

用户已确认用途为“仅本地个人研究：最小元数据和原文链接”。为公开目录中的沪深股票提供有界研报列表、稳定来源引用与已获取记录的历史读取，不依赖模型生成。首个实源标的是 `600519.SH`；此标的的成功不能代表其他标的或全部历史已验收。

本切片仅保存证券身份、来源报告标识、标题、发布机构、来源发布日期、原文链接及采集/分页出处。来源列表可能带有的 EPS、评级、摘要、正文等字段不进入保存合同。一致预期另按延期合同处理；PDF 下载、正文解析、模型调用、自动订阅和对外分发不属于本切片。

## 领域与依赖

- DSA 拥有外部协议、来源适配与单页读取；沿既有 `CapabilityContract`、`kind=data` 精确能力键及来源登记扩展 `RESEARCH_REPORT_METADATA`，不能借用新闻能力或在核心层按来源分支。
- Server 拥有本地采集快照及历史消费。请求使用已有目录身份，不能为读取研报创建资产或持仓；历史读取不请求外部来源。快照与模型生成的研究报告分别建模，不能写入或启用研究 V2 生成链。
- 共享 schema 只提供规范请求、响应、关联校验及稳定引用；不携带东方财富原始 DTO。来源与主备、启停、业务就绪继续经过现有控制面，不能自动改写来源配置或路由。
- 若必须新增持久化结构，使用新增 migration、结构矩阵和运行门禁，按保留数据流程部署；先完成隔离验证，再进入目标运行态。

## 元数据与读取合同

- **RM1 身份**：一次请求只读一个已知 `CN/STOCK` 的沪深规范标的。源返回 `stockCode` 必须与请求一致；不做全市场回退。缺失或错配字段不能生成可引用记录。
- **RM2 引用**：以来源命名空间与 `infoCode` 形成稳定报告引用，原文链接按已核对的来源模板构造并标明来源。采集快照另有不可变标识；重复报告及后续修订可追溯，不能覆盖既有历史证据。
- **RM3 日期**：保存有效的来源日期及 `date` 精度。当前返回的 `publishDate` 为零点值，没有可验证的精确发布时间或时区，不把它解释为精确发布时刻，也不用 `fetchedAt` 代替发布日期；本合同不证明严格盘中 PIT 可见性。
- **RM4 预算与分页**：每次只发一个有限超时、有限响应体的列表请求，显式限制页码和页大小；日期仅作为可选筛选，省略时不补隐藏窗口。不自动翻页、重试、换来源或下载附件。返回请求页、来源总页/总条数及局部读取状态；页内完整不等于全部历史完整，页码不能充当永久历史游标。
- **RM5 来源边界**：保存并展示最小元数据及原文链接，仅用于当前本地个人研究范围。Apache-2.0 是上游软件许可证，不替代数据授权声明；以后扩大用途需重新核对。
- **RM6 历史**：保留本次请求、规范来源结果、采集时间和版本。历史查询只读取本地成功保存的快照，不暗中补采；空页、失败、截断及无快照分别表达，不能伪装成全历史无研报。
- **RM7 错误与控制**：超时、权限、字段错误、身份不符、来源停用或路由不可用均保留稳定错误语义及请求标识，使用标准 Data V3 信封。来源配置、其他路由、已有研究数据保持；真实模型和 Longbridge 继续遵守原暂停条件。
